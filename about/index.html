About Hermes Atlas

A free, community-curated directory of the open-source tools, skills, plugins, and integrations built for Hermes Agent, and the guides for choosing between them.

By Kevin Simback · Hermes Atlas maintainer · Updated 2026-10-25

What Hermes Atlas is

Hermes Atlas maps the open-source ecosystem around Hermes Agent, the open-source AI agent from Nous Research. The ecosystem catalog lists tools, skills, plugins, memory providers, workspaces, deployment options, and integrations across 12 categories. Every project has its own page with a plain-English summary, live GitHub data, and its README.

On top of the catalog are the guides that help you choose: curated lists, the Skills Hub, use-case bundles ("I want to build X; which repos do I need?"), and the Hermes Agent handbook for installing and running it.

Who it's for

  • Hermes Agent users who want to add a capability (memory, a messaging bridge, a new skill) without searching GitHub repo by repo.
  • Developers extending Hermes who want to see what already exists before building, and how others approached it.
  • Tool authors who want Hermes Agent users to find their project.

What gets listed

Hermes Atlas is not a general developer tools directory. A project is listed only if it is built for or integrated with Hermes Agent. Cross-platform tools are included when they support Hermes Agent directly, for example a skills manager that works with Claude Code, Codex, and Hermes Agent.

To be listed, a project must:

  • be specifically built for or integrated with Hermes Agent
  • have been created after Hermes Agent launched (July 22, 2025)
  • show genuine effort and add value to the ecosystem, rather than being a personal pet project or homework assignment
  • have at least one GitHub star (official or notable projects can be exceptions)
  • pass a basic security review (no obfuscated code, credential harvesting, and so on)

Direct forks of Hermes Agent without meaningful changes, unrelated projects that happen to use the name "hermes", and abandoned repositories are left out. The full rules are in CONTRIBUTING.md.

How the data stays current

  • Live GitHub data. Star counts are refreshed from the GitHub API daily, and project pages are rebuilt automatically whenever the catalog changes.
  • Summaries from the source. Each project summary is generated by an LLM from the project's README, regenerated when the README changes, and audited against the README for claims it doesn't support.
  • Health checks. Repositories that are deleted or renamed upstream are caught by automated catalog health checks and removed or updated.
  • Grounded chat. The Ask the Atlas chat answers from a knowledge base of Hermes Agent documentation, release notes, and guides, and cites its sources.

Use it from your agent

Everything on the site is available in machine-readable form:

  • llms.txt and llms-full.txt: a site map and the full text of the guides and summaries, for LLMs.
  • data/repos.json and data/summaries.json: the catalog and every project summary as JSON.
  • The hermes-atlas MCP server (npx -y hermes-atlas-mcp) lets MCP clients such as Claude Desktop search the catalog directly.

Submit a project

Listing is free. Open a Suggest a Repo issue on GitHub and paste the repository URL. Automation fetches the metadata, runs a basic security check, and opens a pull request, which a maintainer reviews against the criteria above. If your project is already listed and its description is out of date, open an issue or a pull request with the correction.

Contact

  • Listings, corrections, and bugs on this site: open a GitHub issue.
  • Bugs or feature requests for Hermes Agent itself: use the official Hermes Agent repo.
  • The maintainer: Kevin Simback, x.com/ksimback.
  • Updates: the Hermes Atlas newsletter.

Frequently asked questions

What is Hermes Atlas?

Hermes Atlas is a free, community-curated directory of the open-source tools, skills, plugins, and integrations built for Hermes Agent, the open-source AI agent from Nous Research. Every project has its own page with a summary, live GitHub data, and its README, and the site adds guides for choosing between them.

Is Hermes Atlas a general developer tools directory?

No. A project is listed only if it is built for or integrated with Hermes Agent. Cross-platform tools are included when they support Hermes Agent directly, for example a skills manager that works with Claude Code, Codex, and Hermes Agent.

How do I find tools and skills to add to my Hermes agent?

Browse or search the ecosystem catalog by category, start from the Skills Hub or the curated lists, or describe what you want to build on use cases. You can also ask the Ask the Atlas chat on any page, or let your agent search the catalog through the hermes-atlas MCP server.

How do I get my tool listed on Hermes Atlas?

Open a Suggest a Repo issue on GitHub with the repository URL. Automation fetches the metadata, runs a basic security check, and opens a pull request, which a maintainer reviews against the inclusion criteria. Listing is free.

Does Hermes Atlas cost anything?

No. The directory, guides, and Ask the Atlas chat are free to use, with no account or sign-up. Suggesting a project for the catalog is also free.

How do I contact the Hermes Atlas team?

Open a GitHub issue for listings, corrections, or bugs; that is the fastest route. You can also reach the maintainer, Kevin Simback, at x.com/ksimback.

How current is the data?

GitHub star counts are refreshed daily, project pages are rebuilt automatically whenever the catalog changes, and a project's summary is regenerated when its README changes. Repositories that are deleted or renamed upstream are caught by automated catalog health checks.
