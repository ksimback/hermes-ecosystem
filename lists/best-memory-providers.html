For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal layer for managing User, Session, and Agent states via temporal reasoning. It is available as an Apache-2.0 self-hosted server or a managed cloud service, utilizing multi-signal retrieval to maintain context.

volcengine / OpenViking

OpenViking is an AGPL-3.0 context database that organizes agent memory as a virtual filesystem using viking:// URIs. It employs a three-tier loading strategy to achieve a 91% token reduction and provides observable retrieval trajectories for debugging.

topoteretes / cognee

This platform enables persistent long-term memory by building self-hosted knowledge graphs that combine vector embeddings with graph-based reasoning. It supports integration through Python, Rust, and TypeScript clients to facilitate complex search and discovery.

garrytan / gbrain

Gbrain functions as an opinionated agent brain that extracts typed entity edges to create a self-wiring knowledge graph. It generates synthesized prose answers featuring citations and gap analysis while ensuring data isolation through multi-user scoped access.

supermemoryai / supermemory

An official Hermes provider, this engine sustains sub-300ms recall at scales exceeding 100B tokens per month using a custom vector graph engine. It features automated fact extraction and byte-level deduplication to provide a 100% prompt-cache discount.

vectorize-io / hindsight

Hindsight provides long-term retain, recall, and reflect workflows compatible with over 25 LLM providers. It offers flexible deployment via Docker, Kubernetes, or managed cloud, supported by client libraries for Python, Node.js, and Go.

plastic-labs / honcho

This FastAPI-based library serves as the foundation for stateful agents by extracting conclusions from conversation history for reasoning-first memory. It supports managed and self-hosted Docker Compose deployments with dedicated Python and TypeScript SDKs.

campfirein / byterover-cli

This official provider implements memory as a git-like repository, offering version control features such as branching and merging over a markdown context tree. It utilizes a 5-tier retrieval system to achieve sub-100ms response times across 20 supported LLM providers.

mnemosyne-oss / mnemosyne

Mnemosyne is a zero-dependency memory system that uses a single SQLite database for local data storage and sub-millisecond performance. It supports the Model Context Protocol (MCP) for integration with tools like Cursor and Claude Code.

ClaudioDrews / memory-os

This seven-layer memory system utilizes a local infrastructure of Docker, Qdrant, Redis, and SQLite to manage persistent vector search and structured facts. It features a Ground Truth hierarchy to ensure agents prioritize specific injected context.

greyhaven-ai / autocontext

Autocontext is a recursive harness that produces filesystem-first artifacts like playbooks and context bundles to assist with complex tasks. It features outcome-gated promotion and ablation-backed attribution to validate improvements in context quality.

MemTensor / memmy-agent

This local memory hub provides a shared, fully controlled context across multiple agents including Claude Code and Hermes. It offers a desktop application, TUI, and an OpenAI-compatible API to manage local memory via a dedicated CLI.

stephenschoettler / hermes-lcm

This plugin provides a lossless, DAG-based context engine for Hermes Agent that ensures no messages are lost. It utilizes a local SQLite store with FTS metadata and includes specialized tools for searching and expanding compacted material.

elkimek / honcho-self-hosted

Honcho enables private, cross-session memory for Hermes Agent through a self-hosted backend. It supports any OpenAI-compatible LLM or local inference server and includes an automated setup script for Docker, PostgreSQL, and Redis.

Signet-AI / signetai

This local-first identity and memory layer offers portable state across Hermes Agent and other major clients with a 97.6% LongMemEval accuracy. It allows users to import data from external sources like Obsidian, Discord, and GitHub to build agent knowledge.

plur-ai / plur

Plur serves as a shared memory layer that stores data as human-readable YAML engrams on a local disk. It employs a hybrid search strategy combining BM25 and local embeddings to facilitate retrieval across multiple agent tools.

yoloshii / ClawMem

ClawMem is an on-device context engine that operates entirely locally without cloud dependencies or API keys. It integrates via MCP and plugins, using hybrid retrieval involving both vector search and BM25.

EfficientContext / ContextPilot

This optimization tool reduces prefill latency by 1.5–3× and saves up to 36% in tokens through block reordering and deduplication. It provides native plugin support for the Hermes Agent ecosystem to accelerate long-context inference.

Sibyl-Labs / Sibyl-Memory

Sibyl-Memory is a file-based, long-term memory system that avoids vector databases and embeddings in favor of SQLite with FTS5 search. It is delivered as a five-package plugin family, including a dedicated Hermes adapter and MCP server.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin provides explainable retrieval by attaching a 'why_retrieved' tag to every recalled result. It features a self-directing loop to resolve knowledge gaps and supports owner-scoping for multi-user environments.

yepyhun / Brainstack

Brainstack acts as a memory kernel stack that integrates Hindsight, Graphiti, and MemPalace into a single owner. It manages state using SQLite, Kuzu, and Chroma to provide agents with purpose-built evidence packets for each query.

amanning3390 / flowstate-qmd

This anticipatory memory system prefetches context by monitoring agent session logs to populate a local cache. It uses SQLite-vec and GGUF models to provide an MCP-native server for coding agent clients.

ccf / agentcairn

AgentCairn enables cross-project memory by using a user's Obsidian vault as the primary source of truth. It stores memory as inspectable Markdown files and utilizes DuckDB as a replaceable retrieval cache.

Perseus-Computing-LLC / perseus

Perseus resolves live workspace state into verified facts before the context window opens, resulting in up to 94% fewer prompt tokens. It functions as a local-first MCP server that renders workspace state into specific context files like AGENTS.md.

generalbusiness-ai / keep

This plugin provides reflective memory using semantic search, BM25 full-text indexing, and ranked graph traversal. It features automated indexing for codebases and multimedia with OCR support, utilizing edge tags to create navigable, bidirectional relationships between notes.

alias8818 / hermes-tool-slimmer

Designed to reduce prompt token overhead, this tool uses local BM25 ranking to select relevant tool schemas for Hermes Agent v0.14.0. It includes a dedicated dashboard for tracking estimated schema token savings and supports native tool search.

Ladybug-Memory / hermes-memory-plugin

This local-only provider uses a single .lbdb embedded graph database file and importance-weighted recall to surface high-priority memories during context prefetch. It supports BM25 keyword search, named graph relationships, and optional GLiNER2 entity extraction.

conorbronsdon / claude-context-os

A Git-backed context layer that stores project state, identity, and decision logs in plain Markdown files. It facilitates session handoffs and checkpoints through hash-checked proposals and provides adapters for Hermes, Claude Code, and other coding agents.

MukundaKatta / hermes-agentmemory

This episodic memory plugin features a pull-model architecture that supports real, immediate event deletion and an on-demand summarizer. It provides a trace.jsonl audit log for every memory operation to ensure transparency in prefetch operations.

piprail / piprail

This SDK and MCP server enables AI agents to pay for services and APIs to charge for access using USDC and stablecoins across 29 chains. It integrates with Hermes to settle payments directly to wallets with 0% transaction fees.

stepanov1975 / hermes-local-knowledge

This plugin indexes local skills, scripts, runbooks, and MCP server configurations for capability routing. It offers tools for artifact search and graph neighbor traversal, using feedback to improve local routing hints.

yonro / hermes-xmemo-plugin

A durable cross-session memory provider that utilizes a local SQLite reliability layer and a write outbox. It features pre-turn context injection and session-end snapshots alongside tools for searching and updating state.

futurebrowser / hermes-exabase-plugin

This plugin integrates Exabase M-1 for self-organizing long-term memory within Hermes Agent. It supports configurable query expansion and result reranking to optimize the retrieval of manually stored or searched memories.

visorcraft / MongrelDB-Hermes

An AI-native memory solution offering AES-256-GCM encryption at rest and multiple retrieval methods including HNSW ANN and FM-index. It can be deployed via native Rust FFI or as an HTTP daemon and includes MinHash deduplication.

sourcevault-ai / sourcevault-code-tools

This plugin provides private local code memory for repositories, requiring a local SourceVault server for indexing and vector storage. It adds deterministic slash commands and LLM-callable tools for semantic search, file reads, and grounded Q&A.

penfieldlabs / hermes-penfield

This provider offers 17 tools for memory management and knowledge graph traversal using a hybrid search of BM25, vector, and graph methods. It also features automatic context checkpointing during message compression.

conorbronsdon / agent-memory-kit

This toolkit provides a file-based curation loop that identifies data rot and contradictions within agent memory using specialized 'rot' and 'lint' curators. It utilizes a git-backed directory for versioned markdown storage and offers five slash commands for capturing, recalling, and reviewing evidence-cited diffs.
