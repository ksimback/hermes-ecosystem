For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal layer for managing multi-level states across users, sessions, and agents. It features temporal reasoning and multi-signal retrieval, available as an Apache-2.0 self-hosted server, OSS SDK, or managed cloud service.

volcengine / OpenViking

OpenViking is an AGPL-3.0 context database that organizes agent memory as a virtual filesystem using viking:// URIs. It utilizes a three-tier loading system to achieve a 91% token reduction and provides observable retrieval trajectories for debugging context paths.

supermemoryai / supermemory

This memory engine provides sub-300ms recall for Hermes Agents using a custom vector graph engine and byte-level deduplication. It automates fact extraction and user profiling while integrating with external data sources like Google Drive, Notion, and GitHub.

garrytan / gbrain

Serving as an opinionated brain for Hermes Agents, this project features a self-wiring knowledge graph with typed edges to synthesize answers with citations. It is designed for multi-user team environments through the use of scoped access controls.

vectorize-io / hindsight

Hindsight implements long-term retain, recall, and reflect workflows to create agent memory that learns over time. It is compatible with over 25 LLM providers and supports Python, Node.js, Go, and CLI clients for both hosted and self-hosted deployments.

plastic-labs / honcho

This memory library enables stateful agents through a FastAPI server that supports hybrid search and prompt-ready context injection. It serves as the upstream library for specialized Hermes wrappers and provides both Python and TypeScript SDKs.

campfirein / byterover-cli

Operating under the Elastic License 2.0, this provider treats memory as a git repository with versioning features like commit, branch, and merge. It utilizes a 5-tier retrieval system to achieve sub-100ms performance and includes an interactive TUI for managing markdown context trees.

mnemosyne-oss / mnemosyne

Mnemosyne is a zero-dependency memory system for Hermes Agents that delivers sub-millisecond performance using a single SQLite database. It supports the Model Context Protocol (MCP) via stdio or SSE and includes a dedicated Python SDK.

ClaudioDrews / memory-os

This seven-layer memory system utilizes Qdrant, Redis, and SQLite to manage persistent vector search and structured facts. It employs a Ground Truth hierarchy to ensure agents prioritize specific injected context and includes an auto-curated wiki.

greyhaven-ai / autocontext

This recursive harness improves agent performance on complex tasks through outcome-gated promotion of context bundles and playbooks. It integrates with MCP clients and OpenAI-compatible endpoints via Python and TypeScript implementations.

stephenschoettler / hermes-lcm

This plugin provides lossless context management for Hermes Agents using a SQLite-backed message store with full-text search metadata. It builds depth-aware summary nodes in a hierarchical DAG, allowing agents to search and expand compacted material without losing messages.

elkimek / honcho-self-hosted

This project enables private, cross-session persistence for Hermes Agents by providing a self-hosted backend for the Honcho library. It includes automated setup scripts for Docker, PostgreSQL, and Redis, supporting any OpenAI-compatible LLM provider.

Signet-AI / signetai

Signet-AI provides a local-first identity and memory layer that enables portable state across Hermes Agent and other MCP clients. It achieves a 97.6% LongMemEval answer accuracy and supports data imports from platforms like Obsidian, Discord, and GitHub.

plur-ai / plur

Plur is a shared memory layer for multi-agent systems that stores data locally as human-readable YAML engrams. It utilizes hybrid retrieval combining BM25 and local embedders to integrate with tools like Claude Code and Cursor.

yoloshii / ClawMem

ClawMem is an on-device context engine that operates locally without the need for API keys or cloud dependencies. It employs hybrid retrieval, including vector search and BM25, to provide memory through MCP and agent plugins.

EfficientContext / ContextPilot

ContextPilot optimizes long-context inference by using block reordering and deduplication to enable prefix reuse. This approach reduces prefill latency by 1.5–3× and saves up to 36% in tokens for Hermes Agent and OpenClaw ecosystems.

Sibyl-Labs / Sibyl-Memory

Sibyl-Memory is a file-based long-term memory system that uses SQLite with FTS5 search instead of vector databases. It features a five-package plugin family, including a dedicated Hermes adapter and a LangGraph BaseStore.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin provides explainable retrieval by tagging every recalled memory with a reason for its selection. It supports embedded in-process operation and includes features for contradiction tracking and owner-scoping in multi-user environments.

yepyhun / Brainstack

Brainstack is a memory kernel stack that integrates Hindsight, Graphiti, and MemPalace into a single memory owner for Hermes. It manages state using SQLite, Kuzu, and Chroma to deliver purpose-built evidence packets to the agent for each query.

amanning3390 / flowstate-qmd

Flowstate-qmd features an anticipatory cache that prefetches context by monitoring agent session logs. It utilizes SQLite-vec and GGUF models for local-first storage and provides an MCP-native server for automated configuration.

ccf / agentcairn

Agentcairn offers cross-project memory for coding agents by using an Obsidian vault as the primary source of truth. It stores memory as inspectable Markdown files and utilizes DuckDB as a replaceable retrieval cache.

generalbusiness-ai / keep

Keep provides reflective memory through semantic search, BM25 full-text indexing, and ranked graph traversal. It automatically indexes codebases and multimedia while using edge tags to create bidirectional relationships between notes.

Perseus-Computing-LLC / perseus

Perseus resolves live workspace state into verified facts before the context window opens, rendering them into files like AGENTS.md. It includes a Rust-based MCP server for persistent semantic memory and aims to reduce prompt tokens by 94%.

alias8818 / hermes-tool-slimmer

This tool reduces Hermes Agent prompt overhead by using local BM25 ranking to select relevant tool keywords. It is compatible with Hermes Agent v0.14.0 and includes a dashboard to track estimated schema token savings.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin utilizes an embedded .lbdb graph database to manage agent memory with a built-in 1-10 importance ranking system. It prioritizes high-value information during context prefetch using BM25 keyword search and optional GLiNER2 entity extraction.

MukundaKatta / hermes-agentmemory

Designed as a pull-model episodic memory provider, this plugin features an on-demand summarizer and a trace.jsonl audit log for tracking all prefetch operations. It distinguishes itself by supporting immediate, real event deletion to prevent persistent summaries from affecting future recall.

yonro / hermes-xmemo-plugin

This provider enables cross-session AI memory through pre-turn context injection and session-end snapshots. It ensures reliability via a local SQLite layer and a write outbox, offering dedicated tools for searching, remembering, and updating agent state.

piprail / piprail

This SDK and MCP server allows Hermes agents to handle financial transactions using USDC and stablecoins across EVM, Solana, and eight other chain families. It facilitates an autonomous payment model where APIs can charge for services and agents can pay for themselves directly.

stepanov1975 / hermes-local-knowledge

This plugin focuses on local capability indexing by routing questions to entire artifacts instead of using standard chunk-based RAG. It registers five native tools for knowledge retrieval and supports automated tool-routing note generation through model calls.

futurebrowser / hermes-exabase-plugin

Integrating Exabase M-1, this plugin provides self-organizing long-term memory for agents with support for manual memory storage. It enhances retrieval accuracy through configurable query expansion and result reranking.

visorcraft / MongrelDB-Hermes

This memory provider prioritizes security with default AES-256-GCM encryption at rest and offers flexible execution via Rust FFI or an HTTP daemon. It combines HNSW ANN, sparse, and FM-index retrieval methods to manage long-term agent data.

sourcevault-ai / sourcevault-code-tools

This plugin serves as a private local memory for code repositories, enabling semantic and literal searches over localhost. It supports grounded Q&A by providing specific file-and-line citations for its responses.

penfieldlabs / hermes-penfield

Penfield offers a suite of 17 tools for memory management and knowledge graph traversal using a hybrid search of BM25, vector, and graph methods. It also features automatic context checkpointing to preserve information during message compression.
