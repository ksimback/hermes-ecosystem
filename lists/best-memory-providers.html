Best Memory Providers for Hermes Agent

The top community-built memory and context management tools for Hermes Agent, ranked by GitHub stars. Memory is what makes Hermes self-improving — these tools extend its built-in recall with long-term semantic memory, graph-based retrieval, and cross-session persistence.

For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

Mem0 is a universal memory layer for AI agents and an official Hermes Agent memory provider, available as a managed cloud platform or self-hosted open-source software under Apache-2.0. It supports semantic, keyword, and entity-based retrieval, with SDKs, a CLI, and a self-hosted server.

vectorize-io / hindsight

Hindsight structures agent memory around retain, recall, and reflect operations for long-term memory workflows. It can be deployed with Docker, pip, or Kubernetes and supports hosted and local LLM providers.

volcengine / OpenViking

OpenViking is an open-source context database and official Hermes Agent memory provider that organizes agent context as browsable files and directories. It supports scoped search and retrieval, with L0, L1, and L2 tiers for loading context.

topoteretes / cognee

Cognee is an open-source memory platform for agents that structures text as entities, relationships, and searchable chunks. Custom data models and ontologies, along with plugins and MCP, provide ways to shape and connect that memory.

supermemoryai / supermemory

Supermemory is a memory engine and API, and an official Hermes Agent memory provider, that extracts conversation facts and handles contradictions and automatic forgetting. It connects to services including Google Drive, Gmail, Notion, OneDrive, and GitHub, and processes PDFs, images, videos, and code.

garrytan / gbrain

Gbrain is an opinionated brain for OpenClaw and Hermes Agent that stores facts with provenance and supports corrections and withdrawal. Memory can be shared across agents while transient task state stays local, with optional semantic search, synthesis, and background enrichment.

plastic-labs / honcho

Honcho is a memory library for building stateful agents that tracks peers, sessions, and messages over time. It supports managed, local, and self-hosted deployments, and includes Python and TypeScript SDKs.

campfirein / byterover-cli

ByteRover CLI treats memory as a Git repo, managing a plain Markdown context tree with Git-like commit, branch, and merge operations. Its five-tier retrieval includes four non-LLM tiers described as sub-100ms, and it offers an interactive TUI and REPL.

mnemosyne-oss / mnemosyne

Mnemosyne is a SQLite-backed memory layer for Hermes agents, described as zero-dependency and sub-millisecond, with one pure-Python dependency. It integrates through MCP, native providers, or a Python SDK; BEAM results are reported for v3.0.0, while LongMemEval is pending.

moorcheh-ai / memanto

Memanto extracts and consolidates memories across agents, reconciles conflicting information, and manages forgetting. It also supports memory exchange through the Open Knowledge Format.

ClaudioDrews / memory-os

Memory OS is a seven-layer memory system for Hermes Agent that includes vector search and structured facts. It uses local infrastructure with Docker, Qdrant, Redis, and SQLite, and a Ground Truth hierarchy to prioritize injected context.

greyhaven-ai / autocontext

Autocontext is a recursive self-improving context harness that runs tasks against evaluation, keeps useful lessons, and discards dead ends. It leaves traces, reports, and playbooks to support agents on complex tasks.

stephenschoettler / hermes-lcm

This Hermes Agent plugin persists messages in a SQLite store organized as a hierarchical DAG. Its lcm_grep and lcm_recall tools help recover details from past context.

vshulcz / deja-vu

deja-vu searches session histories across agents and projects, including sessions already on disk. It can also resume a session or continue it in another agent, and runs locally without a model or server.

elkimek / honcho-self-hosted

This project lets Hermes Agent use a self-hosted Honcho backend for private memory across sessions. It supports OpenAI-compatible providers and local inference servers, with an automated setup script for Docker, PostgreSQL, and Redis.

Signet-AI / signetai

Signet provides a local-first layer for agent identity, memory, and secrets, with portable state across supported agent harnesses. It connects through hooks, plugins, or extensions and includes a dashboard for browsing memory and asking questions.

plur-ai / plur

plur stores shared agent memory as plain-text YAML engrams and supports local search after a one-time model download, with keyword fallback. Its README reports 95.6% R@5 on LongMemEval-S (N=500).

yoloshii / ClawMem

ClawMem is an on-device memory and context engine that combines BM25, vector search, rank fusion, and cross-encoder reranking. It can generate session handoffs and capture decisions and preferences, with integrations through hooks, MCP, and native agent plugins.

Sibyl-Labs / Sibyl-Memory

Sibyl-Memory keeps long-term agent memory in a local SQLite file, using FTS5 search and a five-tier schema without a vector database or embeddings. Its package family includes an SDK, CLI, Hermes adapter, MCP server, and LangGraph BaseStore.

EfficientContext / ContextPilot

ContextPilot optimizes context ordering for cache-aware scheduling, deduplication, and prefix-cache sharing, including for text and multimodal context. It integrates with Hermes Agent as well as vLLM, SGLang, llama.cpp, and OpenClaw.

yantrikos / yantrikdb-hermes-plugin

This Hermes memory plugin uses an embedded backend by default, with an HTTP backend also available. Its recall results include a why_retrieved reason, and it supports memory canonicalization and contradiction tracking.

JanYork / llm-wiki-cli

llm-wiki-cli is an agent-driven CLI for recalling, maintaining, and evolving persistent knowledge across sessions. It builds a source-grounded Wiki with citations and history without requiring embeddings or a vector database.

ccf / agentcairn

agentcairn stores durable, cross-project memory as inspectable Markdown files with frontmatter metadata, using an Obsidian vault as the source of truth. A local DuckDB cache supports hybrid search and retrieval, while MCP servers and host-specific plugins connect it to coding agents.

amanning3390 / flowstate-qmd

flowstate-qmd anticipates context needs by watching agent session logs and prefetching context into a cache. It uses local SQLite-vec storage and GGUF models via node-llama-cpp, and provides an MCP-native server with automated configuration for major coding-agent clients.

yepyhun / Brainstack

Brainstack brings Hindsight, Graphiti, and MemPalace together under a single memory owner, with SQLite, Kuzu, and Chroma for state and retrieval management. It prepares a purpose-built evidence packet for the agent on each query.

generalbusiness-ai / keep

Keep combines semantic search with BM25 full-text retrieval and ranked graph traversal, while automatically indexing codebases, URLs, and multimedia with OCR support. Its edge tags connect stored notes through navigable, bidirectional relationships.

aliasocracy / hermes-tool-slimmer

Hermes Tool Slimmer reduces tool-schema token overhead through local keyword-based ranking and Tool Search support. It integrates as middleware on Hermes 0.19+ without patching Hermes core, and includes a dashboard for monitoring savings and managing tool configurations.

conorbronsdon / agent-context-os

Agent Context OS provides a Git-backed context and workflow layer for Claude Code, Codex, and other listed agents. Its workflows cover migration, handoffs, and memory proposals, while integrations remain opt-in rather than enabled automatically.

Ladybug-Memory / hermes-memory-plugin

This local-only Hermes plugin stores memory in a single .lbdb embedded graph database file and supports BM25 keyword search with named relationships between entries. Its importance-weighted recall surfaces higher-priority memories during context prefetch.

stepanov1975 / hermes-local-knowledge

Hermes Local Knowledge indexes configured local sources and selected Hermes runtime sources for capability lookup and routing. It registers five tools for search, retrieval, traversal, feedback, and usage reports, along with three Hermes lifecycle hooks.

MukundaKatta / hermes-agentmemory

Hermes AgentMemory is a pull-model episodic memory plugin with on-demand summarization and a trace.jsonl audit log of prefetch operations. It also supports immediate event deletion, so deleted events are not retained as persistent summaries for future recall.

hermes-labs-ai / hermes-blind

Hermes Blind extracts a session's original goal from its first user turn, with goals, first-sentence, and full extraction modes. It skips tool output and other non-user-turn records, and uses neither a summarizing model nor an external service.

piprail / piprail

Piprail provides a TypeScript SDK for x402 payments and an MCP server for budget-bound agent wallets. It operates without a backend, database, or API keys.

yonro / hermes-xmemo-plugin

The Hermes XMemo plugin runs inside Hermes and communicates with XMemo over HTTPS to provide durable cross-session memory with semantic search. It supplies ranked, bounded context recall before a turn and includes a local SQLite reliability layer.

futurebrowser / hermes-exabase-plugin

The Hermes Exabase plugin integrates Exabase M-1 for self-organizing long-term agent memory. It provides tools for searching and manually storing memories, with configurable query expansion and result reranking for retrieval.

sourcevault-ai / sourcevault-code-tools

SourceVault Code Tools provides private local code memory for repositories, including semantic search, file reads, and grounded Q&A. Its slash commands support search, file reads, context, and Q&A across Hermes CLI, Telegram, and Hermes Desktop; it also includes repo sync and indexed git-history search commands.

visorcraft / MongrelDB-Hermes

MongrelDB-Hermes provides long-term memory for Hermes Agent, with AES-256-GCM encryption at rest enabled by default. It offers dense HNSW, sparse, and FM-index retrieval, and can run through native Rust FFI or an HTTP daemon.

penfieldlabs / hermes-penfield

Penfield provides Hermes memory tools for managing memories and traversing knowledge graphs. Its hybrid search combines BM25, vector, and graph methods, and it can checkpoint context automatically during message compression.

conorbronsdon / agent-memory-kit

Agent Memory Kit helps curate agent memory stored in plain Markdown, producing reviewable JSON diffs rather than using a database. Its rot and lint curators flag stale or conflicting facts, while a local Git repository tracks changes and supports reverting them.
