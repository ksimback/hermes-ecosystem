For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal layer for managing User, Session, and Agent states through temporal reasoning and multi-signal retrieval. It is available as an Apache-2.0 self-hosted server, an OSS SDK, or a managed cloud service.

supermemoryai / supermemory

This engine features a custom vector graph system that sustains sub-300ms recall at scales exceeding 100B tokens per month. It integrates automated fact extraction and byte-level deduplication with connectors for platforms including Google Drive, Notion, and GitHub.

volcengine / OpenViking

An AGPL-3.0 context database that utilizes a virtual filesystem structure with viking:// URIs and tiered hierarchical loading. It provides observable retrieval trajectories for debugging and has demonstrated a 91% token reduction on LoCoMo10 benchmarks.

garrytan / gbrain

This opinionated agent brain extracts entity relationships without LLM calls and provides synthesized answers featuring citations and gap analysis. It is designed for institutional memory, supporting multi-user environments with scoped data access.

vectorize-io / hindsight

Hindsight implements long-term retain, recall, and reflect workflows to help agents learn over time. It provides an LLM wrapper for existing agents alongside dedicated Python and Node.js client SDKs.

plastic-labs / honcho

This library enables stateful agents through a FastAPI server that supports hybrid search and prompt-ready context injection. It serves as the upstream foundation for self-hosted Hermes memory implementations and offers both Python and TypeScript SDKs.

campfirein / byterover-cli

Operating under the Elastic License 2.0, this provider manages context as a git-like repository with versioning features such as commit, branch, and merge. It achieves sub-100ms performance using a 5-tier retrieval system and includes an interactive TUI powered by React/Ink.

mnemosyne-oss / mnemosyne

A zero-dependency memory system that utilizes a single SQLite database to achieve sub-millisecond performance. It supports the Model Context Protocol (MCP) via stdio or SSE and includes a Python SDK for direct operations.

ClaudioDrews / memory-os

This seven-layer system manages persistent memory via Qdrant and structured facts to create an auto-curated wiki for the agent. It relies on local infrastructure including Docker, Redis, and SQLite to maintain a Ground Truth hierarchy for context prioritization.

greyhaven-ai / autocontext

This recursive harness helps agents complete complex tasks by generating filesystem-based traces, reports, and playbooks. It supports multiple providers, including local models and OpenAI-compatible APIs, via Python and TypeScript CLI surfaces.

stephenschoettler / hermes-lcm

A lossless context management plugin that uses a DAG-based engine to ensure no messages are lost during agent operations. It features a SQLite-backed store with FTS metadata and builds depth-aware summary nodes for hierarchical searching.

elkimek / honcho-self-hosted

This project provides a self-hosted backend for the Honcho library to enable private, cross-session persistence for Hermes Agent. It includes automated setup scripts for Docker, PostgreSQL, and Redis, supporting any OpenAI-compatible or local inference server.

Signet-AI / signetai

This local-first identity, memory, and secrets layer provides portable state across Hermes Agent, Claude Code, and MCP clients. It imports data from Obsidian, Discord, and GitHub, achieving a 97.6% LongMemEval answer accuracy.

plur-ai / plur

This shared memory layer utilizes an open engram YAML format to store human-readable memory on local disks. It supports MCP tools including Claude Code and Cursor through a local-first retrieval stack using BM25 and hybrid search.

yoloshii / ClawMem

This on-device context engine operates locally without API keys or cloud dependencies. It integrates via MCP, Claude Code hooks, and plugins using a hybrid retrieval method involving BM25 and vector search.

EfficientContext / ContextPilot

This optimization tool accelerates long context LLM inference through block reordering and deduplication for prefix reuse. It features native plugin support for the Hermes Agent and OpenClaw ecosystems to reduce prefill latency and token usage.

Sibyl-Labs / Sibyl-Memory

This file-based, long-term memory architecture uses SQLite with FTS5 search instead of vector databases or embeddings. It is delivered via a five-package plugin family including an SDK, CLI, MCP server, Hermes adapter, and a LangGraph BaseStore.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin provides explainable retrieval by attaching why_retrieved tags to every recall. It supports in-process embedded mode by default and includes features for contradiction tracking and recency ranking.

yepyhun / Brainstack

This memory kernel stack integrates Hindsight, Graphiti, and MemPalace into a single memory owner. It manages state and retrieval using SQLite, Kuzu, and Chroma to provide agents with purpose-built evidence packets per query.

amanning3390 / flowstate-qmd

This anticipatory memory system uses RAG and vector search to prefetch context by monitoring agent session logs. It is an MCP-native server that utilizes local-first storage via SQLite-vec and GGUF models.

generalbusiness-ai / keep

This reflective memory system uses semantic search with BM25 full-text and ranked graph traversal. It automates indexing for URLs, codebases, and multimedia with OCR support, using edge tags to create bidirectional relationships.

Perseus-Computing-LLC / perseus

This layer resolves live workspace state into verified facts to reduce prompt tokens before the context window opens. It supports MCP-native integration via stdio or SSE and pairs with Perseus Vault for encrypted, persistent memory.

ccf / agentcairn

This daemonless memory solution stores information as inspectable Markdown files to allow users to use an Obsidian vault as a source of truth. It uses DuckDB as a replaceable retrieval cache and supports Claude Code and Codex.

alias8818 / hermes-tool-slimmer

This tool reduces Hermes Agent tool-schema overhead through keyword selection and local BM25 tool ranking. It includes a dashboard for tracking estimated schema token savings and is compatible with Hermes Agent v0.14.0.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin utilizes a single.lbdb embedded graph database to store memories. It features BM25-first retrieval and an importance ranking system from 1-10 to prioritize high-priority memories during context prefetch.

MukundaKatta / hermes-agentmemory

This pull-model episodic memory plugin supports real, immediate event deletion to prevent persistent summaries from affecting future recall. It includes a trace.jsonl audit log to track every memory operation.

yonro / hermes-xmemo-plugin

This provider enables durable cross-session AI memory through session-end snapshots and pre-turn context injection. It utilizes a local SQLite reliability layer and a write outbox to manage state updates.

piprail / piprail

This SDK and MCP server facilitates payments for APIs and AI agents using USDC and stablecoins across multiple chain families, including EVM and Solana. It integrates with Hermes to enable self-charging capabilities.

stepanov1975 / hermes-local-knowledge

This plugin indexes local capabilities such as scripts, runbooks, and MCP server configurations. It provides tools for knowledge search and neighbor traversal, with an optional feature for automatic tool-routing note generation.

futurebrowser / hermes-exabase-plugin

This plugin integrates Exabase M-1 to provide self-organizing long-term agent memory. It includes tools for manual memory storage and searching, alongside configurable query expansion and result reranking.

visorcraft / MongrelDB-Hermes

This AI-native memory solution provides AES-256-GCM encryption at rest and supports multiple execution modes via Rust FFI or an HTTP daemon. It offers HNSW ANN, sparse, and exact-text recall alongside MinHash dedup.

sourcevault-ai / sourcevault-code-tools

This local plugin provides private code memory for repositories, enabling semantic and literal code search. It supports grounded Q&A that includes specific file-and-line citations.

penfieldlabs / hermes-penfield

This provider offers 17 tools for memory management and knowledge graph traversal using hybrid search methods. It combines BM25, vector, and graph methods with automatic context checkpointing during message compression.
