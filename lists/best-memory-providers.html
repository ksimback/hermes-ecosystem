For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal memory layer with multi-level support for user, session, and agent states. It features temporal reasoning and multi-signal retrieval, available through a managed cloud, self-hosted server, or Apache-2.0 SDK.

volcengine / OpenViking

OpenViking is an official context database that organizes agent memory as a virtual filesystem using viking:// URIs and tiered loading. It achieves significant token reduction and task-completion gains by archiving sessions as editable Markdown files for efficient extraction.

vectorize-io / hindsight

Hindsight implements long-term retain, recall, and reflect workflows across more than 25 LLM providers and multiple storage backends. It provides client implementations for Python, Node.js, and Go, having achieved state-of-the-art performance on the LongMemEval benchmark.

topoteretes / cognee

This platform provides agents with persistent long-term memory by building self-hosted knowledge graphs from text, code, and conversations. It supports local extraction and embedding models to distill session lessons into searchable permanent memory without requiring LLM API keys.

supermemoryai / supermemory

An official memory provider that maintains auto-updated user profiles and supports multi-modal extraction from PDFs, images, and videos. It utilizes a custom vector graph engine to deliver sub-300ms recall and byte-level deduplication for high-volume token processing.

garrytan / gbrain

This opinionated agent brain combines keyword retrieval, semantic search, and a typed knowledge graph for synthesis with citations. It exposes memory to agents via MCP over Tailscale or local connections to facilitate structured reference extraction.

plastic-labs / honcho

Honcho is a memory library for building stateful agents, serving as the upstream foundation for the Hermes self-hosted wrapper. It is implemented as a FastAPI server and supports managed, local CLI, or Docker deployments for various AI clients.

campfirein / byterover-cli

This official provider manages memory as a git-like repository, offering version control features like branching and merging over a markdown context tree. It utilizes a 5-tier retrieval system to achieve sub-100ms performance across 20 supported LLM providers.

mnemosyne-oss / mnemosyne

Mnemosyne is a zero-dependency memory system for Hermes Agents that uses a single SQLite database for local storage. It features episodic compression for sub-linear storage growth and integrates via MCP, Python SDK, or OpenWebUI.

ClaudioDrews / memory-os

This system employs a seven-layer memory architecture including vector search on Qdrant and an auto-curated wiki. It uses a Ground Truth hierarchy to ensure agents prioritize injected context within a local infrastructure of Docker, Redis, and SQLite.

greyhaven-ai / autocontext

Autocontext is a recursive self-improving harness that provides filesystem-first artifacts like traces and context bundles. It supports Python and TypeScript surfaces to help agents manage complex tasks through MCP and OpenAI-compatible endpoints.

stephenschoettler / hermes-lcm

This plugin provides lossless context management for Hermes Agents using a hierarchical DAG and SQLite store for message persistence. It includes specific recall tools like lcm_grep and lcm_recall to ensure no message details are lost during agent operations.

vshulcz / deja-vu

This tool indexes existing session history from 34 different coding agents to enable millisecond lookups over months of past data. It operates directly on disk-based history and redacts keys and tokens during the indexing process.

elkimek / honcho-self-hosted

This self-hosted backend provides private cross-session memory for Hermes Agent using Docker, PostgreSQL, and Redis. It supports local inference servers and any OpenAI-compatible LLM provider for persistent state management.

plur-ai / plur

Plur implements a shared memory layer using plain-text YAML engrams stored on local disk. It utilizes an MCP server for multi-agent tool portability and performs hybrid retrieval through BM25 and local embeddings.

Signet-AI / signetai

This local-first identity and memory layer synchronizes state across Hermes Agent, Claude Code, and other clients with a reported 97.6% LongMemEval accuracy. It supports real-time data ingestion from platforms including Obsidian, Discord, and GitHub.

yoloshii / ClawMem

ClawMem is an on-device context engine that captures agent decisions and preferences using a local GGUF observer model. It functions without cloud dependencies or API keys, utilizing a retrieval pipeline of BM25, vector search, and cross-encoder reranking.

Sibyl-Labs / Sibyl-Memory

This five-package plugin family provides durable, file-based memory using a SQLite-backed hierarchical schema and FTS5 search. The architecture is notable for requiring zero vector databases and zero embedding models.

EfficientContext / ContextPilot

This optimization tool accelerates long-context inference by reordering text and multimodal context for prefix-cache sharing. It integrates with vLLM and llama.cpp to provide deduplication and cache-aware scheduling for Hermes Agent.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin features explainable retrieval by attaching a 'why_retrieved' tag to every recall result. It manages memory health by tracking contradictions, preventing duplicates through idempotent writes, and identifying knowledge gaps.

ccf / agentcairn

AgentCairn uses a user's Obsidian vault as the primary source of truth, storing memory as inspectable Markdown files with frontmatter metadata. It employs a local DuckDB cache for hybrid search and integrates with coding agents via MCP servers.

JanYork / llm-wiki-cli

This CLI tool enables agents to autonomously maintain persistent wikis complete with citations, links, and provenance. It stores data in SQLite with rebuildable Markdown projections and supports portable archives for merging wiki data.

amanning3390 / flowstate-qmd

Flowstate provides anticipatory memory by watching agent session logs to prefetch context into a local-first cache. Built for the Hermes 2026 Hackathon, it uses SQLite-vec and GGUF models to serve context via an MCP-native server.

yepyhun / Brainstack

Brainstack acts as a memory kernel that integrates Hindsight, Graphiti, and MemPalace into a single owner for Hermes Agent. It manages state using SQLite, Kuzu, and Chroma to deliver specific evidence packets for every agent query.

Perseus-Computing-LLC / perseus

This context layer resolves live workspace states into verified facts to reduce prompt token usage by up to 94%. It provides local-first session history tracking and supports MCP-native integration via stdio or SSE servers.

generalbusiness-ai / keep

This reflective memory system utilizes BM25 full-text search and ranked graph traversal to navigate stored notes. It features automated indexing for codebases and multimedia with OCR support, using edge tags to establish bidirectional relationships.

alias8818 / hermes-tool-slimmer

Designed for Hermes Agent v0.14.0, this tool reduces schema overhead through local BM25 tool ranking and native tool search support. It includes a dedicated dashboard for monitoring estimated token savings during agent operations.

conorbronsdon / claude-context-os

This Git-backed layer stores durable context in plain Markdown files rather than native agent memory for coding agents like Claude Code and Codex. It manages reviewed context updates through a system of hash-checked proposals and receipts.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin uses a single .lbdb embedded graph database to surface high-priority memories via a 1-10 importance ranking system. It combines BM25 keyword search with optional GLiNER2 entity extraction to manage named graph relationships.

MukundaKatta / hermes-agentmemory

This episodic memory plugin implements a pull-model that supports immediate event deletion and an on-demand summarizer. It provides a trace.jsonl audit log to track every prefetch and memory operation for increased transparency.

piprail / piprail

This SDK and MCP server enables agents to manage budget-bound wallets for x402 payments across EVM, Solana, and other chain families. It operates without a backend or API keys, allowing agents to pay for services using USDC and stablecoins.

stepanov1975 / hermes-local-knowledge

This plugin indexes local skills, runbooks, and MCP configurations to facilitate knowledge search and neighbor traversal. It supports automatic tool-OKF generation via detached model calls to streamline local capability routing.

yonro / hermes-xmemo-plugin

This provider enables cross-agent continuity by allowing agents to read memories from other connected sessions. It utilizes native lifecycle hooks for session snapshots and a local SQLite layer to ensure write outbox reliability.

futurebrowser / hermes-exabase-plugin

Integrating Exabase M-1, this plugin provides self-organizing long-term memory with tools for manual storage and search. It supports configurable query expansion and result reranking to optimize retrieval performance.

sourcevault-ai / sourcevault-code-tools

This plugin provides private local code memory for repositories through deterministic slash commands and LLM-callable tools. It requires a local SourceVault server to handle indexing, vector storage, and grounded Q&A.

visorcraft / MongrelDB-Hermes

This long-term memory solution features AES-256-GCM encryption at rest and supports HNSW ANN, sparse, and FM-index retrieval. It can be executed via native Rust FFI or as an HTTP daemon, incorporating MinHash deduplication for stored data.

penfieldlabs / hermes-penfield

This provider offers 17 specialized tools for memory management and knowledge graph traversal within the Hermes ecosystem. It utilizes a hybrid search architecture combining BM25, vector, and graph methods, while featuring automatic context checkpointing to preserve information during message compression.

conorbronsdon / agent-memory-kit

This lightweight, file-based toolkit focuses on memory hygiene by identifying 'rot' and contradictions within plain markdown files. It generates evidence-cited JSON diffs for manual review and leverages a local git repository to track or revert changes to the agent's knowledge base.
