For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal memory layer with multi-level support for User, Session, and Agent states. It features temporal reasoning and multi-signal retrieval, available via an OSS SDK, self-hosted server, or managed cloud.

volcengine / OpenViking

An official Hermes Agent memory provider that organizes context as a virtual filesystem using viking:// URIs. It utilizes tiered L0/L1/L2 loading to reduce token consumption and provides observable retrieval trajectories for debugging.

supermemoryai / supermemory

This official Hermes Agent memory provider uses a custom vector graph engine and hybrid search to combine RAG and memory. It features automated fact extraction, context fencing, and connectors for services like Google Drive, Gmail, and GitHub.

garrytan / gbrain

This opinionated brain for Hermes Agents provides synthesized answers complete with citations and gap analysis. It utilizes a self-wiring knowledge graph with typed edges and supports scoped access for multi-user teams.

vectorize-io / hindsight

This memory system supports long-term retain, recall, and reflect workflows. It is compatible with over 25 LLM providers and offers both hosted and self-hosted deployment options via Python, Node.js, Go, and CLI clients.

plastic-labs / honcho

This memory library serves as the upstream library for the elkimek/honcho-self-hosted wrapper. It provides a FastAPI server with Python and TypeScript SDKs, supporting hybrid search and prompt-ready context injection.

campfirein / byterover-cli

An official Hermes Agent memory provider that manages context trees using git-like version control via brv vc commit, branch, and merge. It features a 5-tier retrieval system and an interactive TUI/REPL interface.

mnemosyne-oss / mnemosyne

This zero-dependency memory system uses a single SQLite database to achieve sub-millisecond performance. It supports MCP via stdio or SSE and includes a Python SDK for direct memory operations.

ClaudioDrews / memory-os

This seven-layer memory system utilizes vector search and structured facts to manage persistent memory on Qdrant. It employs a Ground Truth hierarchy to ensure agents prioritize injected context.

greyhaven-ai / autocontext

This recursive self-improving context harness supports multiple providers, including Anthropic and OpenAI-compatible models. It provides Python and TypeScript CLI surfaces and generates traces, playbooks, and datasets from runs.

stephenschoettler / hermes-lcm

This lossless context management plugin uses a DAG-based engine and a SQLite-backed message store to ensure no message is lost. It builds depth-aware summary nodes in a hierarchical DAG and provides tools for searching and expanding compacted material.

elkimek / honcho-self-hosted

This self-hosted backend enables private cross-session memory for Hermes Agent. It supports any OpenAI-compatible LLM provider or local inference servers and includes an automated setup script for Docker, PostgreSQL, and Redis.

Signet-AI / signetai

This local-first layer manages identity, memory, and secrets to provide portable state across Hermes Agent and various MCP clients. It supports data imports from Obsidian, Discord, and GitHub and reports a 97.6% LongMemEval answer accuracy.

plur-ai / plur

This shared memory layer utilizes an open engram YAML format to store human-readable data locally. It features hybrid retrieval via BM25 and local embedders and integrates with MCP tools like Claude Code and Cursor.

yoloshii / ClawMem

Designed as an on-device context engine, this tool operates locally without cloud dependencies or API keys. It employs hybrid retrieval through vector search and BM25 and integrates via MCP and Claude Code hooks.

EfficientContext / ContextPilot

This optimization tool accelerates LLM inference by using block reordering and deduplication for prefix reuse. It reduces prefill latency by 1.5–3× and features native plugin support for the Hermes Agent and OpenClaw ecosystems.

Sibyl-Labs / Sibyl-Memory

This file-based, local-first architecture uses SQLite with FTS5 search instead of vector databases or embeddings. It is distributed as a five-package plugin family including an SDK, CLI, MCP server, Hermes adapter, and a LangGraph BaseStore.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin features embedded mode by default and provides explainable retrieval via a why_retrieved tag. It includes recency ranking, contradiction tracking, and owner-scoping for multi-user environments.

yepyhun / Brainstack

This memory kernel stack integrates Hindsight, Graphiti, and MemPalace into a single memory owner. It manages state and retrieval using SQLite, Kuzu, and Chroma to provide agents with purpose-built evidence packets.

amanning3390 / flowstate-qmd

This anticipatory memory system uses RAG and vector search to prefetch context by monitoring agent session logs. It utilizes local-first storage via SQLite-vec and GGUF models and provides an MCP-native server.

ccf / agentcairn

This daemonless memory system stores information as inspectable Markdown files to ensure user ownership. It uses DuckDB as a replaceable retrieval cache and supports Claude Code and Codex.

generalbusiness-ai / keep

This reflective memory solution uses semantic search with BM25 and ranked graph traversal. It features automated indexing for URLs, codebases, and multimedia with OCR support, using edge tags to create bidirectional relationships.

Perseus-Computing-LLC / perseus

This layer resolves live workspace state into verified facts to load only necessary context, potentially reducing prompt tokens by 94%. It supports stdio or SSE MCP servers and operates locally without requiring an account.

alias8818 / hermes-tool-slimmer

This tool reduces Hermes Agent tool-schema overhead through keyword selection and local BM25 tool ranking. It includes a dashboard for tracking estimated schema token savings and is compatible with Hermes Agent v0.14.0.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin utilizes a single.lbdb embedded graph database to manage memories. It features importance-weighted recall via a 1-10 ranking system and supports BM25 keyword search alongside optional GLiNER2 entity extraction.

MukundaKatta / hermes-agentmemory

This pull-model episodic memory plugin supports real, immediate event deletion to prevent persistent summaries from affecting future recall. It includes a trace.jsonl audit log to track every memory operation and utilizes an on-demand summarizer.

yonro / hermes-xmemo-plugin

This provider enables durable cross-session AI memory through pre-turn context injection and session-end snapshots. It maintains reliability via a local SQLite layer and a write outbox while providing tools for searching, remembering, and updating state.

piprail / piprail

This SDK and MCP server enables APIs to charge for themselves and AI agents to pay for themselves using USDC and stablecoins. It supports multiple chain families, including EVM and Solana, and integrates with Hermes.

stepanov1975 / hermes-local-knowledge

This plugin provides local capability indexing and routing by directing local questions to whole artifacts instead of using chunk RAG. It registers five native tools for knowledge search, retrieval, and feedback, with optional automated tool-routing note generation.

futurebrowser / hermes-exabase-plugin

This plugin integrates Exabase M-1 to provide self-organizing long-term agent memory. It includes tools for manual memory storage and searching, while supporting configurable query expansion and result reranking.

visorcraft / MongrelDB-Hermes

This AI-native long-term memory solution features AES-256-GCM encryption at rest by default. It supports HNSW ANN, sparse, and exact-text recall, and can be executed via a native Rust FFI or an HTTP daemon.

sourcevault-ai / sourcevault-code-tools

This plugin provides private, local code memory for repositories through semantic and literal code search. It runs locally over localhost and supports grounded Q&A featuring file-and-line citations.

penfieldlabs / hermes-penfield

This provider offers 17 tools for memory management and knowledge graph traversal. It employs a hybrid search method combining BM25, vector, and graph techniques, and includes automatic context checkpointing during message compression.
