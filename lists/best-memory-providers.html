For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This universal memory layer provides multi-level storage for user, session, and agent states using temporal reasoning and multi-signal retrieval. It is available as an official Hermes Agent provider through an Apache-2.0 self-hosted server, an OSS SDK, or a managed cloud service.

supermemoryai / supermemory

This memory engine utilizes a custom vector graph engine to deliver sub-300ms recall and byte-level deduplication for high-volume token processing. It unifies memory, RAG, and user profiles into a single API that supports multi-modal extraction from sources like Google Drive, Notion, and GitHub.

volcengine / OpenViking

An open-source context database that employs the viking:// protocol and tiered L0/L1/L2 loading to optimize token expenditure. It demonstrates significant task-completion gains and provides observable retrieval trajectories to assist in debugging agent memory workflows.

garrytan / gbrain

This opinionated agent brain constructs a self-wiring knowledge graph using typed edges to synthesize answers with citations and gap analysis. It is designed for local deployment using PGLite to maintain a structured and searchable memory architecture.

vectorize-io / hindsight

This system focuses on long-term memory through specialized retain, recall, and reflect workflows that allow agents to learn over time. It offers Python and Node.js SDKs alongside Docker-based deployment options for integrating persistent memory into agentic stacks.

plastic-labs / honcho

Serving as the upstream library for specialized Hermes wrappers, this library enables stateful agents through peer-centric modeling and background reasoning. It can be deployed as a managed service or a self-hosted FastAPI server with support for Python and TypeScript.

campfirein / byterover-cli

This provider treats memory like a git repository, offering version control features such as commits, branches, and merges over a markdown context tree. It features a 5-tier retrieval system with sub-100ms performance and an interactive TUI powered by React/Ink.

AxDSan / mnemosyne

This system provides a sub-millisecond AI memory architecture built on a standalone SQLite database with no external dependencies. It utilizes temporal knowledge graphs and episodic compression to manage agent context across various integrations and the Python SDK.

ClaudioDrews / memory-os

This seven-layer system organizes memory into a Ground Truth hierarchy that includes persistent Qdrant vector search, structured facts, and an auto-curated wiki. It relies on local infrastructure like Docker, Redis, and SQLite to ensure agents prioritize specifically injected context.

greyhaven-ai / autocontext

This recursive self-improving context harness uses filesystem-first traces and reports to help agents navigate complex tasks. It includes CLI tools for simulating and investigating tasks, supporting both Pi and MCP clients for context management.

stephenschoettler / hermes-lcm

A lossless context management plugin that uses a DAG-based engine to ensure no messages are lost within the agent's history. It stores data in SQLite with FTS metadata and builds depth-aware summary nodes to facilitate efficient searching and expansion of context.

elkimek / honcho-self-hosted

This self-hosted backend provides private cross-session memory for Hermes Agent using Docker, PostgreSQL, and Redis. It supports any OpenAI-compatible LLM provider or local inference servers for persistent state management.

plur-ai / plur

Plur offers a shared memory layer that stores data as plain-text YAML engrams for multi-agent systems. It enables local-first, zero-cost search and supports MCP tools like Claude Code and Cursor.

Signet-AI / signetai

Signet provides a local-first identity and secrets layer that ensures portable state across Hermes Agent and various MCP clients. Users can inspect, edit, and repair memory through a dedicated dashboard and retrieval inspection tools.

yoloshii / ClawMem

This on-device context engine uses hybrid retrieval combining BM25 and vector search without cloud dependencies. It captures agent decisions using a local GGUF observer model and integrates via MCP or Claude Code hooks.

EfficientContext / ContextPilot

ContextPilot optimizes long-context inference through block reordering and deduplication to enable prefix reuse. It reduces prefill latency by 1.5–3× and offers native plugin support for the Hermes Agent and OpenClaw ecosystems.

Sibyl-Labs / Sibyl-Memory

Sibyl-Memory is a file-based long-term memory system that utilizes SQLite with FTS5 search instead of vector databases. The five-package plugin family includes a specific Hermes adapter and a LangGraph BaseStore for local-first persistence.

yantrikos / yantrikdb-hermes-plugin

This plugin features explainable retrieval by attaching a 'why_retrieved' tag to every recalled item. It tracks contradictions via conflict and resolution primitives and supports both embedded in-process mode and HTTP backends.

amanning3390 / flowstate-qmd

Flowstate-qmd implements anticipatory memory by watching agent session logs to prefetch context into a cache. It uses SQLite-vec and GGUF models for local-first storage and provides an MCP-native server with automated configuration.

yepyhun / Brainstack

Brainstack integrates Hindsight, Graphiti, and MemPalace into a single memory owner for Hermes Agent. It manages state using SQLite, Kuzu, and Chroma to deliver purpose-built evidence packets for every agent query.

keepnotes-ai / keep

Keep provides reflective memory using semantic search, BM25 full-text, and ranked graph traversal. It features automated indexing for multimedia with OCR support and creates bidirectional relationships between notes using edge tags.

alias8818 / hermes-tool-slimmer

This tool reduces prompt token overhead by using local BM25 ranking to select relevant tool schemas. It includes a dashboard for tracking token savings and is compatible with Hermes Agent v0.14.0 native tool search.

Perseus-Computing-LLC / perseus

Perseus resolves live workspace state into verified facts to ensure agents load only the context they actually need. It implements the Model Context Protocol and supports encrypted persistent memory through the Perseus Vault.

ccf / agentcairn

This project provides long-term, cross-project memory for AI coding agents by storing data as inspectable Markdown files. It utilizes DuckDB as a replaceable retrieval cache and supports Claude Code and Codex.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin uses a single.lbdb embedded graph database to manage memories. It features an importance ranking system for prioritized recall and supports BM25 keyword search alongside optional GLiNER2 entity extraction.

MukundaKatta / hermes-agentmemory

This plugin implements a pull-model episodic memory system that supports immediate event deletion. It includes an on-demand summarizer and provides an audit trace of all memory operations via trace.jsonl.

yonro / hermes-xmemo-plugin

This provider enables durable, cross-session AI memory through semantic search. It utilizes a local SQLite reliability layer and outbox to support cross-agent continuity via user-approved memories.

piprail / piprail

This SDK and MCP server enables API charging for AI agents using USDC and stablecoins across various chain families, including EVM and Solana. It integrates with Hermes and other platforms like elizaOS and n8n.

futurebrowser / hermes-exabase-plugin

This plugin integrates Exabase M-1 to provide self-organizing long-term agent memory. It includes tools for manual memory storage and searching, with support for configurable query expansion and result reranking.

stepanov1975 / hermes-local-knowledge

This reusable plugin provides five native tools for searching, fetching, and reporting on artifacts. It supports indexing for skills, scripts, markdown documents, cron jobs, and MCP servers.

sourcevault-ai / sourcevault-code-tools

This plugin offers private local code memory for repositories, enabling semantic and literal code search. It runs locally over localhost and supports grounded Q&A with file-and-line citations.

visorcraft / MongrelDB-Hermes

This AI-native memory solution features AES-256-GCM encryption at rest and supports HNSW ANN, sparse, and exact-text recall. It also includes MinHash for near-duplicate detection and metadata/range filters.

penfieldlabs / hermes-penfield

This provider offers 17 tools for memory management and knowledge graph traversal. It utilizes hybrid search combining BM25, vector, and graph methods, and includes automatic context checkpointing during message compression.
