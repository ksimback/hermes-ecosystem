For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

An official Hermes Agent memory provider that offers a universal memory layer for User, Session, and Agent states. It supports multi-level memory with temporal reasoning and multi-signal retrieval, available as an OSS SDK, self-hosted server, or managed cloud.

supermemoryai / supermemory

An official Hermes Agent memory provider featuring a custom vector graph engine and sub-300ms recall. It provides RAG, user profiles, and multi-modal extraction for PDFs, images, and videos via a single API.

volcengine / OpenViking

An official Hermes Agent memory provider that uses a filesystem management paradigm to unify agent memories and skills. It utilizes viking:// URIs and tiered L0/L1/L2 loading to reduce token consumption.

garrytan / gbrain

A brain for the Hermes Agent that provides synthesis and gap analysis for queries. It features a self-wiring knowledge graph with typed edges and supports local deployment using PGLite.

vectorize-io / hindsight

A memory system designed for long-term retain, recall, and reflect workflows. It is available via Python and Node.js client SDKs and offers Docker-based deployment options.

plastic-labs / honcho

A memory library for building stateful agents that supports peer-centric modeling and background reasoning. It is available as a managed service or a self-hosted FastAPI server with Python and TypeScript SDKs.

campfirein / byterover-cli

An official Hermes Agent memory provider that manages a context tree using git-like version control. It features an interactive TUI and supports 20 LLM providers and 24 built-in agent tools.

AxDSan / mnemosyne

A zero-dependency, sub-millisecond memory system for Hermes Agents. It utilizes a single SQLite database and supports MCP, Python SDK, and bidirectional memory sync.

greyhaven-ai / autocontext

A recursive self-improving context harness that generates persistent playbooks and hints from iterative task runs. It distills successful behaviors into local-model training artifacts and exports CLI-first skills for Hermes integration.

stephenschoettler / hermes-lcm

A lossless context management plugin that uses a SQLite message store with FTS metadata. It provides agent tools for searching and expanding compacted material and includes optional redaction for sensitive patterns.

elkimek / honcho-self-hosted

A self-hosted backend for Honcho that enables private cross-session memory for the Hermes Agent. It supports local inference servers or any OpenAI-compatible LLM provider and includes a Docker, PostgreSQL, and Redis setup script.

plur-ai / plur

A shared memory layer for multi-agent systems that stores persistent knowledge as readable YAML engram files. It supports hierarchical scoping and integrates with Hermes Agent via plugins and MCP tools.

Signet-AI / signetai

A local-first layer for managing identity, memory, and secrets that provides portable context across multiple agent harnesses and MCP clients. It includes a dedicated dashboard for inspecting and repairing memory.

yoloshii / ClawMem

An on-device, local-first memory and context engine that operates without cloud dependencies or API keys. It uses hybrid retrieval via vector search and multi-graph traversal with a shared SQLite vault.

EfficientContext / ContextPilot

A context optimization plugin for Hermes Agent that uses block reordering and deduplication for prefix reuse. It aims to reduce prefill latency and token consumption during LLM inference.

yantrikos / yantrikdb-hermes-plugin

A self-maintaining plugin that provides explainable recall via why_retrieved tags. It includes contradiction tracking using resolution primitives and a built-in outcome ledger for agent-authored skills.

yepyhun / Brainstack

A memory kernel stack that integrates Hindsight, Graphiti, and MemPalace into a single owner. It manages state and retrieval using SQLite, Kuzu, and Chroma to provide evidence packets to the agent.

amanning3390 / flowstate-qmd

An anticipatory memory system that prefetches context by monitoring agent session logs. It uses local-first storage via SQLite-vec and provides an MCP-native server for coding agent clients.

keepnotes-ai / keep

A reflective memory system featuring semantic search with BM25 and ranked graph traversal. It supports automated indexing for codebases, URLs, and multimedia with OCR and bidirectional edge tags.

alias8818 / hermes-tool-slimmer

A tool to reduce Hermes Agent prompt token overhead through keyword selection and Tool Search support. It includes a dashboard for tracking estimated schema token savings and is compatible with Hermes Agent v0.14.0.

Ladybug-Memory / hermes-memory-plugin

A local-only plugin that uses a single.lbdb embedded graph database for storage. It features importance-weighted recall to surface high-priority memories and supports BM25 keyword search.

MukundaKatta / hermes-agentmemory

A pull-model episodic memory plugin that supports real, immediate event deletion and provides a trace.jsonl audit log for every memory operation. It uses an on-demand summarizer.

yonro / hermes-xmemo-plugin

A memory provider that offers durable cross-session AI memory with semantic search and provenance tracking. It supports automatic memory mirroring from Hermes native tools and session snapshots.

futurebrowser / hermes-exabase-plugin

A memory plugin that integrates Exabase M-1 for self-organizing long-term agent memory. It provides tools for manual memory storage and supports configurable query expansion and reranking.

penfieldlabs / hermes-penfield

A memory provider featuring 17 tools for knowledge graph traversal and memory management. It uses hybrid search methods and provides automatic context checkpointing during message compression.
