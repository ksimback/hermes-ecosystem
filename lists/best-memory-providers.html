For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal layer for managing multi-level states across users, sessions, and agents. It supports temporal reasoning and multi-signal retrieval, available through a managed cloud, self-hosted server, or an Apache-2.0 open-source SDK.

volcengine / OpenViking

OpenViking is an AGPL-3.0 context database that organizes agent memory as a virtual filesystem using viking:// URIs. It utilizes a three-tier loading system to achieve a 91% token reduction and provides observable retrieval trajectories for debugging context paths.

topoteretes / cognee

Cognee functions as a self-hosted knowledge graph engine that provides AI agents with persistent long-term memory across sessions. It combines vector embeddings with graph-based reasoning and offers clients in Python, Rust, and TypeScript.

garrytan / gbrain

This opinionated brain for Hermes Agents generates synthesized prose answers complete with citations and gap analysis. It builds a self-wiring knowledge graph by extracting typed entity edges while maintaining verified data isolation for multi-user access.

supermemoryai / supermemory

Supermemory is an official provider featuring a custom vector graph engine that sustains sub-300ms recall at scales exceeding 100B tokens per month. It automates fact extraction and user profiling, utilizing byte-level deduplication to secure a 100% prompt-cache discount.

vectorize-io / hindsight

Hindsight provides long-term retain, recall, and reflect workflows that allow agent memory to learn over time. It supports over 25 LLM providers and offers flexible deployment via Docker, Kubernetes, or managed cloud services.

plastic-labs / honcho

Honcho is a reasoning-first memory library that extracts conclusions from conversation history to build stateful agents. It is implemented as a FastAPI server with Python and TypeScript SDKs, supporting managed, local, and Docker Compose deployments.

campfirein / byterover-cli

This official provider treats memory as a git repository, offering version control features like branching and merging over a markdown context tree. It utilizes a five-tier retrieval system to achieve sub-100ms performance and includes an interactive TUI powered by React/Ink.

mnemosyne-oss / mnemosyne

Mnemosyne is a zero-dependency memory system that uses a single SQLite database for local data storage and sub-millisecond performance. It supports the Model Context Protocol (MCP) for integration with tools like Cursor and Claude Code via a simple Python SDK.

ClaudioDrews / memory-os

This seven-layer memory system utilizes Qdrant, Redis, and SQLite to manage persistent vector search and structured facts. It features an auto-curated wiki and a Ground Truth hierarchy to ensure agents prioritize specific injected contexts.

greyhaven-ai / autocontext

Autocontext is a recursive self-improving harness that produces filesystem-first artifacts like traces and playbooks to help agents with complex tasks. It features outcome-gated promotion and ablation-backed attribution to validate the effectiveness of context changes.

stephenschoettler / hermes-lcm

This plugin provides a DAG-based context engine for Hermes Agent that ensures no messages are lost during processing. It uses a local SQLite store with full-text search metadata and provides tools for agents to search and expand compacted material.

elkimek / honcho-self-hosted

This project enables private cross-session memory for Hermes Agent by providing a self-hosted backend for the Honcho library. It includes automated setup scripts for Docker, PostgreSQL, and Redis, supporting any OpenAI-compatible or local inference server.

Signet-AI / signetai

Signet-AI provides a local-first identity and memory layer that enables portable state across Hermes Agent and other MCP clients. It achieves a 97.6% LongMemEval accuracy and supports data imports from Obsidian, Discord, and GitHub.

plur-ai / plur

This shared memory layer stores information as human-readable YAML engrams on the local disk for multi-agent systems. It utilizes a hybrid search mechanism combining BM25 and local embeddings to facilitate retrieval across tools like Claude Code and Codex.

yoloshii / ClawMem

ClawMem is an on-device context engine that operates locally without cloud dependencies or API keys. It integrates via MCP and plugins, employing hybrid retrieval through BM25 and vector search to manage agent memory.

EfficientContext / ContextPilot

ContextPilot optimizes long-context inference by reordering blocks and deduplicating data to enhance prefix reuse. It offers native plugin support for Hermes Agent, reducing prefill latency by 1.5–3× while saving up to 36% in token usage.

Sibyl-Labs / Sibyl-Memory

This file-based long-term memory system uses SQLite with FTS5 search instead of vector databases or embeddings. It features a five-package plugin family that includes a dedicated Hermes adapter and a LangGraph BaseStore.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin provides explainable retrieval by attaching a 'why_retrieved' tag to every recalled result. It includes a self-directing loop to resolve knowledge gaps and supports owner-scoping for multi-user environments.

yepyhun / Brainstack

Brainstack serves as a memory kernel that integrates Hindsight, Graphiti, and MemPalace into a single owner. It manages state and retrieval using SQLite, Kuzu, and Chroma to deliver purpose-built evidence packets for agent queries.

amanning3390 / flowstate-qmd

This anticipatory memory system prefetches context by monitoring agent session logs and storing data locally via SQLite-vec. Developed for the Hermes 2026 Hackathon, it functions as an MCP-native server compatible with major coding clients.

ccf / agentcairn

AgentCairn establishes cross-project memory by using an Obsidian vault as the primary source of truth. It stores information in inspectable Markdown files and utilizes DuckDB as a replaceable retrieval cache for coding agents.

Perseus-Computing-LLC / perseus

Perseus resolves live workspace state into verified facts before the context window opens, rendering data into files like AGENTS.md. This local-first architecture supports MCP and aims to reduce prompt tokens by 94%.

generalbusiness-ai / keep

Keep is a reflective memory system that combines BM25 full-text search with ranked graph traversal. It features automated indexing for multimedia and codebases, using edge tags to create bidirectional relationships between notes.

alias8818 / hermes-tool-slimmer

This tool reduces prompt token overhead for Hermes Agent v0.14.0 by using local BM25 ranking for tool schemas. It includes a dashboard to track estimated token savings and supports native tool search functionality.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin utilizes a single .lbdb embedded graph database to manage agent memory. It features importance-weighted recall to surface high-priority entries and supports BM25 keyword search alongside named graph relationships.

conorbronsdon / claude-context-os

This Git-backed layer stores identity and project state in plain Markdown files for coding agents. It uses hash-checked proposals for session handoffs and provides dedicated adapters for Hermes, Claude Code, and Cursor.

MukundaKatta / hermes-agentmemory

A pull-model episodic memory plugin that addresses persistent summary issues by supporting real, immediate event deletion. It includes an on-demand summarizer and generates a trace.jsonl audit log for every prefetch operation.

piprail / piprail

This SDK and MCP server enables Hermes agents to handle payments using USDC and stablecoins across 29 chains. It allows agents to settle payments directly to wallets with 0% transaction fees via a few lines of code.

stepanov1975 / hermes-local-knowledge

This plugin indexes local skills, scripts, and MCP server configurations to facilitate capability routing. It provides tools for artifact search and graph neighbor traversal, using feedback to improve local routing hints.

yonro / hermes-xmemo-plugin

This provider enables durable cross-session memory through pre-turn context injection and session-end snapshots. It features a local SQLite reliability layer and a write outbox for searching and updating agent state.

futurebrowser / hermes-exabase-plugin

Integrating Exabase M-1, this plugin provides self-organizing long-term memory for Hermes agents. It supports manual memory storage and offers configurable query expansion and result reranking for retrieval.

visorcraft / MongrelDB-Hermes

This AI-native memory solution features AES-256-GCM encryption at rest and supports HNSW ANN, sparse, and FM-index retrieval. It can be executed via native Rust FFI or as an HTTP daemon with built-in MinHash deduplication.

sourcevault-ai / sourcevault-code-tools

This plugin provides private local code memory for repositories using a local SourceVault server for vector storage. It adds deterministic slash commands for search and sync, supporting grounded Q&A through LLM-callable tools.

penfieldlabs / hermes-penfield

This suite offers 17 tools for memory management and knowledge graph traversal using hybrid BM25, vector, and graph search. It also features automatic context checkpointing during message compression.

conorbronsdon / agent-memory-kit

A database-free curation tool that uses a git-backed directory of Markdown files to manage agent memory. It includes 'rot' and 'lint' curators to identify stale data and proposes evidence-cited diffs for manual review.
