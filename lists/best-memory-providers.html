For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This official Hermes Agent memory provider offers a universal layer for managing User, Session, and Agent states via temporal reasoning and multi-signal retrieval. It is available as an Apache-2.0 self-hosted server, an OSS SDK, or a managed cloud service.

volcengine / OpenViking

OpenViking is an AGPL-3.0 context database that organizes information as a virtual filesystem using viking:// URIs. It utilizes a three-tier loading system to achieve significant token reduction and task-completion gains while providing observable retrieval trajectories.

garrytan / gbrain

This opinionated agent brain utilizes a self-wiring knowledge graph with typed entity relationships to manage information. It supports multi-tenant company deployments and performs gap analysis to identify missing data within user queries.

supermemoryai / supermemory

This official provider features a custom vector graph engine capable of sub-300ms recall at scales exceeding 100B tokens per month. It automates fact extraction and user profiling while offering byte-level deduplication and connectors for platforms like Google Drive and GitHub.

vectorize-io / hindsight

Hindsight provides long-term retain, recall, and reflect workflows for agents across more than 25 LLM providers. It is deployable via Docker or Kubernetes and supports both Python and Node.js clients for flexible storage backend integration.

plastic-labs / honcho

Honcho is a memory library that enables reasoning-first memory by extracting conclusions from conversation history. It is implemented as a FastAPI server with dedicated SDKs and supports managed, local, or Docker-based deployments.

campfirein / byterover-cli

This official provider manages context as a git-like repository, offering version control features such as branching and merging for markdown context trees. It utilizes a 5-tier retrieval system to achieve sub-100ms performance and includes an interactive TUI powered by React/Ink.

mnemosyne-oss / mnemosyne

Mnemosyne is a zero-dependency memory system that uses a single SQLite database for local storage and sub-millisecond performance. It features episodic compression to ensure sub-linear storage growth and supports MCP, Python SDK, and OpenWebUI.

ClaudioDrews / memory-os

This system employs a seven-layer memory architecture, including vector search on Qdrant and an auto-curated wiki, to manage agent state. It uses a Ground Truth hierarchy to ensure the agent prioritizes injected context over other data.

greyhaven-ai / autocontext

Autocontext is a recursive self-improving harness that produces filesystem-first artifacts like context bundles and playbooks. It features outcome-gated promotion and ablation-backed attribution to refine context changes based on task success.

stephenschoettler / hermes-lcm

This plugin provides lossless context management through a hierarchical DAG of depth-aware summary nodes. It uses a SQLite-backed store with FTS metadata, allowing agents to search and expand compacted material without losing original message data.

elkimek / honcho-self-hosted

This project provides a self-hosted backend for the Honcho library, enabling private cross-session persistence for Hermes Agent. It includes automated setup scripts for Docker, PostgreSQL, and Redis, and supports any OpenAI-compatible inference server.

Signet-AI / signetai

Signet-AI provides a local-first identity and secrets layer that enables portable state across Hermes Agent and other MCP clients. It achieves a 97.6% LongMemEval accuracy and allows agents to import data from external sources like Obsidian, Discord, and GitHub.

plur-ai / plur

This shared memory layer utilizes an open YAML format called engrams to store human-readable data on local disks for multi-agent systems. It facilitates retrieval through a hybrid search combining BM25 and local embeddings, supported by Model Context Protocol integration.

yoloshii / ClawMem

ClawMem is an on-device context engine that operates entirely locally without cloud dependencies or API keys. It integrates with Hermes Agent via MCP and plugins, employing a hybrid retrieval system of BM25 and vector search.

EfficientContext / ContextPilot

ContextPilot optimizes long-context inference by reordering and deduplicating blocks to maximize prefix reuse. This native Hermes Agent plugin reduces prefill latency by 1.5–3× and can save up to 36% of prompt tokens.

Sibyl-Labs / Sibyl-Memory

Sibyl-Memory is a file-based long-term memory system that uses SQLite with FTS5 search instead of vector databases or embeddings. It offers a five-package plugin family that includes a dedicated Hermes adapter and a CLI for local-first management.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin provides explainable retrieval by attaching a 'why_retrieved' tag to every recalled memory. It features a self-directing loop to resolve knowledge gaps and supports owner-scoping for multi-user environments like Telegram or Discord.

yepyhun / Brainstack

Brainstack serves as a memory kernel stack that integrates Hindsight, Graphiti, and MemPalace into a single owner for Hermes Agent. It manages state and retrieval using a combination of SQLite, Kuzu, and Chroma to deliver purpose-built evidence packets.

ccf / agentcairn

AgentCairn enables cross-project memory for coding agents by using an Obsidian vault as the primary source of truth. It stores memory as inspectable Markdown files and utilizes DuckDB as a replaceable retrieval cache to avoid opaque databases.

amanning3390 / flowstate-qmd

This anticipatory memory system prefetches context by monitoring agent session logs to populate a local cache. It is an MCP-native server that uses SQLite-vec and GGUF models to provide RAG and vector search capabilities.

Perseus-Computing-LLC / perseus

Perseus resolves live workspace state into verified facts and rendered context files before the context window opens. This local-first architecture uses SQLite and FTS5 to reduce prompt tokens by up to 94% with minimal overhead.

generalbusiness-ai / keep

Keep is a reflective memory system that combines BM25 full-text search with ranked graph traversal for semantic retrieval. It features automated indexing for multimedia and codebases, using edge tags to create bidirectional relationships between notes.

alias8818 / hermes-tool-slimmer

This utility reduces Hermes Agent prompt overhead by using local BM25 ranking to select only relevant tool schemas. It includes a dashboard for tracking token savings and is compatible with Hermes Agent v0.14.0 native tool search.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin utilizes a columnar .lbdb embedded graph database to manage agent recall. It features a built-in 1-10 importance ranking system to surface high-priority memories during context prefetch and supports BM25 keyword search.

conorbronsdon / claude-context-os

This Git-backed workflow layer provides a deterministic lifecycle kernel for hash-checked proposals and receipts. It offers a source-neutral migration workflow for importing documents and includes an opt-in catalog for documenting external tools.

MukundaKatta / hermes-agentmemory

A pull-model episodic memory plugin that features real event deletion and an on-demand summarizer to prevent persistent summaries from affecting future recall. It maintains a trace.jsonl audit log to provide a record of every memory and prefetch operation.

yonro / hermes-xmemo-plugin

This provider enables durable cross-session memory through pre-turn context injection and session-end snapshots. It relies on a local SQLite reliability layer and a write outbox to support tools for searching, remembering, and updating state.

piprail / piprail

This SDK and MCP server enables AI agents to handle payments using USDC and stablecoins across 29 chains, including EVM and Solana. It settles payments directly to wallets with 0% fees and integrates with agent frameworks like elizaOS.

stepanov1975 / hermes-local-knowledge

This plugin provides local capability indexing for skills, scripts, runbooks, and MCP server configurations. It includes five native tools for searching and fetching, with support for automatic generation of tool routing notes.

futurebrowser / hermes-exabase-plugin

Integrating Exabase M-1, this plugin provides self-organizing long-term memory for agents. It supports configurable query expansion and result reranking to improve the retrieval of manually stored or searched memories.

visorcraft / MongrelDB-Hermes

This AI-native memory solution offers AES-256-GCM encryption at rest and supports HNSW ANN, sparse, and FM-index retrieval. It can be executed via native Rust FFI or as an HTTP daemon and includes MinHash deduplication.

sourcevault-ai / sourcevault-code-tools

This plugin provides private local code memory for repositories, supporting semantic search and grounded Q&A through a local SourceVault server. It adds deterministic slash commands and LLM-callable tools for models with structured tool use.

penfieldlabs / hermes-penfield

This provider features 17 tools for memory management and knowledge graph traversal using hybrid search that combines BM25, vector, and graph methods. It also performs automatic context checkpointing during message compression.

conorbronsdon / agent-memory-kit

A file-based curation loop that uses a git-backed directory of markdown files to manage memory without a database. It includes 'rot' and 'lint' curators to identify stale or conflicting data and proposes evidence-cited diffs for review.
