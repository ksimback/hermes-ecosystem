breakdown

numtide / llm-agents.nix

Provides Nix packages for various AI coding agents and development tools, including Hermes. These packages are updated on a daily basis.

marshallrichards / ClawPhone

Offers scripts and notes for running agent CLIs, such as Hermes Agent, on Android smartphones via Termux. It includes an automated installer for Antigravity CLI on ARM64 and configuration guides for running OpenClaw.

AbuZar-Ansarii / Hermes-Agent-On-Android

Provides a Termux-based installer for Hermes Agent that uses a one-line command. This deployment supports over 200 AI models and includes a gateway service for incoming connections.

ultraworkers / hermes-agent-helm-chart

An unofficial community Helm chart for deploying Hermes Agent on Kubernetes. It enforces single-writer state safety for persistent HERMES_HOME storage and supports both direct deployment and operator-ready CRD-based workflows.

amirghm / hermes-agent-mobile

A one-command installer that enables the Hermes AI assistant on Android (via Termux) and iOS (via iSH). It integrates with Telegram for voice and file messaging and supports scheduled tasks via cron jobs on Termux.

TheAiSingularity / hermesclaw

Provides hardware-level enforcement for Hermes Agent sandboxing via NVIDIA OpenShell. This setup allows for kernel-level restriction of network and filesystem access through configurable security policies.

xmbshwll / hermes-agent-docker

A simple Docker sandbox image containing the official Hermes installation and mini-swe-agent. It supports persistent state through mounted home directories and allows building specific Hermes tags using build arguments.

0xrsydn / nix-hermes-agent

A Nix package and NixOS module designed for reproducible Hermes deployment. It features declarative configuration for workspace documents and hybrid skill management for both Nix-managed and CLI-installed skills.

solomon2773 / nora

A self-hosted control plane for deploying and operating OpenClaw and Hermes AI agents on Docker or Kubernetes. It provides per-agent metrics, costs, and LLM budget caps via REST, CLI, and MCP.

jpalmae / hermeshq

A Docker-first control plane designed to run and operate multiple Hermes Agent instances through a single web application. It manages separate workspaces and identities while offering hierarchy-aware inter-agent delegation.

JackTheGit / hermes-autonomous-server

A headless systemd deployment for Ubuntu and Debian servers that integrates with Nous Portal. It configures Hermes Gateway as a reboot-safe service to enable autonomous execution of recurring AI cron jobs.

MilkyWay008 / Hermes-OTG

A portable production package that runs from a USB or drive without host installation or registry writes. It includes Desktop, TUI, and Gateway modes with isolated data environments.
