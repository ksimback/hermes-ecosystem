Project Breakdown

llm-agents.nix

This project provides a comprehensive suite of Nix packages for terminal-based AI coding agents, including Hermes. It automates daily updates for all included tools and supports a mix of open-source and proprietary binary-based development agents.

portable-hermes-agent

Designed for Windows users, this no-install desktop application provides a GUI and over 100 tools without requiring admin rights or Docker. It features integrated GPU monitoring, local model management, and a workflow engine for scheduled automation.

hermesclaw

Hermesclaw focuses on security by providing hardware-level enforcement of network, filesystem, and process boundaries for the agent. It features three security policy presets and includes secure gateways for integrating Hermes with Telegram, Discord, and Slack.

hermes-agent-docker

This project provides a streamlined Docker sandbox that includes both the official Hermes installation and mini-swe-agent. It supports persistent state through mounted directories and allows users to build specific Hermes versions using build arguments.

nix-hermes-agent

This repository offers a NixOS module for declarative management of Hermes configurations, documents, and systemd services. It prioritizes security through sops-nix integration and supports a hybrid skill model that combines Nix-managed assets with interactive CLI installations.

hermes-autonomous-server

Targeting production environments, this deployment configures the Hermes Gateway as a reboot-safe systemd service for Ubuntu and Debian. It is optimized for headless operation and enables the autonomous execution of recurring AI cron jobs.

portainer-stack-hermes

This Docker Compose stack integrates with Portainer to deploy Hermes alongside a ttyd web terminal interface. It simplifies the deployment lifecycle by automating image builds through GitHub Actions and the GitHub Container Registry.
