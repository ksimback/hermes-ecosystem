breakdown

numtide / llm-agents.nix

This project provides Nix packages for various AI coding agents, including Hermes. These packages are updated on a daily basis.

marshallrichards / ClawPhone

This repository contains scripts and notes for running agent CLIs, such as Hermes Agent, on Android smartphones via Termux. It includes an automated installer for Antigravity CLI on ARM64 and configuration guides for running OpenClaw.

AbuZar-Ansarii / Hermes-Agent-On-Android

This project offers an automated Termux-based installer for running Hermes Agent on Android devices. It supports local model execution via Ollama and is compatible with providers such as OpenAI and Anthropic.

ultraworkers / hermes-agent-helm-chart

This unofficial community Helm chart enables Hermes Agent deployment on Kubernetes with cloud-native state-safety guardrails. It supports direct deployment or operator-ready CRD-based workflows and features a configurable gateway mode.

amirghm / hermes-agent-mobile

This one-command installer enables the Hermes AI assistant on Android via Termux and iOS via iSH. It integrates with Telegram for voice and file messaging and supports scheduled tasks through Termux cron jobs.

TheAiSingularity / hermesclaw

This project provides hardware-level enforcement for Hermes Agent sandboxing using NVIDIA OpenShell. It allows for kernel-level restriction of network and filesystem access through configurable security policies.

xmbshwll / hermes-agent-docker

This project provides a simple Docker sandbox image that includes the official Hermes installation and mini-swe-agent. It supports persistent state through mounted home directories and allows for building specific Hermes tags via build arguments.

0xrsydn / nix-hermes-agent

This repository provides a Nix package and NixOS module for reproducible Hermes deployment. It features declarative configuration for workspace documents and hybrid skill management for Nix-managed and CLI-installed skills.

solomon2773 / nora

This self-hosted control plane is used to deploy, monitor, and operate OpenClaw and Hermes AI agents on Docker or Kubernetes. It provides per-agent metrics, costs, and LLM budget caps via REST, CLI, and MCP.

jpalmae / hermeshq

This Docker-first control plane orchestrates multiple Hermes Agent instances with separate workspaces and identities. It provides hierarchy-aware inter-agent delegation, task scheduling, and enterprise MCP access.

JackTheGit / hermes-autonomous-server

This project configures Hermes Gateway as a reboot-safe systemd service for headless operation on Ubuntu and Debian servers. It enables autonomous execution of recurring AI cron jobs and includes Nous Portal integration.
