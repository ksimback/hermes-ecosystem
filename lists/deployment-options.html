breakdown

numtide / llm-agents.nix

A collection of Nix packages that enables instant execution of Hermes and other AI coding agents via nix run commands. It ensures software freshness through daily automatic updates for all included packages.

marshallrichards / ClawPhone

Provides scripts and configuration guides to run agent CLIs, including Hermes, on Android smartphones using Termux. It leverages Termux:API and Termux:GUI to grant the agent access to mobile hardware and user interfaces.

rookiemann / portable-hermes-agent

A zero-install Windows desktop distribution featuring a GUI and 100 built-in tools across 20 toolsets. It supports local model execution via LM Studio and includes a dynamic tool maker for custom automation pipelines.

AbuZar-Ansarii / Hermes-Agent-On-Android

A Termux-based installer that uses a one-line script to deploy Hermes Agent on Android and Ubuntu environments. This setup enables local model execution via Ollama integration and supports persistent memory on mobile devices.

ultraworkers / hermes-agent-helm-chart

A community Helm chart for Kubernetes deployments that implements cloud-native state-safety guardrails to prevent concurrent write conflicts. It supports both direct deployment and operator-ready CRD workflows with optional gateway mode.

TheAiSingularity / hermesclaw

A security-focused deployment that utilizes NVIDIA OpenShell for hardware-enforced sandboxing and kernel-level protection. It secures network and filesystem access while providing over 40 built-in tools and self-improving skills.

xmbshwll / hermes-agent-docker

A streamlined Docker sandbox image that bundles the official Hermes installation with mini-swe-agent. It supports persistent state through mounted home directories and allows for custom builds using specific Hermes tags.

0xrsydn / nix-hermes-agent

A NixOS module and package that provides declarative management of agent configurations and systemd services. It integrates with sops-nix for secure secrets handling and supports a hybrid approach for both Nix-managed and interactive installs.

JackTheGit / hermes-autonomous-server

A production-ready headless deployment that configures the Hermes Gateway as a reboot-safe systemd service. It is designed for Ubuntu and Debian servers to enable the autonomous execution of recurring AI cron jobs.

jpalmae / hermeshq

A Docker-first control plane that allows users to operate multiple Hermes Agent instances with separate identities from a single web application. It features hierarchy-aware task delegation and enterprise MCP access for external AI clients.

ellickjohnson / portainer-stack-hermes

A Docker Compose stack designed for Portainer that provides a ttyd web terminal interface for agent interaction. It automates the deployment process via Git Repository stacks and GitHub Action workflows.
