breakdown

numtide / llm-agents.nix

This project provides Nix packages for AI coding agents, including Hermes, that are automatically updated on a daily basis. It allows users to integrate development tools from providers like Google, OpenAI, and GitHub into a Nix-based environment.

marshallrichards / ClawPhone

This repository offers an automated installer and configuration guides for running Hermes Agent and Antigravity CLI on ARM64 Android devices via Termux. It enables hardware and UI access through Termux:API and Termux:GUI integrations.

AbuZar-Ansarii / Hermes-Agent-On-Android

This solution features a one-line installation script for deploying Hermes Agent within Termux environments on Android. It supports over 70 tools, persistent memory for user preferences, and compatibility with both local Ollama models and cloud API providers.

ultraworkers / hermes-agent-helm-chart

This community Helm chart facilitates the deployment of Hermes Agent on Kubernetes with a focus on single-writer state safety for persistent storage. It supports both direct deployments and operator-ready workflows, including a configurable gateway mode with API and webhook listeners.

amirghm / hermes-agent-mobile

This one-command installer brings Hermes to both Android and iOS devices using Termux and iSH. It distinguishes itself by integrating with Telegram for voice and file messaging and supporting scheduled tasks via cron jobs.

TheAiSingularity / hermesclaw

This project focuses on security by providing a sandboxed environment for Hermes Agent with hardware-level enforcement via NVIDIA OpenShell. It implements kernel-level restrictions on network and filesystem access alongside configurable security policies for web search and messaging.

solomon2773 / nora

Nora is a self-hosted control plane designed to deploy and monitor Hermes agents across Docker and Kubernetes. It provides operational oversight through per-agent metrics, LLM budget caps, and a multi-interface approach including REST, CLI, and MCP.

xmbshwll / hermes-agent-docker

This repository provides a Docker-based sandbox image that includes both the official Hermes installation and mini-swe-agent. It supports persistent state through mounted home directories and allows users to build specific Hermes tags using build arguments.

0xrsydn / nix-hermes-agent

This project offers a Nix package and NixOS module for declarative and reproducible Hermes deployments. It features hybrid skill management and secure secrets integration via systemd EnvironmentFiles or sops-nix.

jpalmae / hermeshq

HermesHQ is a Docker-first control plane that manages multiple agent instances through a single web application with RBAC-controlled access. It enables hierarchical inter-agent delegation and provides Enterprise MCP access for external AI client integration.

JackTheGit / hermes-autonomous-server

This deployment option configures Hermes Gateway as a reboot-safe systemd service for headless operation on Ubuntu and Debian servers. It is designed for production-ready autonomous execution of recurring AI cron jobs and integrates with Nous Portal.

MilkyWay008 / Hermes-OTG

This portable package allows Hermes Agent to run from a USB drive or any external storage without host installation or registry modifications. It bundles Python 3.12 and rescue tools to support isolated Desktop, TUI, and Gateway modes in offline environments.
