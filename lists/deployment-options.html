breakdown

numtide / llm-agents.nix

This project provides daily-updated Nix packages for Hermes across various interfaces, including CLI tools, desktop applications, and agentic IDEs. It serves as a specialized distribution point for users who require consistent, versioned access to the agent's ecosystem.

marshallrichards / ClawPhone

ClawPhone offers scripts and configuration guides for running the Antigravity CLI and OpenClaw on ARM64 Android devices via Termux. It enables hardware and UI interaction by leveraging Termux:API and Termux:GUI for mobile-specific agent workflows.

AbuZar-Ansarii / Hermes-Agent-On-Android

This repository features a one-line automated installer for deploying Hermes Agent within Android Termux environments. The setup supports over 70 tools and persistent memory, allowing the agent to function using either external providers or local models via Ollama.

ultraworkers / hermes-agent-helm-chart

This community Helm chart facilitates Kubernetes deployments with a focus on cloud-native state safety and single-writer storage enforcement. It supports both direct deployments and operator-ready workflows, including configurable gateway modes with API and webhook listeners.

amirghm / hermes-agent-mobile

This one-command installer brings Hermes to both Android and iOS platforms using Termux and iSH. It extends agent functionality with Telegram integration for voice and file messaging, alongside support for scheduled cron jobs on mobile hardware.

TheAiSingularity / hermesclaw

Hermesclaw provides a sandboxed environment for Hermes Agent using NVIDIA OpenShell for hardware-level enforcement. It implements kernel-level restrictions on network and filesystem access while allowing users to configure specific security policies for web search and messaging.

solomon2773 / nora

Nora acts as a self-hosted control plane for operating OpenClaw and Hermes agents on Docker or Kubernetes. It provides operational oversight through per-agent metrics, cost tracking, and LLM budget caps accessible via REST, CLI, or MCP.

xmbshwll / hermes-agent-docker

This project provides a Docker sandbox image that bundles the official Hermes installation with mini-swe-agent. It supports persistent state through mounted directories and allows users to target specific Hermes versions using build arguments.

0xrsydn / nix-hermes-agent

This NixOS module enables reproducible, declarative deployment of Hermes with integrated secret management via sops-nix. It features a hybrid skill management system that allows for both Nix-managed and CLI-installed agent capabilities.

jpalmae / hermeshq

HermesHQ is a Docker-based control plane designed to manage multiple agent instances with RBAC-controlled access and separate workspaces. It supports hierarchical inter-agent delegation and provides enterprise MCP access for external AI client integrations.

JackTheGit / hermes-autonomous-server

This deployment option configures the Hermes Gateway as a reboot-safe systemd service for headless operation on Ubuntu and Debian. It is designed for production-ready autonomous execution, specifically supporting recurring AI cron jobs and Nous Portal integration.

MilkyWay008 / Hermes-OTG

Hermes OTG is a portable distribution that runs from USB drives without requiring host installation or registry modifications. It bundles Python, PortableGit, and rescue tools to support Desktop, TUI, and Gateway modes in isolated offline environments.
