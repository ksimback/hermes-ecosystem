breakdown

numtide / llm-agents.nix

This project provides daily-updated Nix packages for Hermes, covering CLI tools, desktop applications, and agentic IDEs. It is included for users seeking a reproducible way to manage AI coding agents across various environments.

marshallrichards / ClawPhone

ClawPhone offers scripts and configuration guides for running Hermes Agent on ARM64 Android smartphones via Termux. It features an automated installer for the Antigravity CLI and utilizes Termux:API and Termux:GUI for hardware and UI access.

praveen-ks-2001 / hermes-agent-template

This one-click Railway template deploys Hermes Agent with a web-based admin dashboard for managing provider setups, gateway logs, and user pairing. It simplifies cloud deployment by including persistent volume support and a password-protected proxy for the native UI.

AbuZar-Ansarii / Hermes-Agent-On-Android

This repository features a one-line Termux installation script to run Hermes Agent on Android with support for over 70 tools and persistent memory. It enables the use of both external providers and local models via Ollama integration.

ultraworkers / hermes-agent-helm-chart

This community Helm chart facilitates Kubernetes deployments by enforcing single-writer state safety for persistent storage. It supports both direct deployments and operator-ready workflows with configurable gateway modes for API and webhook listeners.

amirghm / hermes-agent-mobile

This one-command installer brings Hermes to both Android and iOS devices using Termux and iSH. It extends mobile functionality by integrating Telegram for voice and file messaging and supporting scheduled tasks via cron jobs.

TheAiSingularity / hermesclaw

Hermesclaw provides a sandboxed environment for Hermes Agent using NVIDIA OpenShell for hardware-enforced security. It restricts network and filesystem access at the kernel level while allowing configurable policies for messaging and web search.

solomon2773 / nora

Nora is a self-hosted control plane for operating Hermes agents on Docker or Kubernetes, offering monitoring tools for metrics and LLM budget caps. It provides multiple interfaces for agent management, including a REST API, CLI, and MCP server.

xmbshwll / hermes-agent-docker

This project provides a Docker sandbox image that includes the official Hermes installation and mini-swe-agent. It allows for persistent state through mounted directories and supports building specific Hermes tags via build arguments.

0xrsydn / nix-hermes-agent

This NixOS module enables declarative Hermes deployments with secure secrets integration via sops-nix and systemd. It supports a hybrid skill management system, allowing users to manage skills through both Nix and the Hermes CLI.

jpalmae / hermeshq

HermesHQ is a Docker-first control plane designed to manage multiple agent instances with RBAC-controlled access and separate workspaces. It supports inter-agent delegation with hierarchy-aware communication and enterprise MCP access for external clients.

JackTheGit / hermes-autonomous-server

This production-ready deployment configures Hermes Gateway as a reboot-safe systemd service for headless operation on Ubuntu and Debian. It is designed for autonomous execution, specifically supporting recurring AI cron jobs.

MilkyWay008 / Hermes-OTG

This portable distribution enables the Hermes Agent to run directly from USB or external drives without requiring host installation or registry modifications. It provides a self-contained production environment bundling Python 3.12, PortableGit, and Sysinternals rescue tools to support Desktop, TUI, and Gateway modes in offline settings.
