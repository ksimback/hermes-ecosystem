breakdown

colbymchenry / codegraph

This tool provides a local, Rust-powered code knowledge graph that pre-indexes TypeScript, JavaScript, ArkTS, and Python files. It integrates with Hermes Agent to reduce token usage and tool calls by auto-syncing the index on every file change.

junhoyeo / tokscale

Tokscale is a CLI-based utility that tracks token usage across multiple AI coding agents, including Hermes and Claude Code. It features a TUI and a 3D contribution graph dashboard, allowing users to submit data for public profiles and leaderboards.

liaohch3 / claude-tap

This local trace viewer enables developers to inspect API traffic from Hermes Agent and other coding tools through a self-contained HTML viewer. It prioritizes security by redacting common authentication headers before recording exported trace sessions.

bergside / typeui

TypeUI offers design systems and layout guidance via MCP servers to help developers build better interfaces with AI. It is compatible with any provider supporting markdown and integrates directly with Hermes Agent, Cursor, and GitHub Copilot.

Javis603 / token-monitor

This widget provides real-time tracking of tokens, costs, and rate limits by reading Hermes Agent state directly. It supports multi-device synchronization and offers historical usage breakdowns categorized by session, project, and model.

Salomondiei08 / oh-my-hermes

This project serves as an opinionated workflow layer that coordinates seven specialized agents and loads 36 skills for app development. It supports autonomous execution on both laptops and VPS environments to streamline building and shipping processes.

joeynyc / hermes-skins

Hermes-skins allows users to customize the Hermes terminal UI with community-created themes, including retro DOS and cyberpunk aesthetics. It uses YAML-based configuration to modify banner colors, spinners, and ASCII art.

AlexAI-MCP / hermes-CCC

This project ports the Hermes Agent brain and 46 core skills to the Claude Code Channel, allowing them to run natively without separate processes or OAuth. It also includes specialized MLOps tools for vLLM, GGUF inference, and RL training.

tinyhumansai / tiny.place

Tiny.place establishes a social economy for autonomous agents by providing encrypted agent-to-agent messaging via the Signal Protocol. It facilitates commerce through Solana-based payments and supports identity registration using human-readable handles.

unmodeled-tyler / vessel-browser

Vessel is an AI-native browser designed for autonomous agent control via MCP, featuring a supervisor sidebar for managing workflows. It supports various providers like Anthropic and OpenAI while offering undo functionality for recent agent-driven changes.

topoteretes / cognee-integrations

This integration suite provides memory capabilities for frameworks like CrewAI and LangGraph, including a plugin for Claude Code with automatic context recall. It also offers chat bots for platforms such as Telegram, Slack, and VS Code.

adityahimaone / hermes-agent-rtk-caveman

This setup utilizes RTK and Caveman templating to achieve 90-99% token savings during Hermes Agent workflows. It includes over 40 pre-configured skills for finance and research, supported by an automated cross-platform installer for macOS and Linux.

Abruptive / Ankh.md

Ankh.md is a TAW Agent framework that enables per-folder scoping for Hermes Agents through local configurations and skills. It allows users to seamlessly switch between default and scoped agents while supporting project-local memories, tools, and custom instructions.

42-evey / evey-setup

This tool automates the installation of the hermes-agent stack and 12 supporting services across three scalable deployment tiers. It provides a zero-cost setup for free models and includes support for 29 community plugins across six functional categories.

hermes-labs-ai / lintlang

Lintlang is a static linter that performs local, deterministic checks on AI agent configurations, tool descriptions, and system prompts. It flags vague descriptions and missing termination conditions, supporting SARIF output for integration with GitHub Code Scanning.

0xNyk / openclaw-to-hermes

This migration utility transitions OpenClaw environments to Hermes Agent by mapping SOUL.md, MEMORY.md, and skills into Hermes YAML and JSON formats. It handles nested authentication structures and sets up systemd gateway services to facilitate the move.

observeco / observeco

Observeco provides self-healing observability for multi-agent systems using passive monitoring and active probing without cloud dependencies. It features a native Hermes Agent plugin for real-time telemetry and establishes config-aware baselines by watching local files.

handnewb / hermes-voice

This voice-enabled assistant for Hermes Agent offers offline, open-mic functionality with wake word support and adaptive turn-taking. It supports 35 languages via Piper and 9 via Kokoro without requiring API keys or user accounts.

33hodl / hermes-startup

Hermes-startup is a local-first skill designed for online monetization using dynamic slash commands and a deterministic local runtime. It prioritizes security by requiring explicit approval for any external actions or write operations.

181079342 / hermes-memoss

This memory plugin for Hermes supports semantic search and multi-dimensional storage through the MemOS API. It includes a built-in circuit breaker for API outages and provides specific tools for searching, adding, and deleting memories.
