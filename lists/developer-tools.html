Project Breakdown

tokscale

This Rust-based TUI tracks token consumption and real-time costs across over 20 AI coding agents, including Hermes and Claude Code. It utilizes LiteLLM pricing data to provide developers with precise financial oversight and 3D usage visualizations for their agentic workflows.

hermes-skins

This customization tool allows users to personalize the Hermes terminal interface through YAML-defined themes and inheritance. It modifies visual elements like banners, spinners, and response boxes with community-driven styles ranging from Cyberdyne Systems to Vault-Tec.

hermes-CCC

This project ports the Hermes Agent brain and its 46 core skills directly into the Claude Code Channel for native execution without external processes or OAuth. It specifically enhances the environment with MLOps tools for vLLM inference, GGUF management, and reinforcement learning training.

vessel-browser

An AI-native browser designed for autonomous control, this tool provides an MCP-native interface for external harnesses like Hermes Agent. It features durable session persistence for agent stability and a human-in-the-loop supervisory layer for real-time transcript monitoring and approvals.

Ankh.md

This framework enables the creation of scoped Hermes Agents that are restricted to specific project folders with local configurations and memories. It allows developers to seamlessly toggle between global and project-local agents, each equipped with unique tools and custom instructions.

lintlang

A static analysis tool that validates agent configurations, tool descriptions, and system prompts without incurring LLM costs or latency. It uses seven structural detectors to identify common failure modes and provides CI-ready gating based on HERM v1.1 scoring.

openclaw-to-hermes

This migration utility streamlines the transition from OpenClaw to Hermes Agent by mapping complex model configurations and personas to the Hermes YAML format. It automates the transfer of memories, skills, and workspace files while securely handling environment-level credentials.

evey-setup

This deployment script uses Docker to orchestrate a full Hermes Agent stack including LiteLLM, Ollama, and Qdrant in minutes. It comes pre-configured with 29 community plugins and automated routing for free models and local GPU inference.
