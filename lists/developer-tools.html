breakdown

colbymchenry / codegraph

This Rust-powered kernel provides a local pre-indexed code knowledge graph to reduce token usage and tool calls for Hermes Agent. It supports Windows, macOS, and Linux and features automatic project synchronization.

junhoyeo / tokscale

This CLI tool tracks token usage across multiple AI clients and coding agents, including Hermes. It features a native Rust TUI and a visualization dashboard for cross-platform monitoring of local agent session data.

liaohch3 / claude-tap

This tool serves as a local trace viewer for inspecting API traffic from Hermes Agent and other coding agents. It allows users to export local trace sessions to HTML and redacts common auth headers during recording.

bergside / typeui

This tool provides design systems and layout guidance via MCP servers to assist in building UIs with AI. It is compatible with any AI provider supporting markdown and integrates with Hermes Agent.

Javis603 / token-monitor

This widget provides real-time tracking of tokens, cost, and rate limits, reading Hermes Agent state directly alongside other CLIs. It supports multi-device synchronization and provides detailed breakdowns of input, output, and cache-hit metrics.

Salomondiei08 / oh-my-hermes

This opinionated workflow layer coordinates seven specialized agents to assist in building, shipping, and operating apps with Hermes Agent. It includes 36 skills and 6 workflows for autonomous execution on laptops or VPS.

joeynyc / hermes-skins

This project offers community CLI skins and themes to customize the Hermes terminal UI. Users can customize banner colors, spinners, and ASCII art banners using YAML-based configuration.

tinyhumansai / tiny.place

This platform facilitates a social economy for autonomous AI agents through encrypted agent-to-agent messaging via Signal Protocol. It supports identity registration with human-readable @handles and commerce via Solana-based USDC and SOL payments.

AlexAI-MCP / hermes-CCC

This is a port of the Hermes Agent brain and 46 core skills to the Claude Code Channel. It runs natively in Claude Code without separate processes or OAuth and includes MLOps tools for RL training and inference.

unmodeled-tyler / vessel-browser

This AI-native browser is built for autonomous agent control via MCP. It features a visible browser UI for real-time AI supervision and includes integrated session management and a research desk.

adityahimaone / hermes-agent-rtk-caveman

This setup utilizes RTK and Caveman templating to achieve 90-99% token savings for Hermes Agent. It includes over 40 pre-configured skills for research, devops, and finance with automated installation for Linux and macOS.

Abruptive / Ankh.md

This TAW Agent framework allows for the creation of scoped Hermes Agents using per-folder scoping. It enables seamless switching between default and scoped agents while supporting project-local tools, memories, and custom instructions.

42-evey / evey-setup

This tool automates the installation of the hermes-agent stack and over 12 supporting services. It provides three scalable deployment tiers and supports 29 community plugins across six functional categories.

roli-lpci / lintlang

This static linter evaluates AI agent configs, tool descriptions, and system prompts using HERM v1.1 scoring. It operates without model or API calls by utilizing static regex and structural heuristics across multiple file formats.

0xNyk / openclaw-to-hermes

This migration tool transfers SOUL.md, MEMORY.md, skills, and memory archives from OpenClaw to Hermes. It maps configurations and credentials into Hermes YAML and JSON formats while setting up systemd gateway services.

observeco / observeco

This observability tool provides automated health monitoring and self-healing for multi-agent systems without cloud dependencies. It includes a beta Hermes plugin that exports telemetry for API requests, tool calls, and token intelligence tracking.
