breakdown

colbymchenry / codegraph

This tool provides a local, pre-indexed code knowledge graph designed to reduce token usage and tool calls for Hermes and other coding agents. It runs entirely on local hardware across Windows, macOS, and Linux, featuring an auto-sync capability to keep the index current.

junhoyeo / tokscale

Tokscale is a CLI tool and visualization dashboard that tracks token usage and associated costs for multiple AI coding agents including Hermes and Claude Code. It allows developers to monitor consumption data across various clients to manage expenses effectively.

liaohch3 / claude-tap

This local trace viewer enables the inspection of API traffic from coding agents like Hermes, Cursor, and Gemini CLI. It generates self-contained HTML viewers for exported sessions and automatically redacts common authentication headers to protect sensitive credentials.

bergside / typeui

TypeUI offers design systems and layout guidance through MCP servers to assist in building user interfaces with AI. It integrates directly with Hermes Agent, Cursor, and GitHub Copilot, supporting any provider that utilizes markdown or general prompting.

Javis603 / token-monitor

This widget provides real-time monitoring of tokens, costs, and rate limits by reading the state of Hermes Agent and 30 other AI coding tools. It features multi-device synchronization and displays historical usage trends to help developers track performance over time.

Salomondiei08 / oh-my-hermes

This opinionated workflow layer coordinates seven specialized agents to build and operate applications using Hermes Agent. It loads 36 skills and 6 workflows, supporting autonomous execution on both laptops and virtual private servers.

joeynyc / hermes-skins

Hermes-skins allows users to customize the Hermes terminal UI with community-created themes and ASCII art. Using YAML-based configurations, developers can modify banner colors and spinners to achieve aesthetics ranging from retro DOS to cyberpunk.

AlexAI-MCP / hermes-CCC

This project ports the Hermes Agent brain and 46 core skills to the Claude Code Channel, allowing them to run natively without external processes or OAuth. It includes specialized MLOps tools for vLLM, GGUF inference, and reinforcement learning training.

unmodeled-tyler / vessel-browser

Vessel is an AI-native browser built for autonomous agent control via the Model Context Protocol. It features a supervisor sidebar for managing agent workflows and includes an undo function to revert recent changes made by the agent.

tinyhumansai / tiny.place

This platform establishes a social economy for autonomous agents by providing encrypted agent-to-agent messaging via the Signal Protocol. It supports identity registration with human-readable handles and facilitates commerce using USDC and SOL on the Solana blockchain.

topoteretes / cognee-integrations

This integration suite provides memory capabilities for platforms like Telegram and Slack using a two-tier system of knowledge graphs and session caches. It supports various frameworks including CrewAI, LangGraph, and the Google ADK.

adityahimaone / hermes-agent-rtk-caveman

This setup utilizes RTK and Caveman templating to achieve 90-99% token savings during Hermes Agent workflows. It comes with over 40 pre-configured skills for DevOps and finance, featuring an automated installer for macOS and Linux.

Abruptive / Ankh.md

This framework enables the creation of scoped Hermes Agents by applying per-folder configurations, skills, and project-local memories. It allows users to switch seamlessly between default and scoped agents while maintaining custom instructions specific to individual directories.

42-evey / evey-setup

This automated installation tool deploys a complete hermes-agent stack and over 12 supporting services in minutes at zero cost. It offers three scalable deployment tiers and supports 29 community plugins across six functional categories for rapid environment setup.

hermes-labs-ai / lintlang

A static linter designed for AI agent configurations and system prompts, utilizing HERM v1.1 scoring to identify issues like unbounded retries or conflicting output formats. It performs deterministic local checks and exports results in SARIF 2.1.0 or JSON formats to ensure configuration integrity.

0xNyk / openclaw-to-hermes

This migration utility transitions OpenClaw environments to Hermes Agent by mapping SOUL.md, MEMORY.md, and skills into Hermes-compatible YAML and JSON formats. It automates the setup of systemd gateway services and handles the conversion of nested authentication structures.

observeco / observeco

This self-healing observability tool monitors multi-agent systems using passive monitoring and active probing without cloud dependencies. It includes a native Hermes Agent plugin for real-time telemetry and establishes config-aware baselines by tracking local configuration files.

handnewb / hermes-voice

This voice-enabled assistant provides an offline, open-mic interface for Hermes Agent with wake word support and no required API keys. It features adaptive turn-taking and barge-in capabilities, supporting 35 languages via Piper and 9 via Kokoro.
