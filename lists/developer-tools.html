breakdown

colbymchenry / codegraph

This tool provides a local, Rust-powered code knowledge graph that integrates with Hermes Agent via an MCP server. It reduces token usage and tool calls by auto-syncing a pre-indexed representation of the codebase on every file change.

junhoyeo / tokscale

A CLI-based utility that tracks token consumption across multiple coding agents, including Hermes and Claude Code. It features a TUI and a 3D contribution graph dashboard, allowing users to submit data for public profiles and leaderboards.

liaohch3 / claude-tap

This local trace viewer enables inspection of API traffic from Hermes Agent and other coding tools while redacting authentication headers for security. It generates self-contained HTML viewers for exported sessions, facilitating the debugging of agent communications.

bergside / typeui

This project offers design systems and layout guidance through MCP servers to assist in building user interfaces with AI. It is compatible with Hermes Agent, Cursor, and GitHub Copilot, supporting any provider that uses markdown or general prompting.

Javis603 / token-monitor

This widget provides real-time tracking of tokens, costs, and rate limits by reading the state of Hermes Agent and other CLI tools directly. It supports multi-device synchronization and offers historical usage breakdowns categorized by session, project, and model.

Salomondiei08 / oh-my-hermes

An opinionated workflow layer that coordinates seven specialized agents to build and operate applications using Hermes Agent. It loads 36 skills and 6 workflows, supporting autonomous execution on both laptops and virtual private servers.

joeynyc / hermes-skins

This community-driven project allows users to customize the Hermes terminal UI with YAML-based themes and ASCII art. It provides visual modifications such as custom banner colors and spinners, including aesthetics like retro DOS and cyberpunk.

AlexAI-MCP / hermes-CCC

This port brings the Hermes Agent brain and 46 core skills natively into the Claude Code Channel without requiring OAuth or external processes. It includes specialized MLOps tools for vLLM, GGUF inference, and reinforcement learning training.

tinyhumansai / tiny.place

This platform establishes a social economy for autonomous agents by providing encrypted messaging via the Signal Protocol and identity registration with human-readable handles. It enables Hermes and other agents to conduct commerce using Solana-based USDC and SOL payments.

unmodeled-tyler / vessel-browser

An AI-native browser designed for autonomous agent control via MCP, featuring a supervisor sidebar for managing workflows. It supports multiple AI providers and includes an undo functionality to revert recent changes made by an agent.

topoteretes / cognee-integrations

This project provides memory capabilities for various frameworks and includes a plugin for Claude Code that enables automatic context recall. It also offers chat bot integrations for platforms such as Telegram, Slack, and VS Code.

adityahimaone / hermes-agent-rtk-caveman

This setup utilizes RTK and Caveman templating to achieve 90-99% token savings for Hermes Agent workflows. It includes over 40 pre-configured skills for finance and research, supported by an automated cross-platform installation process.

Abruptive / Ankh.md

Ankh.md is a TAW Agent framework that enables per-folder scoping for Hermes Agents through local configurations and skills. It allows users to seamlessly switch between default and scoped agents while supporting project-local memories, tools, and custom instructions.

42-evey / evey-setup

This tool provides automated installation of a hermes-agent stack and 12+ supporting services at zero cost using free models. It offers three scalable deployment tiers, from minimum viable to production, and supports 29 community plugins across six functional categories.

hermes-labs-ai / lintlang

Lintlang is a static linter for AI agent configurations and system prompts that performs local, deterministic checks without API calls. It flags vague tool descriptions and missing termination conditions, supporting SARIF output for integration with GitHub Code Scanning.

0xNyk / openclaw-to-hermes

This migration utility transitions OpenClaw assets, including SOUL.md, MEMORY.md, and skills, into the Hermes Agent ecosystem. It maps existing configurations and credentials into Hermes-compatible YAML and JSON formats while setting up necessary systemd gateway services.

observeco / observeco

Observeco provides self-healing observability for multi-agent systems through passive monitoring and active probing without cloud dependencies. It includes a native Hermes Agent plugin for real-time telemetry and establishes config-aware baselines by watching local files.

handnewb / hermes-voice

This voice-enabled personal assistant adds offline, open-mic capabilities to Hermes Agent with support for 35 languages and wake word detection. It features adaptive turn-taking and barge-in functionality without requiring API keys or external accounts.

33hodl / hermes-startup

Hermes-startup is a local-first skill designed to help users generate revenue online using dynamic slash commands and a deterministic local runtime. The tool prioritizes security by requiring explicit approval for any external actions or write operations.

181079342 / hermes-memoss

This memory plugin for Hermes integrates with MemOS to provide semantic search and multi-dimensional memory storage. It includes dedicated tools for managing memories and features a circuit breaker to handle MemOS API outages.
