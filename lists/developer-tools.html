breakdown

colbymchenry / codegraph

Codegraph builds a local project knowledge graph with `codegraph init` and automatically syncs it as files change. Its MCP server connects that pre-indexed code context to Hermes Agent and other coding agents, with the stated goal of reducing token usage and tool calls.

junhoyeo / tokscale

Tokscale tracks token usage and costs across Hermes and a range of other AI coding agents and tools. Its CLI and visualization dashboard make it a cross-agent usage tracker for developers working across multiple tools.

Javis603 / token-monitor

Token Monitor provides a real-time widget for token usage, costs, tool limits, and session details, reading Hermes Agent state alongside several other CLIs. It also shows historical trends and usage breakdowns, with multi-device sync.

liaohch3 / claude-tap

Claude Tap records and displays coding-agent API traces, including prompts, tool calls, streaming responses, and token usage. Developers can compare adjacent requests to inspect context changes, and the tool redacts common auth headers before recording traces.

bergside / typeui

TypeUI provides design skills, UI prompts, and layout guidance for building interfaces with AI. It supports providers that accept Markdown or general prompting and connects to coding tools through TypeUI MCP or plugins.

Salomondiei08 / oh-my-hermes

Oh My Hermes is an installable workflow layer for building, shipping, and operating apps with Hermes Agent. It includes product-development and operations skills, plus a CTO loop made up of seven focused agents.

joeynyc / hermes-skins

Hermes Skins is a community CLI for themes and skins for the Hermes terminal UI. Users can create skins with YAML files, and custom skins inherit values they do not specify from the default skin.

hermes-labs-ai / lintlang

Lintlang statically checks agent-facing content in project directories, including agent configs, tool descriptions, and system prompts. Its findings include file locations and suggested fixes, and it supports CI gates and reviewed baselines.

tinyhumansai / tiny.place

Tiny.place describes itself as a social economy for autonomous AI agents. It provides encrypted agent-to-agent messaging via Signal Protocol, identity registration with human-readable @handles, and commerce using Solana-based USDC and SOL payments.

unmodeled-tyler / vessel-browser

Vessel Browser is an AI-native browser built for autonomous agent control via MCP, with support for Anthropic, OpenAI, Ollama, and other AI providers. Its supervisor sidebar manages agent approvals, checkpoints, and conversation threads, and it supports external MCP clients and browser automation workflows.

AlexAI-MCP / hermes-CCC

Hermes-CCC ports the Hermes Agent brain and 46 core skills to Claude Code Channel, where it runs without separate processes or OAuth. It also includes MLOps tools for vLLM, GGUF inference, and RL training.

topoteretes / cognee-integrations

Cognee Integrations is a monorepo of Cognee-owned integration packages organized into permanent knowledge graph and session cache tiers. Its Claude Code plugin automatically captures and recalls context.

adityahimaone / hermes-agent-rtk-caveman

This setup combines RTK and Caveman templating for token-saving CLI workflows, with a stated 90–99% token savings. It includes 40+ preconfigured skills for finance, DevOps, and research, plus automated installation for macOS and Linux.

Abruptive / Ankh.md

Ankh.md provides per-folder configuration for creating scoped Hermes Agents, including local skills, memories, tools, and instructions. It can switch between the default agent and a scoped agent, making it suited to projects that need distinct local contexts.

Sahil-SS9 / hermes-project-stewardship

This project supports durable stewardship workflows for Hermes agent fleets, using Hermes Projects and Kanban as the record for projects and tasks. It verifies project state before changes, fails closed when that state is unclear, and supports per-project autonomy levels with human approval of proposals.

42-evey / evey-setup

This project automates installation of hermes-agent and 12+ supporting services, with three deployment tiers ranging from a minimum viable setup to a production stack. It also supports 29 community plugins across six functional categories.

0xNyk / openclaw-to-hermes

This migration tool transfers OpenClaw data—including SOUL.md, MEMORY.md, skills, and memory archives—to Hermes. It also maps configurations and credentials to Hermes YAML and JSON formats and can set up systemd gateway services.

observeco / observeco

Observeco is a Hermes plugin that exports real-time telemetry from agent conversations for monitoring and recovery. It offers zero-token passive analysis or scheduled active probing, and uses local file changes to detect performance drift against config-aware baselines.

handnewb / hermes-voice

This project adds voice interaction to Hermes Agent, with adaptive turn-taking and barge-in capabilities. It supports 35 languages via Piper and 9 via Kokoro, and runs offline without API keys or accounts.

33hodl / hermes-startup

hermes-startup provides a deterministic local runtime that operates with zero network access by default. It requires explicit approval for consequential actions and external writes, and includes contracts for opportunities, offer previews, and exact approvals.

181079342 / hermes-memoss

This Hermes memory plugin supports semantic search and multidimensional memory storage, with tools to search, add, and delete memories. It also includes a circuit breaker for MemOS API outages.
