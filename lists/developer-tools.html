breakdown

colbymchenry / codegraph

This Rust-powered kernel provides a local pre-indexed code knowledge graph designed to reduce token usage and tool calls for Hermes Agent. It supports Windows, macOS, and Linux and features automatic project synchronization.

junhoyeo / tokscale

This CLI tool tracks token usage across multiple AI clients and coding agents, including Hermes and Claude Code. It features a native Rust TUI and a visualization dashboard for monitoring local agent session data.

liaohch3 / claude-tap

This tool acts as a local trace viewer for inspecting API traffic from agents like Hermes Agent, Claude Code, and Cursor. It allows users to export local trace sessions to HTML and redacts common auth headers during recording.

bergside / typeui

This tool provides design systems and layout guidance via MCP servers to assist in building UIs with AI. It is compatible with any AI provider supporting markdown and integrates with Hermes Agent, Cursor, and Claude.

Salomondiei08 / oh-my-hermes

This opinionated workflow layer coordinates seven specialized agents to build, ship, and operate applications. It includes 36 skills and 6 workflows that support autonomous execution on laptops or a VPS.

joeynyc / hermes-skins

This community CLI tool allows for the customization of Hermes terminal UI elements like banner colors, spinners, and ASCII art. It uses YAML-based configuration to enable the creation of diverse themes, such as cyberpunk or retro DOS aesthetics.

tinyhumansai / tiny.place

This platform facilitates a social economy for autonomous agents using encrypted agent-to-agent messaging via the Signal Protocol. It supports identity registration with human-readable @handles and commerce through Solana-based USDC and SOL payments.

AlexAI-MCP / hermes-CCC

This project is a port of the Hermes Agent brain and 46 core skills to the Claude Code Channel. It runs natively within CCC without separate processes or OAuth and includes MLOps tools for RL training and GGUF inference.

unmodeled-tyler / vessel-browser

This AI-native browser is built for autonomous agent control via MCP. It provides a visible UI for real-time AI supervision and includes integrated session management and a research desk.

adityahimaone / hermes-agent-rtk-caveman

This setup utilizes RTK and Caveman templating to achieve 90-99% token savings through specialized CLI workflows. It includes over 40 pre-configured skills for research, devops, and finance on macOS and Linux.

Abruptive / Ankh.md

This TAW Agent framework enables the creation of scoped Hermes Agents using per-folder local configurations and skills. It allows for seamless switching between default and scoped agents while supporting project-local memories and tools.

42-evey / evey-setup

This tool automates the installation of the hermes-agent stack and over 12 supporting services. It offers three scalable deployment tiers and supports 29 community plugins across six functional categories.

roli-lpci / lintlang

This static linter validates AI agent configurations, tool descriptions, and system prompts using regex and structural heuristics. It supports JSON, YAML, plain text, Markdown, and.prompt files without requiring model or API calls, and includes HERM v1.1 scoring.

0xNyk / openclaw-to-hermes

This migration tool facilitates the transition from OpenClaw to Hermes Agent by transferring SOUL.md, MEMORY.md, skills, and memory archives. It maps OpenClaw configs and credentials into Hermes YAML and JSON formats while setting up systemd gateway services.

observeco / observeco

This observability tool provides self-healing capabilities for multi-agent systems through automated operational and functional health monitoring. It includes a beta Hermes plugin that exports telemetry for API requests and tool calls, alongside token intelligence tracking for cost estimation and memory bloat.
