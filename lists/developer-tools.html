breakdown

colbymchenry / codegraph

Codegraph builds a full project knowledge graph with `codegraph init`, using structural extraction and cross-file resolution across supported languages. Its MCP support for multiple coding agents makes pre-indexed code context available to Hermes Agent and other agents while reducing token usage and tool calls.

junhoyeo / tokscale

Tokscale tracks token usage and costs across Hermes, Claude Code, OpenClaw, Codex, Gemini, and other AI coding agents by reading each client’s local storage. It also offers a command to submit usage to a leaderboard and public profile.

liaohch3 / claude-tap

Claude Tap records coding-agent API traffic for local inspection, with support for Hermes Agent, Claude Code, Codex, Gemini CLI, Cursor CLI, and others. It exports trace sessions to a self-contained HTML viewer and redacts common authentication headers before recording.

Javis603 / token-monitor

Token Monitor displays token usage, costs, rate limits, and session details for Hermes Agent and other listed CLIs, reading their local data paths. It adds multi-device sync and historical usage trends for monitoring activity over time.

bergside / typeui

TypeUI provides design systems and layout guidance through MCP servers, and also works with AI providers that support markdown or general prompting. Its integrations include Hermes Agent, Cursor, Claude, and GitHub Copilot, making it a design-focused tool in this developer-tools list.

Salomondiei08 / oh-my-hermes

Oh My Hermes adds an opinionated workflow layer for building, shipping, and operating apps with Hermes Agent. It includes skills for product briefs, design handoffs, and implementation, plus seven agents spanning product lifecycle roles and GitHub integration for issue and pull request delivery.

joeynyc / hermes-skins

Hermes Skins is a community CLI for customizing the Hermes terminal UI, including banner colors, spinners, and ASCII art. YAML-based configuration lets users create themes, with examples ranging from retro DOS to cyberpunk styles.

hermes-labs-ai / lintlang

Lintlang is a command-line static linter for AI agent configurations, tool descriptions, and system prompts, using HERM v1.1 scoring. It scans prompts, tool definitions, schemas, and agent files, then reports findings with specific fixes and supported line references.

tinyhumansai / tiny.place

Tiny.place describes itself as a social economy for autonomous AI agents, with encrypted agent-to-agent messaging using Signal Protocol and identity registration through human-readable @handles. It also supports commerce using Solana-based USDC and SOL payments.

unmodeled-tyler / vessel-browser

Vessel Browser is an AI-native browser designed for autonomous agent control through MCP, with support for Anthropic, OpenAI, Ollama, and other AI providers. Its supervisor sidebar manages agent approvals, checkpoints, and conversation threads, alongside support for external MCP clients and browser automation workflows.

AlexAI-MCP / hermes-CCC

Hermes-CCC ports the Hermes Agent brain and 46 core skills to Claude Code Channel, running natively in Claude Code without a separate process or OAuth. It also includes MLOps tools for vLLM, GGUF inference, and RL training.

topoteretes / cognee-integrations

Cognee Integrations is a monorepo of Cognee-owned integration packages with two tiers: a permanent knowledge graph and a session cache. Its Claude Code plugin automatically captures and recalls context.

adityahimaone / hermes-agent-rtk-caveman

This setup combines RTK and Caveman templating with preconfigured CLI workflows, with the project reporting 90–99% token savings. It also bundles 40+ skills for finance, DevOps, and research and provides automated installation for macOS and Linux.

Abruptive / Ankh.md

Ankh.md is a framework for creating scoped Hermes Agents with folder-specific configuration, skills, memories, tools, and instructions. It switches between the default agent and a scoped agent, making it suited to workflows that need project-local behavior.

42-evey / evey-setup

evey-setup automates installation of Hermes Agent and 12+ supporting services, with three deployment tiers ranging from a minimum viable setup to a production stack. It also supports 29 community plugins across six functional categories.

0xNyk / openclaw-to-hermes

This tool migrates OpenClaw data—including SOUL.md, MEMORY.md, skills, and memory archives—to Hermes. It also maps configurations and credentials to Hermes YAML and JSON formats and can set up systemd gateway services.

observeco / observeco

observeco monitors AI agents through a native Hermes plugin that exports real-time conversation telemetry. Its two monitoring modes include zero-token passive analysis and scheduled active probing, while config-aware baselines track performance drift relative to local file changes.

handnewb / hermes-voice

hermes-voice adds voice interaction to Hermes Agent, with wake-word support, adaptive turn-taking, and barge-in. It runs offline without API keys or accounts and supports 35 languages via Piper and nine via Kokoro.

33hodl / hermes-startup

hermes-startup is a local runtime for pursuing online opportunities, operating in deterministic zero-network mode by default. It requires explicit approval for consequential actions and external writes, and includes contracts for opportunities, offer previews, and exact approvals.

181079342 / hermes-memoss

hermes-memoss is a MemOS memory plugin that supports semantic search and multidimensional memory storage. It provides tools to search, add, and delete memories, and includes a circuit breaker for MemOS API outages.
