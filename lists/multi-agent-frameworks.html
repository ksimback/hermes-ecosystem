breakdown

builderz-labs / mission-control

This self-hosted orchestration stack provides a zero-dependency SQLite environment for dispatching tasks across CrewAI, LangGraph, and AutoGen workflows. It distinguishes itself with the Aegis review system, which implements quality gates to monitor agent spend and task accuracy.

agent-of-empires / agent-of-empires

A versatile control surface that manages parallel sessions for Hermes, Claude Code, and other agents using tmux for persistent background execution. It offers a mobile-first web dashboard and TUI, utilizing Docker or Podman to ensure all agent activities remain sandboxed.

CryptoDmitry / hermes-agent-control-room

This template introduces a sidecar control plane focused on agent governance and documentation for scaling from single VPS instances to specialist teams. It utilizes a structured task bus pattern to facilitate formal delegation between orchestrators and sub-agents.

Agent-3-7 / minions

Minions provides a centralized mission control interface featuring a Kanban board for tracking autonomous task statuses and review queues. It emphasizes human-in-the-loop verification by live-streaming agent reasoning and tool execution for real-time supervision.

swarmclawai / swarmclaw

This framework enables the creation of autonomous swarms across 23+ providers, including Ollama and Hermes, with built-in heartbeats and scheduling. It features a unique 'conversation-to-skill' learning mechanism and durable memory to evolve agent capabilities over time.

shannhk / hermes-agent-control-room

Designed for infrastructure-heavy workflows, this level-based architecture scales Hermes from a single agent to automated teams capable of VPS provisioning and security auditing. It leverages a task bus pattern to manage handoffs and specialized skill sets for system administration.

linke-ai / hermes-agent-team

A local collaboration system that orchestrates Leader and Specialist agents using MCP and ACP protocols for tool handling. The platform integrates a real-time Web UI and Hermes Kanban to monitor the entire lifecycle of agent dialogues and task progress.

1ilkhamov / opencode-hermes-multiagent

This project deploys a massive cohort of 17 specialized agents dedicated to distinct phases like research, planning, and infrastructure. It enforces strict quality gates through mandatory reviewer and tester agents to ensure code integrity across customizable pipelines.

howdymary / hermes-agent-metaharness

A meta-optimization framework that uses an automated outer-loop search to refine the harness code of Hermes agents. It tracks performance frontiers by orchestrating TBLite and TB2 benchmarks, utilizing candidate mutation to improve agent efficiency.

runtimenoteslabs / gladiator

Gladiator creates a competitive arena where two autonomous AI companies, powered by Hermes and Paperclip, compete for GitHub stars. The system orchestrates nine agents per side and visualizes their code execution and scoreboard metrics on a real-time dashboard.

Rainhoole / hermes-agent-acp-skill

This delegation tool routes tasks between Hermes, Codex, and Claude Code while preventing parent context pollution through isolated workflows. It prioritizes safety by enforcing configurable timeouts and strict output character limits on all delegated sub-tasks.
