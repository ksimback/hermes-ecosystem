breakdown

builderz-labs / mission-control

A self-hosted orchestration dashboard that manages multi-agent workflows across frameworks like CrewAI, LangGraph, and AutoGen. It provides a secure, zero-dependency environment featuring integrated secret detection and spend monitoring.

agent-of-empires / agent-of-empires

A TUI and PWA control surface designed for managing diverse coding agents within sandboxed Docker or Podman containers. It enables parallel execution across multiple git worktrees and repositories for high-scale development.

CryptoDmitry / hermes-agent-control-room

A tiered architecture template that scales Hermes agents from single VPS instances to automated specialist teams. It utilizes a task bus pattern for efficient delegation and includes bundled skills for security auditing and registry management.

shannhk / hermes-agent-control-room

A level-based scaling template for Hermes Agent that facilitates the transition from individual agents to orchestrated teams. It employs a task bus for agent handoffs and provides built-in skills for VPS provisioning and backup management.

swarmclawai / swarmclaw

A framework for building autonomous agent swarms that supports over 23 LLM providers, including Hermes and Ollama. It features durable memory and the ability for agents to learn new skills directly from conversations.

Agent-3-7 / minions

A supervision interface for Hermes agents that uses a Kanban board to track autonomous task status and review queues. It ensures quality through live streaming of agent reasoning and mandatory human-in-the-loop verification.

1ilkhamov / opencode-hermes-multiagent

A specialized pipeline of 17 agents dedicated to end-to-end software development, from research to infrastructure. It enforces strict quality and security gates and integrates MCP servers for web fetching and documentation.

linke-ai / hermes-agent-team

A local collaboration system that orchestrates Leader and Specialist agents using MCP and ACP protocols. It provides a real-time Web UI to monitor agent dialogues and manage task flows via an integrated Kanban system.

howdymary / hermes-agent-metaharness

A meta-optimization harness that uses automated outer-loop searches to refine agent code based on arXiv research. It orchestrates TBLite and TB2 benchmark evaluations to track and improve performance frontiers.

runtimenoteslabs / gladiator

An agent-vs-agent arena where autonomous AI companies compete for GitHub stars. It orchestrates nine agents using Paperclip and Hermes Agent, visualizing their tasks and scoreboard metrics on a real-time dashboard.

Rainhoole / hermes-agent-acp-skill

An ACP-style delegation system that routes tasks between Hermes subagents, Codex, and Claude Code. It prevents parent context pollution through isolated workflows and enforces safety via configurable timeouts and output limits.
