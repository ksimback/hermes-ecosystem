breakdown

TauricResearch / TradingAgents

This framework deploys specialized agents to conduct fundamental, sentiment, and technical analysis for financial trading. It utilizes a researcher team to perform bullish and bearish debates, with final approvals handled by dedicated risk management and portfolio manager agents.

builderz-labs / mission-control

This self-hosted orchestration platform governs agent registration, task dispatching, memory browsing, and cost tracking. It supports local or Docker-based deployment and provides multiple interfaces including a Web UI, CLI, and MCP server.

agent-of-empires / agent-of-empires

This control surface manages persistent coding agent sessions, including Hermes Agent and Claude Code, using tmux for background execution. It facilitates multi-repo workspace management through Git worktrees and provides sandboxing via Docker, Podman, or Apple Containers.

CryptoDmitry / hermes-agent-control-room

This execution engine is the first to manage Hermes agents on the Solana blockchain using the Claude-style MCP protocol. It features HTTP signal detection to manage payment-required states for paid APIs during orchestrated workflows.

shannhk / hermes-agent-control-room

This template uses a level-based architecture to scale Hermes Agent from single VPS instances to automated teams. It implements a task bus pattern for delegation and includes bundled skills for security auditing and VPS provisioning.

swarmclawai / swarmclaw

This framework enables the construction of autonomous agent swarms with durable memory and support for over 23 LLM providers. It features MCP tool integration and provides visual org charts to manage agent team delegation.

agent37-platform / minions

This mission control interface uses a Kanban board to track autonomous task statuses and review queues for Hermes agents. It provides live streaming of agent reasoning and requires human-in-the-loop verification for all proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This project coordinates 17 specialized agents across research, planning, and infrastructure roles using a strict pipeline architecture. A Master Orchestrator manages all routing and coordination between these specialized entities.

linke-ai / hermes-agent-team

This local web system orchestrates Leader and Specialist agents to manage the automated task lifecycle. It integrates MCP and ACP protocols for tool handling and features a real-time UI for monitoring agent dialogues and Kanban flows.

howdymary / hermes-agent-metaharness

This meta-harness automates the outer-loop optimization of benchmark harness code for Hermes Agent. It orchestrates TBLite and TerminalBench-2 evaluations while providing structured candidate mutation and frontier tracking.

runtimenoteslabs / gladiator

This arena orchestrates two competing AI companies, each comprising nine autonomous agents, to compete for GitHub stars. It utilizes Paperclip and Hermes Agent for execution and provides a real-time dashboard to visualize code and scoreboard metrics.

InfiniteWhispers / HermesAgent-MultiModel

This fully-local framework implements a Mixture-of-Agents stack optimized for consumer GPUs like the RTX 4080 and 5080. It uses Hermes for task routing and tool-calling through parallel model querying and synthesis without cloud dependencies.
