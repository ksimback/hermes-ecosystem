breakdown

TauricResearch / TradingAgents

This framework utilizes multiple LLM providers to deploy specialized agents for technical, sentiment, news, fundamental, and analysis tasks. It features a researcher team that assesses insights through structured debates.

builderz-labs / mission-control

This orchestration tool supports workflows for CrewAI, LangGraph, AutoGen, and other frameworks through a Web UI, CLI, MCP server, and REST API. It provides capabilities for task tracking, scheduling, and monitoring spend.

agent-of-empires / agent-of-empires

This project provides a TUI and web dashboard for managing parallel coding agents, including Hermes Agent and Claude Code. It utilizes git worktrees for management and offers optional Docker or Podman sandboxing.

CryptoDmitry / hermes-agent-control-room

This template uses a tiered architecture and a task bus pattern to scale from single VPS agents to automated specialist teams. It includes bundled skills for security auditing, registry management, and VPS setup.

shannhk / hermes-agent-control-room

This framework employs a level-based architecture and a task bus pattern to scale Hermes Agent from single agents to automated teams. It provides bundled skills for backup management, security auditing, and VPS provisioning.

swarmclawai / swarmclaw

This framework enables the construction of autonomous agent swarms using over 23 LLM providers. It features durable agent memory, MCP tool integration, and visual org charts for team delegation.

agent37-platform / minions

This mission control interface allows users to create, supervise, and review autonomous Hermes Agent work via a Kanban board. It provides live streaming of agent reasoning and tool execution alongside human-in-the-loop verification.

1ilkhamov / opencode-hermes-multiagent

This system coordinates 17 specialized agents across research, planning, implementation, quality, and infrastructure roles. It utilizes a strict pipeline architecture governed by a Master Orchestrator for routing.

linke-ai / hermes-agent-team

This web system orchestrates Leader and Specialist agents for automated task lifecycle management. It integrates MCP and ACP protocols and provides a real-time Web UI for monitoring agent dialogues and Kanban flows.

howdymary / hermes-agent-metaharness

This meta-harness automates the outer-loop optimization of benchmark harness code. It orchestrates TBLite and TerminalBench-2 evaluations while providing structured candidate mutation and frontier tracking.

runtimenoteslabs / gladiator

This arena orchestrates nine autonomous agents representing two competing AI companies. It uses Paperclip and Hermes Agent for task execution and provides a real-time dashboard for scoreboard metrics and code visualization.

InfiniteWhispers / HermesAgent-MultiModel

This framework implements a Mixture-of-Agents stack via parallel model querying and synthesis for local execution. It uses Hermes for task routing and tool-calling, optimized for consumer GPUs like the RTX 4080/5080.
