breakdown

builderz-labs / mission-control

A self-hosted orchestration layer that manages multi-agent workflows across frameworks like CrewAI and LangGraph. It features a zero-dependency SQLite stack and Aegis quality gates to ensure mandatory task sign-off.

agent-of-empires / agent-of-empires

A TUI and PWA control surface designed for monitoring various coding agents, including Hermes Agent and Claude Code. It enables parallel execution across git worktrees using Docker, Podman, or Apple Containers for sandboxing.

CryptoDmitry / hermes-agent-control-room

A tiered architecture template that scales Hermes agents from a single VPS instance to orchestrated specialist teams. It utilizes a task bus pattern for delegation and includes bundled skills for security auditing and registry management.

shannhk / hermes-agent-control-room

A level-based scaling template for Hermes Agent that facilitates the transition from individual agents to automated teams. It implements a task bus for orchestrator-to-specialist handoffs and provides skills for VPS provisioning and backup management.

swarmclawai / swarmclaw

A framework for building autonomous agent swarms with support for over 23 LLM providers, including Ollama and OpenRouter. It provides visual org charts for team orchestration alongside durable memory and scheduled execution.

Agent-3-7 / minions

A supervision hub for Hermes agents featuring a Kanban board to track autonomous task status and review queues. It allows users to monitor live reasoning streams and perform human-in-the-loop verification of all completions.

1ilkhamov / opencode-hermes-multiagent

A pipeline that coordinates 17 specialized agents focused on research, implementation, and infrastructure. It automates the full development lifecycle from bug fixes to performance optimization while enforcing mandatory security audits.

linke-ai / hermes-agent-team

A local collaboration system that orchestrates Leader and Specialist agents using MCP and ACP protocols. It provides a real-time Web UI to monitor agent dialogues and manage the task lifecycle via Hermes Kanban.

howdymary / hermes-agent-metaharness

A meta-optimization harness that uses an automated outer-loop search to refine agent code. It orchestrates TBLite and TB2 benchmark evaluations to track performance frontiers through candidate mutation.

runtimenoteslabs / gladiator

An agent-vs-agent arena where autonomous AI companies compete for GitHub stars. It orchestrates nine agents using Paperclip and Hermes Agent, visualizing the competition via a real-time scoreboard and task dashboard.

Rainhoole / hermes-agent-acp-skill

An ACP-style delegation tool that routes tasks between Hermes subagents, Codex, and Claude Code. It prevents parent context pollution through isolated workflows and enforces safety via configurable timeouts and character limits.
