breakdown

TauricResearch / TradingAgents

TradingAgents is a multi-agent framework for financial trading, with fundamental analysts assessing company financials and performance metrics and sentiment analysts aggregating news headlines and social chatter. Selected analysts work in parallel using their own tools, making the project a specialized example of coordinated agents for market analysis.

builderz-labs / mission-control

Mission Control governs agent registration, task dispatch, memory browsing, and cost tracking for multi-agent workflows. It stands out for offering a Web UI, CLI, MCP server, and REST API, with local Node.js installation or Docker deployment.

tutti-os / tutti

Tutti is a collaborative workspace where people and agents build together, connecting existing agents using existing subscription credits. Its shared real-time access to files and context, alongside an app ecosystem for image generation and UI design, distinguishes it from agent orchestration tools focused on task routing.

agent-of-empires / agent-of-empires

Agent of Empires provides TUI and web dashboards for managing multiple coding agents, including Hermes Agent, Claude Code, OpenCode, Codex, and Gemini. It maintains persistent background sessions with tmux and supports sandboxing with Docker, Podman, and Apple Containers, as well as diff review.

rlaope / oh-my-hermes

oh-my-hermes adds a coding harness, long-term memory system, optimized subagents, and automatic model-routing packages for Hermes Agent. It works above Hermes-native skills without replacing Hermes and includes setup, update, and diagnostic commands.

Orkas-AI / Orkas

Orkas is a desktop client in which a commander LLM dispatches sub-agents in parallel or series. It includes nine specialist agents at launch, supports different model providers, and is available for macOS, Windows, and Linux.

shannhk / hermes-agent-control-room

Hermes Agent Control Room is a Control Room-first template for scaling from a single VPS agent to specialist teams and automated workflows. Its level-based architecture uses a task bus for orchestrator-to-specialist delegation and handoffs, and bundles skills for VPS provisioning, security auditing, and backup management.

swarmclawai / swarmclaw

Swarmclaw is for building autonomous agent swarms with orchestration, skills, and multiple model providers. It supports 23+ LLM providers, durable agent memory, and MCP tool integration, and uses visual org charts for team delegation.

agent37-platform / minions

Minions is a mission control interface for creating, supervising, and reviewing autonomous Hermes Agent work from one screen. Its Kanban board tracks task status and review queues, while live streaming and human verification support oversight of agent reasoning, tool use, and proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This project coordinates 17 specialized AI agents across research, planning, implementation, quality, and infrastructure. It uses a strict pipeline architecture with a Master Orchestrator for routing and coordination.

linke-ai / hermes-agent-team

Hermes Agent Team is a local web system for collaboration between Leader and Specialist agents, using Hermes Agent profiles, MCP, ACP, and Hermes Kanban. It supports automated task lifecycle management and provides a real-time Web UI for agent dialogues and Kanban task flows.

howdymary / hermes-agent-metaharness

Hermes Agent Metaharness automates outer-loop optimization of benchmark harness code. It orchestrates TBLite and TerminalBench-2 evaluations, with structured candidate mutation and frontier tracking.

runtimenoteslabs / gladiator

Gladiator runs an agent-vs-agent arena in which nine autonomous agents across two competing AI companies work to earn GitHub stars, using Paperclip and Hermes Agent for task execution and learning. Its real-time dashboard shows agent tasks, code, and scoreboard metrics, making it a competition-focused example of multi-agent orchestration.

InfiniteWhispers / HermesAgent-MultiModel

HermesAgent-MultiModel runs a fully local Mixture-of-Agents stack, querying multiple models in parallel and synthesizing their responses, with Hermes handling task routing and tool calls. Its focus on consumer GPUs and no cloud dependencies distinguishes it as a local multi-model approach.
