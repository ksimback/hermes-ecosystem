breakdown

TauricResearch / TradingAgents

TradingAgents is a financial trading framework that assigns trading tasks to agents in specialized roles and has them discuss strategies dynamically. It is designed for research purposes.

builderz-labs / mission-control

Mission Control is a self-hosted system for governing agent tasks, registrations, memory browsing, and cost tracking. It stands out for offering Web UI, CLI, MCP server, and REST API interfaces, with local Node.js installation or Docker deployment.

agent-of-empires / agent-of-empires

Agent of Empires provides a TUI and web control surface for managing multiple coding agents, including Hermes Agent. It supports persistent tmux sessions, Git worktrees, and multi-repository workspaces, with a web dashboard for structured views, terminal access, and diffs.

shannhk / hermes-agent-control-room

Hermes Agent Control Room is a template for scaling Hermes Agent from a single VPS agent to specialist teams and automated workflows. Its level-based architecture and task bus support delegation and handoffs, and it includes skills for VPS provisioning, security auditing, and backup management.

swarmclawai / swarmclaw

SwarmClaw is a framework for building autonomous agent swarms, with support for 23+ LLM providers, durable agent memory, and MCP tool integration. Visual org charts provide a way to represent team delegation.

agent37-platform / minions

Minions is a control interface for creating, supervising, and reviewing autonomous Hermes Agent work. It combines a Kanban board and live streams of agent reasoning and tool execution with human verification of agent-proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This project coordinates 17 specialized agents across research, planning, implementation, quality, and infrastructure. A strict pipeline architecture and Master Orchestrator handle routing and coordination.

linke-ai / hermes-agent-team

Hermes Agent Team is a local web system for coordinating Leader and Specialist agents through an automated task lifecycle. It integrates MCP and ACP for local tools and communication, with a real-time UI for agent dialogues and Kanban task flows.

howdymary / hermes-agent-metaharness

Hermes Agent Metaharness automates outer-loop optimization of benchmark harness code and orchestrates TBLite and TerminalBench-2 evaluations. It also provides structured candidate mutation and frontier tracking.

runtimenoteslabs / gladiator

Gladiator runs an agent-versus-agent arena in which nine autonomous agents operate across two competing AI companies. Using Paperclip and Hermes Agent for task execution and learning, it displays agent tasks, code, and scoreboard metrics on a real-time dashboard.

InfiniteWhispers / HermesAgent-MultiModel

HermesAgent-MultiModel is a local Mixture-of-Agents framework that queries models in parallel and synthesizes their outputs, using Hermes for task routing and tool-calling. It is designed for consumer GPUs, is optimized for RTX 4080/5080 hardware, and does not require cloud dependencies.
