breakdown

TauricResearch / TradingAgents

This framework deploys specialized agents to conduct fundamental, sentiment, and technical analysis for financial trading. It utilizes a structured debate format between bullish and bearish researchers, overseen by risk management and portfolio manager agents who approve final trades.

builderz-labs / mission-control

Mission Control is a self-hosted orchestration platform that governs agent registration, memory browsing, and cost tracking across multi-agent workflows. It offers flexible access through Web UI, CLI, MCP server, and REST API interfaces, supporting both local Node.js and Docker deployments.

agent-of-empires / agent-of-empires

This control surface manages multiple coding agents, including Hermes Agent and Claude Code, through TUI and web-based dashboards with diff review capabilities. It ensures persistent background execution using tmux and provides secure sandboxing via Docker, Podman, and Apple Containers.

shannhk / hermes-agent-control-room

Utilizing a level-based architecture, this template scales Hermes Agent from single VPS instances to automated teams using a task bus pattern for delegation. It includes bundled skills for specialized operations such as VPS provisioning, security auditing, and backup management.

swarmclawai / swarmclaw

Swarmclaw enables the construction of autonomous agent swarms supported by durable memory and MCP tool integration across more than 23 LLM providers. It features visual org charts to help users manage and visualize agent team delegation.

agent37-platform / minions

This mission control interface features a Kanban board for tracking autonomous task statuses and a live stream of agent reasoning and tool execution. It emphasizes human-in-the-loop verification, requiring manual review for all agent-proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This system employs a strict pipeline architecture to coordinate 17 specialized agents across research, planning, implementation, and infrastructure roles. A Master Orchestrator manages the routing and coordination of these agents to ensure structured task execution.

linke-ai / hermes-agent-team

This local web system orchestrates Leader and Specialist agents using MCP and ACP protocols for tool and communication handling. It provides a real-time Web UI for monitoring agent dialogues and managing task lifecycles through a integrated Kanban flow.

howdymary / hermes-agent-metaharness

This meta-harness automates the outer-loop optimization of benchmark harness code, specifically orchestrating TBLite and TerminalBench-2 evaluations. It manages structured candidate mutation and frontier tracking to optimize agent performance.

runtimenoteslabs / gladiator

Gladiator creates an arena where two autonomous AI companies, powered by nine agents using Paperclip and Hermes Agent, compete for GitHub stars. A real-time dashboard visualizes the competition, displaying agent tasks, code, and live scoreboard metrics.

InfiniteWhispers / HermesAgent-MultiModel

This fully-local framework implements a Mixture-of-Agents stack that uses Hermes for task routing and tool-calling without cloud dependencies. It is optimized for consumer GPUs like the RTX 4080/5080, utilizing parallel model querying and synthesis via Ollama.
