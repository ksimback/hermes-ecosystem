breakdown

TauricResearch / TradingAgents

This framework deploys specialized agents to conduct fundamental, sentiment, and technical analysis for financial trading. It features a dedicated researcher team for bullish and bearish debates, alongside risk management and portfolio manager agents for final decision approvals.

builderz-labs / mission-control

This self-hosted orchestration platform governs agent registration, task dispatching, and cost tracking through a Web UI, CLI, or REST API. It supports multi-agent workflows and memory browsing with deployment options via Node.js or Docker.

tutti-os / tutti

Tutti provides a collaborative workspace where human users and agents build together using shared files and real-time context. The system connects existing agents using current subscription credits and includes an app ecosystem for UI design and image generation.

agent-of-empires / agent-of-empires

This control surface manages multiple coding agents, including Hermes Agent and Claude Code, across persistent tmux sessions for background execution. It supports multi-repo management via Git worktrees and provides environment sandboxing through Docker, Podman, and Apple Containers.

Orkas-AI / Orkas

Orkas is a desktop client where a commander LLM dispatches nine built-in specialist agents in parallel or series for research, media, and development. The system stores all data locally and supports self-evolution through reflection and skill crystallization.

rlaope / oh-my-hermes

This package adds an operating layer to Hermes Agent that provides planning, research, and long-term project memory. It integrates with Hermes Desktop and CLI applications and can be installed via Homebrew, Bun, or npm.

CryptoDmitry / hermes-agent-control-room

This template serves as an MCP agent execution engine on the Solana blockchain for managing specialist teams and orchestrated workflows. It supports the Claude-style MCP protocol in stdio mode and includes detection for payment-required states for paid APIs.

shannhk / hermes-agent-control-room

Utilizing a level-based architecture, this template scales Hermes Agent from single VPS instances to automated teams using a task bus pattern for delegation. It includes bundled skills for security auditing, VPS provisioning, and backup management.

swarmclawai / swarmclaw

Swarmclaw enables the construction of autonomous agent swarms with durable memory and MCP tool integration across more than 23 LLM providers. It features visual org charts to manage and view agent team delegations.

agent37-platform / minions

This mission control interface allows users to supervise autonomous Hermes Agent work through a Kanban board and live reasoning streams. It enforces human-in-the-loop verification for all agent-proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This project coordinates 17 specialized AI agents across research, planning, quality, and infrastructure domains. It utilizes a strict pipeline architecture managed by a Master Orchestrator for routing and coordination.

linke-ai / hermes-agent-team

This local web system orchestrates Leader and Specialist agents for automated task lifecycle management using Hermes Agent profiles. It integrates MCP and ACP protocols for tool handling and provides a real-time UI for monitoring dialogues and Kanban flows.

howdymary / hermes-agent-metaharness

This meta-optimization framework automates the outer-loop refinement of benchmark harness code for Hermes Agent. It orchestrates TBLite and TerminalBench-2 evaluations while utilizing structured candidate mutation and frontier tracking to improve agent performance.

runtimenoteslabs / gladiator

This project creates a competitive arena where two autonomous AI companies, powered by Hermes Agent and Paperclip, compete for GitHub stars. It orchestrates nine agents across these organizations and provides a real-time dashboard to visualize task execution, code generation, and scoreboard metrics.

InfiniteWhispers / HermesAgent-MultiModel

This framework implements a fully-local Mixture-of-Agents stack that utilizes Hermes for task routing and tool-calling without cloud dependencies. It is optimized for consumer GPUs like the RTX 4080/5080, leveraging parallel model querying and synthesis to execute complex workflows.
