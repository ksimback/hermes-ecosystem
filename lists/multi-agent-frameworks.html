breakdown

TauricResearch / TradingAgents

This framework utilizes multiple LLM providers and local Ollama models to power fundamental, sentiment, news, and technical analysts. It employs structured-output agents to facilitate financial trading decision making.

builderz-labs / mission-control

This orchestration platform supports workflows for CrewAI, LangGraph, AutoGen, and other agents via a Web UI, CLI, MCP server, or REST API. It provides capabilities for task tracking, memory browsing, scheduling, and spend monitoring.

agent-of-empires / agent-of-empires

This project provides a TUI, web dashboard, and CLI to manage various coding agents, including Claude Code and Gemini CLI. It offers optional sandboxing through Docker, Podman, or Apple containers.

CryptoDmitry / hermes-agent-control-room

This template uses a tiered architecture and a task bus pattern to scale from single agents to automated specialist teams. It includes bundled skills for VPS setup, security auditing, and registry management.

shannhk / hermes-agent-control-room

This level-based architecture enables scaling from single agents to automated teams using a task bus pattern for delegation and handoffs. It features bundled skills for VPS provisioning, security auditing, and backup management.

swarmclawai / swarmclaw

This framework enables the construction of autonomous agent swarms using over 23 LLM providers, including OpenAI and Ollama. It features durable agent memory, MCP tool integration, and visual org charts for team delegation.

agent37-platform / minions

This mission control interface allows users to create, supervise, and review autonomous Hermes Agent work through a Kanban board and review queues. It provides live streaming of agent reasoning and tool execution alongside human-in-the-loop verification.

linke-ai / hermes-agent-team

This web system orchestrates Leader and Specialist agents for automated task lifecycle management. It integrates MCP and ACP protocols for local communication and tool handling, featuring a real-time Web UI for monitoring dialogues and Kanban flows.

1ilkhamov / opencode-hermes-multiagent

This system coordinates 17 specialized agents across research, planning, implementation, quality, and infrastructure. It utilizes a strict pipeline architecture managed by a Master Orchestrator for routing and coordination.

howdymary / hermes-agent-metaharness

This meta-harness automates the outer-loop optimization of benchmark harness code. It orchestrates TBLite and TerminalBench-2 evaluations while providing structured candidate mutation and frontier tracking.

runtimenoteslabs / gladiator

This arena orchestrates nine autonomous agents representing two competing AI companies. It uses Paperclip and Hermes Agent for task execution and features a real-time dashboard for visualizing tasks, code, and scoreboard metrics.

Rainhoole / hermes-agent-acp-skill

This system routes tasks between Hermes subagents, Codex, and Claude Code using ACP-style delegation. It prevents parent context pollution through isolated workflows and enforces safety via configurable timeouts and output character limits.

InfiniteWhispers / HermesAgent-MultiModel

This framework implements a Mixture-of-Agents architecture through parallel model querying and synthesis. It utilizes Hermes for tool-calling and task routing to run a fully-local stack on consumer GPUs without cloud dependencies.
