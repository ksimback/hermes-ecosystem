breakdown

nexu-io / open-design

A local-first design and prototyping system that generates prototypes, motion graphics, and images. It integrates with Hermes Agent and other local CLIs to bridge the gap between design and code.

mukul975 / Anthropic-Cybersecurity-Skills

A comprehensive library of 754 cybersecurity skills mapped to major frameworks like MITRE ATT&CK and NIST CSF 2.0. It follows the agentskills.io standard for seamless discovery across AI platforms.

Agents365-ai / drawio-skill

Enables the generation of draw.io diagrams, including ERDs and Flowcharts, from natural language. It can visualize codebase structures for languages like Python, Go, and Rust using thousands of official shapes.

AMAP-ML / SkillClaw

An agentic evolver that automates skill deduplication and quality improvement through background evolution loops. It unifies skill libraries across multiple agents and devices with native Hermes integration.

conorbronsdon / avoid-ai-writing

An auditing tool that detects and rewrites content to eliminate AI writing patterns. It utilizes a two-pass detection system and 49 pattern categories to ensure human-like output.

wondelai / skills

A cross-platform skills library based on industry guidelines and established frameworks. It offers modular installation via npx or a plugin marketplace for agentskills.io-compatible agents.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that monitors active workflows to automatically propose and generate reusable skills. It produces both Python plugin scaffolds and SKILL.md documentation.

DougTrajano / pydantic-ai-skills

Provides type-safe agentskills.io support for Pydantic AI. It uses progressive disclosure of metadata to reduce token usage and supports both programmatic and filesystem-based definitions.

ZeroPointRepo / youtube-skills

A set of tools for extracting YouTube transcripts, captions, and timestamps without relying on yt-dlp. It supports video search and playlist extraction for Hermes Agent and other compatible agents.

amanning3390 / hermeshub

A community hub for browsing and installing skills with automated security scanning and threat detection. It features a creator marketplace with crypto/Stripe payments and an agent-to-agent trust scoring system.

Cranot / super-hermes

Teaches Hermes Agent to generate its own analytical prompts using dynamic 'prisms' for resilience and optimization. It includes constraint reporting to identify analysis blind spots via /prism-reflect.

AkoliteZA / hermes-agent-idea-workflow

A workflow that converts rough ideas into structured design documents and implementation handoffs. It offers Lite and Full modes and includes a PASS/FAIL evaluation gate for spec reviews.

ReinaMacCredy / maestro

A local-first Rust harness for long-running agents featuring structured memory and a plan-approve-execute cycle. It uses a durable card model to track tasks and evidence-backed QA gates for verification.

tlehman / litprog-skill

A literate programming tool that weaves code and documentation into .lit.md files. It uses a tangler to extract runnable source files and automatically syncs edits back to the documentation.

esaradev / icarus-plugin

Implements cross-instance shared memory via markdown files to capture high-value decisions. It includes a pipeline for fine-tuning and switching to replacement models based on captured work.

smartcontractkit / chainlink-agent-skills

Provides agentskills.io-compliant tools for interacting with the Chainlink oracle network. It supports integrations for CCIP, VRF, and Data Feeds, installable via the Vercel skills CLI.

armelhbobdad / bmad-module-skill-forge

Converts repositories, documentation, and developer discourse into compliant agentskills.io skills. It ensures provenance through pinned commits and file-line citations.

black-forest-labs / skills

Official FLUX image generation skills providing standardized prompting guidelines for FLUX.1 and FLUX.2. It includes API integration patterns for webhooks and precise hex color specifications.

chigwell / skilldock.io

A registry of reusable AI skills featuring a versioned installation system with recursive dependency resolution. It provides an OpenAPI-driven Python client and supports Stripe and TON payment rails.

tiann / execplan-skill

Enables autonomous execution of complex, multi-step tasks with real-time progress tracking. It includes built-in rollback procedures to ensure safe recovery during long-running operations.

cablate / Agentic-MCP-Skill

A progressive MCP client that uses three-layer lazy loading to minimize token consumption. It utilizes a socket-based daemon architecture to support hot-reloading of server configurations.

adnw-vinc / hermes-nextcloud

Integrates Hermes Agent with Nextcloud to manage files, calendars, and contacts via WebDAV and CalDAV. It ensures secure communication using HTTPS and Nextcloud App Passwords.

PederHP / skillsdotnet

A C#/.NET implementation of the agentskills.io specification with MCP integration. It leverages Microsoft.Extensions.AI for tool-based loading and supports automatic directory registration.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

A plugin that rewrites and scores prompts across various surfaces like Discord and Telegram. It tailors outputs based on model reasoning capabilities and tracks token savings in a local SQLite database.

Sahil-SS9 / hermaguard

An adversarial code review tool that uses three parallel subagents to hunt for bugs and exploitability. It integrates Semgrep and Bandit for pre-scanning and uses an MCP server to manage suppression rules.

Sahil-SS9 / hermes-simplify-swarm

A multi-agent swarm that simplifies code by targeting hygiene, clarity, and correctness. It uses a risk-tiered triage system to safely modify code and detect concurrency anti-patterns.

willingning-coder / eagle-eye

A five-layer retrieval system that uses FTS5, embeddings, and RRF fusion to find the most relevant skills. It reduces token consumption by filtering large skill libraries down to the top five matches.

mag3nt-com / openclaw-skill

Automates payments for HTTP 402 responses using USDC via protocols like Pay Link and x402. It is compatible with Hermes Agent, OpenClaw, and the agentskills.io standard.
