breakdown

obra / superpowers

This framework provides a software development methodology using subagent-driven development for autonomous task execution. It integrates with coding harnesses like Claude, Codex, and Cursor while enforcing TDD and YAGNI principles.

nexu-io / open-design

This local-first prototyping system supports various local CLI executables and OpenAI-compatible endpoints. It includes a design system for brand visual language and can generate HTML, PDF, PPTX, and MP4 exports.

topoteretes / cognee

This platform provides AI agents with persistent long-term memory across sessions using a self-hosted knowledge graph engine. It is capable of building knowledge graphs from any data format and supports Rust and TypeScript clients.

mukul975 / Anthropic-Cybersecurity-Skills

This repository contains 817 structured cybersecurity skills across 29 security domains. These skills are mapped to six industry frameworks and are compatible with over 26 AI platforms.

Agents365-ai / drawio-skill

This tool converts Mermaid text into editable.drawio files and supports 11 diagram type presets. It features built-in self-check and auto-fix capabilities for generating diagrams from natural language.

conorbronsdon / avoid-ai-writing

This utility audits and rewrites content to remove detectable AI writing patterns through a two-pass detection process. It utilizes a 112-entry word replacement table and is compatible with Hermes and Cursor.

internet-court / internet-court-skill

This skill acts as a trust layer for agent-to-agent commerce, providing adjudication for deals. It integrates fragmented ecosystem layers through natural-language mandates, escrow, and dispute resolution.

AMAP-ML / SkillClaw

This tool automates skill evolution, deduplication, and quality improvement to unify skills across multiple agents and devices. It integrates with Hermes and OpenAI-compatible APIs.

wondelai / skills

This cross-platform library provides spec-conformant Agent Plugins compatible with Claude Code and agentskills.io. It includes 12 metaskills that preserve state within a docs/ folder.

mohitagw15856 / pm-claude-skills

This collection includes 1,099 professional agent skills that run natively in Hermes Agent and Claude Code. It also provides ready-to-paste exports for use with other assistants.

Romanescu11 / hermes-skill-factory

This meta-skill plugin automatically detects and proposes reusable skills from active workflows. It generates Python plugin scaffolds and SKILL.md documentation via slash commands.

ZeroPointRepo / youtube-skills

This skill set provides access to YouTube transcripts, search, channels, and playlists via TranscriptAPI. It is compatible with the Agent Skills format and works with Hermes Agent and Cursor.

Cranot / super-hermes

This project enables Hermes Agent to generate custom thinking instructions for specific tasks using pre-built analytical lenses. It provides findings alongside a report of analysis blind spots.

DougTrajano / pydantic-ai-skills

This repository offers type-safe support for agentskills.io using progressive disclosure for prompt efficiency. It supports modular packages containing instructions, resources, and scripts, as well as remote registries.

AkoliteZA / hermes-agent-idea-workflow

This skill set converts rough ideas into structured design and implementation documents. It features Lite and Full modes for different project complexities and includes a spec review gate with PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill facilitates literate programming by generating.lit.md files that combine prose, diagrams, and source code. It uses a tangler to extract runnable source files and automatically syncs edits back to the document.

ReinaMacCredy / maestro

This harness supports long-running AI agents through a three-level work model. It utilizes file-backed or SQLite-backed cards and includes a CLI for managing tasks and cards.

esaradev / icarus-plugin

This plugin provides cross-instance shared memory via markdown files to capture high-value decisions and outcomes. It includes a pipeline for fine-tuning and switching to replacement models.

smartcontractkit / chainlink-agent-skills

This project provides integration for CCIP, VRF, and Data Feeds following the Agent Skills specification. It includes specialized skills for CRE and ACE services.

Hermes-brasil / hermes-brasil

This community resource provides skills in SKILL.md format along with installation and configuration guides in Portuguese. It supports the agentskills.io standard.

black-forest-labs / skills

This repository provides prompting guides for FLUX.2 and FLUX.1 models along with API integration documentation. It offers a suite of six specialized FLUX 3 video skills.

armelhbobdad / bmad-module-skill-forge

This tool generates version-pinned, agentskills.io-compliant skills from code or documentation. It provides provenance via file and line number citations and supports Node.js and Python environments.

chigwell / skilldock.io

This registry provides a Python SkillDockClient and a CLI for installing reusable AI skills with recursive dependency resolution. It also includes commerce features using TON payments.

tiann / execplan-skill

This skill enables autonomous execution for long-running, multi-step tasks. It features real-time tracking of progress and decisions alongside built-in rollback procedures for safe recovery.

supernovae-st / nika

This Intent as Code workflow language uses a single Rust binary to manage AI tasks through four verbs. It enables local-first execution with any LLM and provides static auditing via nika check alongside tamper-evident execution receipts.

adnw-vinc / hermes-nextcloud

This skill allows the agent to manage files, notes, calendars, tasks, and contacts via WebDAV and CalDAV. It communicates securely over HTTPS using Nextcloud App Passwords and includes a guided setup script for configuration.

cablate / Agentic-MCP-Skill

This project implements a progressive MCP client using a three-layer lazy loading architecture to minimize token usage. It utilizes a socket-based daemon for persistent connections and enables incremental discovery of tool schemas and server metadata.

willingning-coder / eagle-eye

This skill employs a 5-layer retrieval system—including hard triggers and dense embeddings—to narrow skill lists before LLM calls. This approach reduces token usage and features graceful degradation if dependencies or embedding models are missing.

Sahil-SS9 / hermaguard

This read-only skill performs adversarial bug-hunting by using three parallel subagents to attack code from different angles. It verifies findings via sandbox execution to provide VERIFIED or REFUTED status and uses a deterministic pre-scan.

amanning3390 / hermeshub

This hub provides community skill browsing, searching, and one-click installation by implementing the Agentic Resource Discovery v0.9 specification. It features federated search integration with GitHub and Hugging Face.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across various surfaces including CLI, TUI, Discord, and Telegram. It tailors rewrites to specific model families and tracks quality scores and token savings in a local SQLite database.

EntangledQuantum / Life_OS

This personal execution OS uses local SQLite storage to manage habits and study blocks without cloud sync. It connects to AI agents via the Model Context Protocol (MCP) and allows users to complete tasks via tapping.

teixeirazeus / fablize-for-hermes

This project adapts verified procedures to include multi-story task decomposition with mandatory evidence-based verification gates. It provides a systematic investigation protocol and a Python goal engine for persistent task state management.

PederHP / skillsdotnet

This C# /.NET implementation of agentskills.io integrates with Microsoft.Extensions.AI for tool-based skill loading. It supports automatic registration of common agent skill directories and implements progressive disclosure via SKILL.md files.

Sahil-SS9 / hermes-simplify-swarm

This skill uses three parallel sub-agents—Hygiene, Clarity, and Correctness—to perform multi-agent code simplification. It supports TypeScript, JavaScript, Python, Go, and Rust through a tiered application process with an approval gate.

handnewb / hermes-cybersec-lab

This turnkey cybersecurity lab provides 2,077 total skills and 131+ tools for network, forensics, and exploitation. It integrates 28 cybersecurity frameworks and standards, including MITRE ATT&CK and OWASP.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server allows users to search over 13,870 MCP servers and 4,384 agent skills. It provides direct installation commands and integrates with MCP-compatible clients such as Hermes.

mag3nt-com / openclaw-skill

This tool automates payments for HTTP 402 responses using USDC via protocols like Pay Link and x402. It is compatible with the agentskills.io standard and the Hermes Agent.

skillseal / skillseal

This project provides functional quality seals for AI agent skills by testing structure, functionality, and security in isolated Docker containers. It produces cryptographically verifiable certificates using Ed25519 signatures.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news briefings ranging from global to street levels. It produces structured reports with core conclusions and uses semantic memory to integrate user interests.

jiawood2006 / hermes-skills

This suite offers video-to-text transcription, local OCR for PDFs and images, and batch e-commerce material generation. It includes specialized features like AI text de-humanization and brand overlays.

CorsenAI / hermes-windows-runtime-skills

This skill manages deterministic path routing between Windows, MSYS, and WSL syntaxes. It uses a PowerShell resolver to select compatible Python interpreters without making network requests or file edits.
