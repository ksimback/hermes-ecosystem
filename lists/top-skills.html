breakdown

nexu-io / open-design

A local-first design and prototyping system that enables Hermes Agent to generate prototypes, motion graphics, and decks. It integrates with over 150 design systems and 22 local CLIs to bridge the gap between design and code.

mukul975 / Anthropic-Cybersecurity-Skills

A comprehensive library of 817 structured cybersecurity skills mapped to major industry frameworks like MITRE ATT&CK and NIST CSF 2.0. It provides agents with specialized knowledge for security auditing and financial fraud detection.

Agents365-ai / drawio-skill

This skill allows Hermes Agent to generate editable .drawio diagrams from natural language prompts. It is particularly useful for visualizing codebase structures across Python, JS, Go, and Rust using a vast library of cloud and AI logos.

AMAP-ML / SkillClaw

An agentic evolver that enables skills to evolve collectively through automatic deduplication and quality improvements. It creates a shared evolution loop to synchronize skill libraries across different agents and team members.

conorbronsdon / avoid-ai-writing

A content auditing tool that eliminates detectable AI writing patterns using a two-pass rewrite process. It utilizes a tiered replacement table and 49 pattern categories to remove structural and rhythmic AI fingerprints.

wondelai / skills

A cross-platform library providing thematic skill collections for architecture, UX, and product strategy. These frameworks are based on established industry guidelines and are compatible with Claude Code and agentskills.io.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that monitors active workflows to automatically detect and propose reusable skills. It streamlines development by generating both Python plugin scaffolds and SKILL.md documentation.

DougTrajano / pydantic-ai-skills

Provides type-safe agentskills.io support for Pydantic AI, utilizing progressive disclosure to reduce token consumption. It supports both programmatic and filesystem-based skill definitions.

ZeroPointRepo / youtube-skills

A suite of tools for extracting YouTube transcripts, captions, and timestamps without relying on yt-dlp. It enables Hermes Agent to perform video searches and browse channels and playlists.

amanning3390 / hermeshub

A community hub for browsing and installing skills with ARD v0.9 compliance and urn:air identifiers. It ensures trusted transactions through Ed25519-signed bids and dual settlement rails via Stripe and MPP.

Cranot / super-hermes

Teaches Hermes Agent to write its own analytical prompts through the dynamic generation of custom 'analytical lenses.' It includes validated prisms for simulation and optimization, along with a reflection tool to identify analysis blind spots.

AkoliteZA / hermes-agent-idea-workflow

A specialized workflow that transforms rough ideas into structured design documents and implementation handoffs. It features Lite and Full modes and includes a formal spec review gate for quality evaluation.

ReinaMacCredy / maestro

A harness for long-running agents that uses a durable card model for tracking tasks and decisions. It features local-first storage for easy diff reviews and mandatory QA gates to verify work before completion.

tlehman / litprog-skill

Implements literate programming by weaving source code and documentation into .lit.md files. It includes a tangler to extract runnable code and automatically syncs edits between the source and the documentation.

esaradev / icarus-plugin

A self-memory system that captures high-value decisions in markdown files for cross-instance sharing. It includes a pipeline for fine-tuning and switching to replacement models based on captured work.

smartcontractkit / chainlink-agent-skills

Provides agentskills.io compliant tools for interacting with the Chainlink oracle network. It supports integrations for CCIP, VRF, Data Feeds, and Data Streams, installable via the Vercel skills CLI.

armelhbobdad / bmad-module-skill-forge

Converts repositories and documentation into agentskills.io-compliant skills using AST analysis. It ensures accuracy by linking every instruction directly to specific source code line numbers.

black-forest-labs / skills

The official skill set for FLUX image generation, providing standardized prompting guidelines for FLUX.1 and FLUX.2. It includes API integration patterns for webhooks and precise hex color specifications.

chigwell / skilldock.io

A registry for reusable AI skills featuring an OpenAPI-driven CLI for lifecycle management. It supports recursive dependency resolution and integrated monetization via TON and Stripe.

tiann / execplan-skill

Enables the autonomous execution of complex, multi-step tasks with real-time progress tracking. It includes built-in rollback procedures to ensure safe recovery during long-running operations.

cablate / Agentic-MCP-Skill

A progressive MCP client that uses three-layer lazy loading to minimize token usage for large toolsets. It maintains persistent connections to multiple MCP servers via a socket-based daemon.

adnw-vinc / hermes-nextcloud

Integrates Hermes Agent with Nextcloud to manage files, calendars, and contacts via WebDAV and CalDAV. It uses secure HTTPS communication and includes a guided setup script for credential validation.

PederHP / skillsdotnet

A C#/.NET implementation of the agentskills.io specification with MCP integration. It leverages Microsoft.Extensions.AI for tool loading and supports progressive disclosure via SKILL.md files.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

A plugin that rewrites and scores prompts for various surfaces, including Discord and Telegram. It tailors rewrites based on model reasoning capabilities and tracks token savings in a local SQLite database.

Sahil-SS9 / hermaguard

An adversarial code review tool that uses three parallel subagents to attack code from different angles to find bugs. It integrates Semgrep, Bandit, and Gosec for deterministic pre-scanning without modifying the code.

Sahil-SS9 / hermes-simplify-swarm

A multi-agent swarm that simplifies code by focusing on hygiene, clarity, and correctness. It uses a risk-tiered triage system to safely modify code and detect concurrency anti-patterns.

willingning-coder / eagle-eye

A five-layer retrieval system that uses FTS5, embeddings, and RRF fusion to find the most relevant skills. It integrates via a pre_llm_call hook and degrades gracefully if optional dependencies are missing.

mag3nt-com / openclaw-skill

Automates payments for HTTP 402 responses using USDC and various payment protocols. It is compatible with OpenClaw, Hermes Agent, and the agentskills.io standard.
