Project Breakdown

Anthropic-Cybersecurity-Skills

This library provides 754 structured cybersecurity skills mapped to major frameworks like MITRE ATT&CK and NIST. It equips Hermes with specialized domain knowledge across 26 security domains, making it a powerhouse for defensive and offensive security tasks.

avoid-ai-writing

This skill audits and rewrites content to eliminate 36 distinct AI writing patterns and structural tells. By using a three-tier word replacement system and a second-pass audit, it ensures Hermes produces more natural, human-like prose.

wondelai/skills

A modular, cross-platform library that brings standardized frameworks for architecture, UX design, and product strategy to Hermes. It utilizes a marketplace and CLI for easy installation, allowing agents to adopt professional-grade workflows instantly.

drawio-skill

Hermes can generate editable .drawio diagrams from natural language descriptions using this skill, which includes presets for ML models and tensor shapes. It features an automated self-check loop to identify and fix layout issues, ensuring high-quality visual outputs.

pydantic-ai-skills

This project implements the Agent Skills open specification for Pydantic AI with a focus on efficiency. It uses progressive disclosure of metadata to reduce token usage while supporting both filesystem-based and programmatic skill definitions.

litprog-skill

A literate programming tool that allows Hermes to weave code and documentation together into .lit.md files. It includes a tangler to extract runnable source files and automatically syncs edits back to the primary document.

chainlink-agent-skills

This skill enables Hermes to interact with the Chainlink Runtime Environment and CCIP workflows for cross-chain smart contract operations. It follows the agentskills.io specification to provide standardized methods for contract discovery and monitoring.

icarus-plugin

This plugin introduces cross-instance shared memory via markdown-based directories, allowing Hermes to remember past work. It includes an end-to-end pipeline for extracting decision-quality data to train and evaluate replacement models.

skilldock.io

A registry and SDK for discovering and managing reusable AI skills with support for recursive dependency resolution. It integrates commerce features via TON and Stripe, enabling a marketplace for monetizing specialized agent capabilities.

black-forest-labs/skills

The official skill set for FLUX image generation, providing Hermes with standardized prompting guidelines and API integration patterns. It supports precise hex color specification and JSON structured prompting for high-fidelity visual synthesis.

hermes-skill-factory

This meta-skill watches active workflows to automatically detect and propose new, reusable skills. It generates both documentation and Python scaffolds, allowing Hermes to effectively expand its own capability set during execution.

maestro

A harness for long-running agents that maintains shared state on disk and facilitates context transfers via structured UKI v5.4 handoffs. It provides a TUI and JSON snapshots to track complex missions across multiple agent instances.

execplan-skill

This skill enables Hermes to execute complex, multi-step tasks autonomously with built-in checkpoints for progress tracking. It includes rollback procedures to ensure safe recovery if a task encounters an error during execution.

hermeshub

A community hub for browsing and searching Hermes skills with one-click installation and automated security scanning. It protects users from malicious payloads while supporting a creator marketplace through micropayment protocols.

bmad-module-skill-forge

This tool converts repositories and developer discourse into agentskills.io-compliant skills using AST analysis for verified function signatures. It links every AI instruction to specific source file lines to ensure high-fidelity code generation.

Agentic-MCP-Skill

A progressive MCP client that uses three-layer lazy loading to minimize token usage for tool definitions. It maintains persistent connections to multiple MCP servers via a socket-based daemon for efficient resource management.

skillsdotnet

This project brings the agentskills.io specification to the C# and .NET ecosystem, including MCP resource templates for on-demand loading. It provides vendor-specific shortcuts to streamline skill integration for developers using the .NET stack.
