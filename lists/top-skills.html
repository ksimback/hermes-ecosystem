breakdown

obra / superpowers

This framework automates specification elicitation and implementation planning by applying TDD, YAGNI, and DRY principles to software development. It integrates with multiple coding harnesses and CLI tools to provide a structured methodology for agentic software engineering.

nexu-io / open-design

A local-first system that enables Hermes Agent to generate web, mobile, and motion graphic artifacts through a dedicated CLI. It supports native agent runtime via the DeepSeek Harness and exports designs into formats including HTML, PDF, PPTX, and MP4.

mukul975 / Anthropic-Cybersecurity-Skills

This library provides 818 structured skills across 34 security domains, mapped to frameworks such as MITRE ATT&CK, NIST CSF 2.0, and ATLAS. It is compatible with over 26 AI platforms, offering a standardized foundation for cybersecurity operations.

Agents365-ai / drawio-skill

This skill allows agents to convert codebases, infrastructure-as-code, and schemas into draw.io diagrams using natural language. It includes a CLI and MCP server that support incremental synchronization while preserving manual layout adjustments.

internet-court / internet-court-skill

Serving as a trust layer for agent-to-agent commerce, this skill facilitates natural-language mandates, ERC-7710 permissions, and x402 payments. It features a master router and connector skills to manage escrow, verification, and dispute resolution.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI patterns using a two-pass editing process for verification. It offers five optional voice profiles and supports rewrite, detect-only, and edit-in-place modes.

AMAP-ML / SkillClaw

This agentic evolver automates skill deduplication and cross-pollination across isolated agent silos for Hermes and other OpenAI-compatible APIs. It includes a bilingual dashboard for inspecting session traces and monitoring collective skill evolution.

wondelai / skills

A cross-platform library featuring 51 expert frameworks and 14 guided metaskills compatible with Claude Code and agent-plugins.org specifications. It maintains session state locally within the project's documentation folder to support persistent agent workflows.

mohitagw15856 / pm-claude-skills

This collection contains 1,170 markdown-based skills for professional and personal tasks that run natively in Hermes Agent without requiring telemetry or user accounts. The skills are designed for immediate use across various assistants including Claude, ChatGPT, and Gemini.

ZeroPointRepo / youtube-skills

This plugin enables Hermes Agent to perform video searches, browse channels, and extract transcripts or playlist data. It requires a TranscriptAPI key and is compatible with multiple environments including OpenClaw, Cursor, and Windsurf.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that monitors active workflows to automatically detect and propose reusable skills. It generates both SKILL.md documentation and Python scaffolds, allowing users to manage detected patterns via slash commands.

Cranot / super-hermes

These skills enable Hermes Agent to generate its own custom thinking instructions and analytical prompts for specific tasks. The system utilizes pre-built analytical lenses and generates reports that highlight potential analysis blind spots.

DougTrajano / pydantic-ai-skills

This project enables type-safe support for agentskills.io using remote registries via Git and S3 sources. It provides sandboxed execution to isolate untrusted scripts from the host while offering tools to read bundled resources.

tlehman / litprog-skill

This skill implements literate programming by generating documents that combine prose, diagrams, and source code. It uses a tangler to extract runnable files and automatically syncs edits back to the original documentation.

AkoliteZA / hermes-agent-idea-workflow

This workflow converts rough ideas into structured design and implementation documents through Lite or Full complexity modes. It ensures quality via a spec review gate that utilizes PASS/FAIL evaluation models.

ReinaMacCredy / maestro

Running on Bun without background services, this harness implements the SLP v2 protocol for supervised cooperative-agent teams. It manages work, decisions, and evidence through a CLI-driven mechanism kernel.

esaradev / icarus-plugin

This plugin facilitates cross-instance shared memory using markdown files to capture high-value decisions and outcomes. It includes a pipeline for fine-tuning and transitioning to replacement models.

Hermes-brasil / hermes-brasil

This community resource provides agentskills.io-compatible skills and guides for VPS production and automation in Portuguese. It supports integrations with messaging platforms including Telegram, Discord, Slack, and WhatsApp.

smartcontractkit / chainlink-agent-skills

Following the Agent Skills specification, this project enables interactions with oracle networks and smart contracts. It supports Chainlink services like CCIP, VRF, and Data Feeds, and installs via the Vercel CLI.

black-forest-labs / skills

These official skills provide API integration and prompting guidelines for FLUX image and video generation. The suite includes eight specialist skills and supports polling and webhooks for BFL API tasks.

armelhbobdad / bmad-module-skill-forge

This tool converts repositories, documentation, and developer discourse into compliant skills with instructions linked to specific file lines. It features automated workflows for briefing, creating, testing, and exporting new skills.

supernovae-st / nika

Nika is a local-first workflow language that compiles natural language into reviewable files using a deterministic compiler. It provides integrity verification for execution traces and supports multiple AI model providers.

chigwell / skilldock.io

This registry offers reusable AI skills with a Python client and CLI for installation with recursive dependency resolution. It also incorporates commerce features using TON payments for skill transactions.

tiann / execplan-skill

Designed for complex multi-step tasks, this skill provides autonomous execution with real-time progress tracking. It includes built-in rollback procedures and checkpoints to ensure safe recovery during long-running operations.

adnw-vinc / hermes-nextcloud

This skill enables Hermes Agent to manage files, notes, calendars, tasks, and contacts through standard WebDAV and CalDAV protocols. It ensures secure communication over HTTPS using Nextcloud App Passwords and includes a guided setup script for credential validation.

amanning3390 / hermeshub

Implementing the Agentic Resource Discovery (ARD) v0.9 specification, this project serves as a centralized hub for browsing and installing community skills. It operates autonomously on NVIDIA infrastructure and provides federated search integration with GitHub and Hugging Face.

cablate / Agentic-MCP-Skill

This progressive MCP client utilizes a three-layer lazy loading architecture to minimize token usage during skill discovery. It features a socket-based daemon for persistent connections and incrementally discovers server metadata and tool schemas.

willingning-coder / eagle-eye

This project implements a five-layer retrieval system using hard triggers, semantic embeddings, and RRF fusion to narrow skill lists before LLM calls. By filtering relevant skills, it reduces token consumption and offers graceful degradation if specific embedding models are unavailable.

EntangledQuantum / Life_OS

Designed as an ADHD-friendly execution system, this project uses MCP connections to allow Hermes Agent to drive scheduling, habits, and study blocks. It stores all data locally in a single SQLite file and includes both a React web app and an Expo-based Android application.

Sahil-SS9 / hermaguard

This read-only code review skill employs three parallel subagents to perform adversarial attacks and edge-case analysis on code. It combines deterministic pre-scans using tools like semgrep and bandit with verified findings through proof-of-concept execution in a hardened sandbox.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin optimizes and scores prompts across multiple surfaces like Discord and Telegram, supporting 97 different languages. It claims to reduce token usage by 20–80% per rewrite while evaluating prompt quality across five specific dimensions.

Sahil-SS9 / hermes-simplify-swarm

Inspired by Claude Code, this skill uses a swarm of three sub-agents focused on hygiene, clarity, and correctness to simplify code in languages such as Python, Go, and Rust. It incorporates a tiered application process that includes a mandatory approval gate for changes.

teixeirazeus / fablize-for-hermes

This project provides a systematic investigation protocol for causal debugging and reproduction through mandatory evidence-based verification gates. It utilizes a Python goal engine for persistent task state management and multi-story task decomposition.

PederHP / skillsdotnet

This C# and .NET implementation of the agentskills.io pattern integrates with Microsoft.Extensions.AI for tool-based skill loading. It supports the automatic registration of skill directories and utilizes SKILL.md files for progressive disclosure.

handnewb / hermes-cybersec-lab

This turnkey cybersecurity lab equips Hermes Agent with over 2,000 skills and 131 tools for network forensics and exploitation. It integrates 28 different frameworks, including MITRE ATT&CK and NIST, to handle real exploits spanning from 2015 to 2026.

conorbronsdon / agent-skills

This project adds persistent memory and session management to agents like Claude Code, enabling worktree recovery and multi-session reconciliation. It also orchestrates parallel subagents for architectural reviews and provides tools for skill scaffolding and eval auditing.

Diabloluo / hermes-hud

This local-first dashboard provides real-time observability for Hermes Agent through 11 monitoring tabs, including token costs, session history, and error tracking. It enforces a strict read-only boundary with zero outbound telemetry and supports incident alerts via Telegram and Feishu.

conorbronsdon / demo-gif-skill

This skill enables agents to add reproducible demo GIFs to repositories by generating vhs or Playwright recording scripts. It supports terminal CLIs, web apps, and libraries, ensuring output files are optimized to stay under 8 MB.

aidevelopers2 / remoteopenclaw-mcp

This tool allows agents to search a database of over 13,870 MCP servers and 4,384 skills directly from the terminal. It provides installation commands for discovered plugins and integrates with MCP-compatible clients like Hermes and Cursor.

Carlo1911 / skill-evolution

This project establishes a self-improvement loop by analyzing session history to propose skill coverage gaps. It gates updates behind deterministic and LLM-judge evaluators and operates locally using the Python standard library without external daemons.

conorbronsdon / agent-skill-builder

This utility generates Claude Code extensions and portable Agent Skills core files while validating them against runtime-specific profiles. It monitors official frontmatter specifications weekly to detect field drift and uses CI-friendly exit codes to prevent broken deployments.

superagnt / leverage

This suite provides skills for social data, CRM management, and lead enrichment, supported by a workspace Postgres database and scheduled tasks. It includes an MCP server for browser-based OAuth authentication and is compatible with agentskills.io standards.

jiawood2006 / hermes-skills

This collection provides specialized tools for transcribing Douyin videos, performing OCR via macOS Vision, and removing common Chinese AI writing patterns. It is designed for content creation workflows, including an E-commerce Material Studio and structured data extraction.

CorsenAI / hermes-windows-runtime-skills

This skill set manages environment-specific path syntax and Python interpreter selection across Windows, Git Bash, and WSL. It ensures deterministic file routing and runtime compatibility without requiring new software installations.

mag3nt-com / openclaw-skill

This skill automates payments for HTTP 402 responses using USDC across protocols like Pay Link and x402. It is compatible with the OpenClaw and Hermes Agent ecosystems for handling monetized web resources.

skillseal / skillseal

This framework certifies the quality of AI agent skills by testing structure, functionality, and security within isolated Docker containers. It produces cryptographically verifiable Ed25519 signatures and offers a public API for certificate verification.

webmilmind1 / hermes-bounty-board

scavio-ai / hermes-agent

This integration exposes 191 tools and five production-grade workflow skills for structured web data extraction across 31 platforms. It utilizes a hosted MCP server to support clients including Hermes, Claude, and Cursor.

Shine8592 / china-briefing
