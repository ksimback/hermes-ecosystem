breakdown

obra / superpowers

This framework implements a subagent-driven methodology to execute engineering tasks autonomously. It enforces a structured workflow of brainstorming, planning, and test-driven development to ensure reliable software creation.

nexu-io / open-design

A local-first design system that provides 26 CLI executables for prototyping and exporting artifacts to formats like HTML, PDF, and MP4. It features a sandboxed iframe preview for live iteration and supports integration with Hermes Agent.

mukul975 / Anthropic-Cybersecurity-Skills

This library provides 818 structured skills across 34 security domains, mapped to frameworks including MITRE ATT&CK and NIST AI RMF. It is compatible with over 26 AI platforms to enhance agent security capabilities.

topoteretes / cognee

Cognee serves as a self-hosted knowledge graph engine that provides agents with persistent long-term memory across sessions. It combines vector embeddings with graph-based reasoning and offers clients in Python, Rust, and TypeScript.

Agents365-ai / drawio-skill

This skill enables agents to generate editable .drawio files from natural language descriptions and Mermaid text. It includes 11 diagram presets along with self-check and auto-fix capabilities to ensure diagram accuracy.

internet-court / internet-court-skill

Acting as a trust layer for agent-to-agent commerce, this skill facilitates natural-language mandates, escrow, and dispute resolution. It utilizes a master router and connector skills to manage delegated permissions and payments.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI patterns using a two-pass detection system. It supports Rewrite, Detect, and Edit-in-place modes with optional voice profiles for varying tones.

AMAP-ML / SkillClaw

SkillClaw enables collective skill evolution through merging and cross-pollination across multiple agents like Hermes and QwenPaw. It includes a bilingual dashboard for inspecting session traces and skill development.

wondelai / skills

A cross-platform library featuring 50 expert frameworks and 14 guided metaskills compatible with the Agent Plugins spec v1.0.0. It maintains persistent state across sessions by storing data within the project's documentation folder.

mohitagw15856 / pm-claude-skills

This collection contains 1,153 markdown-based skills for professional and life tasks that run natively in Hermes Agent. It features ready-to-paste exports and integrations for platforms such as Slack, Raycast, and Obsidian.

ZeroPointRepo / youtube-skills

This plugin provides capabilities for video search, transcript extraction, and playlist browsing on YouTube. It is compatible with Hermes Agent and Cursor, requiring a TranscriptAPI key for operation.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that automatically detects reusable patterns in active workflows to propose new skills. It generates both SKILL.md documentation and Python scaffolds, allowing users to manage detected patterns via slash commands.

Cranot / super-hermes

This project enables Hermes Agent to generate its own analytical instructions and thinking lenses for specific tasks. It enhances output quality by reporting findings alongside an analysis of potential blind spots.

DougTrajano / pydantic-ai-skills

This toolkit provides type-safe support for modular skill packages using progressive disclosure to maintain prompt efficiency. It supports programmatic skills, remote registries, and resources for Pydantic AI agents.

AkoliteZA / hermes-agent-idea-workflow

This skill set automates the transition from rough concepts to structured design documents and implementation handoffs. It features Lite and Full modes for different project scales and includes a spec review gate with PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill implements literate programming by weaving prose, diagrams, and source code into .lit.md files. It includes a tangler to extract runnable code and automatically syncs source file edits back to the primary documentation.

ReinaMacCredy / maestro

Maestro is a harness for long-running agents that utilizes a mechanism kernel to operate without a background service. It organizes workflows through four distinct roles—Human, Supervisor, Lead, and Peer—and requires Herdr for hosting rooms.

esaradev / icarus-plugin

This plugin facilitates cross-instance shared memory by capturing high-value decisions and outcomes in markdown files. It establishes a pipeline for fine-tuning and transitioning to replacement models based on recorded work history.

smartcontractkit / chainlink-agent-skills

Built on the Agent Skills specification, this project provides interoperable skills for interacting with Chainlink oracle networks. It supports integrations for CCIP, VRF, and Data Feeds, as well as specialized CRE and ACE services.

Hermes-brasil / hermes-brasil

This community-driven repository offers Hermes Agent skills, installation guides, and configuration resources specifically in Portuguese. All contributions follow the SKILL.md format and the agentskills.io standard.

black-forest-labs / skills

These official skills integrate FLUX.2 image and FLUX 3 video generation models into agent workflows. The modules include specialized support for cinematic inserts, archival formats, and optimized prompting guidelines.

armelhbobdad / bmad-module-skill-forge

This tool converts repositories and developer discourse into version-pinned skills with audit trails and provenance maps. It links instructions to specific file lines at pinned commits and requires Python 3.10 and Node.js 22.

chigwell / skilldock.io

This registry provides a CLI and Python client for installing reusable AI skills with recursive dependency resolution. It also features a commerce layer that supports skill transactions using TON payments.

tiann / execplan-skill

This skill manages complex, multi-step tasks by providing autonomous execution with real-time progress tracking. It ensures operational safety through built-in checkpoints and rollback procedures for recovery.

supernovae-st / nika

This project introduces a workflow language that audits AI tasks for costs, permissions, and types before local execution via a single Rust binary. It ensures accountability by generating hash-chained, tamper-evident receipts for every run.

adnw-vinc / hermes-nextcloud

This skill enables Hermes to manage files, calendars, and contacts through standard WebDAV and CalDAV protocols. It features a guided setup script for credential validation and utilizes Nextcloud App Passwords for secure HTTPS communication.

cablate / Agentic-MCP-Skill

This progressive MCP client utilizes a three-layer lazy loading architecture to minimize token usage during tool discovery. It employs a socket-based daemon for persistent connections and incremental metadata retrieval.

willingning-coder / eagle-eye

Eagle Eye implements a five-layer retrieval system that combines hard triggers, semantic embeddings, and RRF fusion to narrow skill lists. This approach reduces token consumption and includes graceful degradation if specific dependencies are unavailable.

amanning3390 / hermeshub

This hub serves as a community platform for browsing and installing skills according to the Agentic Resource Discovery (ARD) v0.9 specification. It operates autonomously on NVIDIA infrastructure and provides federated search across GitHub and Hugging Face.

EntangledQuantum / Life_OS

This personal execution system uses a local SQLite database to manage habits and study blocks without cloud synchronization. It allows a Hermes agent to handle system design while the user interacts via a task-completion interface.

Sahil-SS9 / hermaguard

HermaGuard performs adversarial code reviews using three parallel subagents to identify edge cases and integration issues. It combines deterministic pre-scans with proof-of-concept execution in a hardened sandbox to verify findings.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin optimizes prompts across various interfaces like CLI and Discord, scoring them across five quality dimensions. It supports 97 languages and claims to reduce token usage by 20–80% per rewrite.

teixeirazeus / fablize-for-hermes

This adaptation implements multi-story task decomposition with mandatory evidence-based verification gates to prevent early-stop errors. It includes a systematic investigation protocol for causal debugging and a Python engine for persistent state management.

Sahil-SS9 / hermes-simplify-swarm

Inspired by Claude Code, this skill uses a swarm of three subagents to improve code hygiene, clarity, and correctness. It supports multiple languages including Rust and Go, featuring a tiered application process with a final approval gate.

PederHP / skillsdotnet

This C# and .NET implementation of the agentskills.io pattern enables tool-based skill loading via Microsoft.Extensions.AI. It supports progressive disclosure through SKILL.md files and automatic registration of skill directories.

handnewb / hermes-cybersec-lab

This comprehensive lab provides over 2,000 skills and 131 tools for network forensics and exploitation. It integrates 28 cybersecurity frameworks, including MITRE ATT&CK and NIST, to address CVE-driven scenarios.

conorbronsdon / agent-skills

This project provides production-tested tools for session management, multi-session reconciliation, and worktree recovery. It enhances agent memory between conversations and orchestrates parallel subagents for architectural and adversarial code reviews.

conorbronsdon / demo-gif-skill

This skill automates the creation of reproducible recording scripts using vhs or Playwright to generate demo GIFs for repository READMEs. It ensures output files are optimized under 8 MB and embeds them directly into the documentation.

conorbronsdon / agent-skill-builder

This tool generates portable agent skills from plain language while monitoring official frontmatter specs to prevent drift. It includes a validator with CI-friendly exit codes to ensure skills remain compatible with runtime-specific profiles.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server enables agents to search a database of over 13,870 MCP servers and 4,384 skills. It provides direct installation commands for discovered tools and integrates with compatible clients like Hermes and Cursor.

Carlo1911 / skill-evolution

This host-agnostic framework creates a self-improvement loop by analyzing session history to propose skill coverage updates. It gates these updates behind deterministic and LLM-judge evaluators while operating locally via the Python standard library.

mag3nt-com / openclaw-skill

This skill automates payments for HTTP 402 responses using USDC across protocols like Pay Link and x402. It is designed for compatibility with the agentskills.io standard and agents like Hermes and OpenClaw.

skillseal / skillseal

This project certifies the structure, functionality, and security of agent skills by testing them within isolated Docker containers. It issues cryptographically verifiable certificates using Ed25519 signatures and provides a public API for verification.

CorsenAI / hermes-windows-runtime-skills

These skills manage deterministic path routing and Python interpreter selection across Windows, Git Bash, and WSL environments. They ensure file operations use environment-specific syntax without requiring new software installations.

webmilmind1 / hermes-bounty-board

This plugin allows agents to earn USDC on the Base network by answering support bounties without requiring accounts or API keys. It includes tools for creating bounty boards, buying context, and settling payments via x402.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news reports ranging from global to street-level perspectives. It utilizes semantic memory to integrate user interests and applies quality gates to produce structured reports with actionable conclusions.

jiawood2006 / hermes-skills

This collection provides tools for video-to-text conversion, OCR, and agent memory management compatible with the agentskills.io standard. It supports various operations across macOS, Linux, and Windows depending on the specific skill selected.

scavio-ai / hermes-agent

This project exposes 191 tools and five production-grade skills through a hosted MCP server for structured web data access. It is built to support multiple agent environments including Claude, Cursor, Goose, and OpenHands.
