breakdown

obra / superpowers

Superpowers combines composable skills that instruct agents to use them with a software-development workflow spanning specification, design sign-off, planning, and subagent execution. It belongs in this list for its structured approach to guiding agent development work, with installation documented separately for multiple harnesses.

nexu-io / open-design

Open Design is a local-first design and prototyping system with coding-agent CLI support, including Hermes Agent. Its skills, templates, design systems, and plugins support interactive web prototypes with live previews as well as slide decks, images, and motion graphics.

mukul975 / Anthropic-Cybersecurity-Skills

This project provides structured cybersecurity skills across security domains and maps them to frameworks including MITRE ATT&CK, ATLAS, D3FEND, and F3. It stands out for its security-focused skill library and stated compatibility with more than 26 AI platforms.

Agents365-ai / drawio-skill

drawio-skill turns natural-language descriptions and real sources into editable .drawio diagrams. Its incremental sync is designed to preserve manual layout and annotations, and the project also offers the diagramctl CLI and an optional MCP server.

internet-court / internet-court-skill

internet-court-skill brings together a master router and connector skills for agent-to-agent commerce, alongside vendored copies of official protocol skills. It also adds a verification and dispute-resolution layer.

conorbronsdon / avoid-ai-writing

avoid-ai-writing can score files or piped text for detectable AI-writing patterns and offers a rewrite mode with up to two editing passes. Its in-place editing mode refuses to modify source code, configuration, and generated data.

AMAP-ML / SkillClaw

SkillClaw uses background evolution to automate skill deduplication and quality improvement, while unifying skill libraries across agents, devices, and team members. It lists integrations with Hermes, Claude Code, Codex, and OpenAI-compatible APIs.

wondelai / skills

This cross-platform skills library includes 51 expert frameworks and 14 guided metaskills, with compatibility for Claude Code, Codex, and agent-plug-ins.org specifications. It also maintains session state in the project's docs folder.

mohitagw15856 / pm-claude-skills

This project offers professional agent skills, each with a framework, output template, and quality checks. Its README describes 1,295 skills and says the project is MIT-licensed.

ZeroPointRepo / youtube-skills

youtube-skills covers YouTube transcripts, video search, channel browsing, and playlist extraction. It supports Hermes Agent, OpenClaw, Claude Code, and Cursor, and requires a TranscriptAPI key, which has a stated 100-credit free tier.

Romanescu11 / hermes-skill-factory

hermes-skill-factory watches active workflows to detect and propose reusable skills, then generates both SKILL.md documentation and Python plugin scaffolds. Slash commands let users manage, list, and save detected patterns.

Cranot / super-hermes

super-hermes teaches Hermes Agent to generate task-specific analytical instructions and includes pre-built analytical lenses for various domains. It reports findings alongside a report of analysis blind spots.

DougTrajano / pydantic-ai-skills

Adds type-safe agentskills.io support for Pydantic AI, with progressive disclosure and remote skill registries from Git and S3. It also provides tools for bundled resources and script execution, with sandboxing to isolate untrusted scripts from the host.

tlehman / litprog-skill

Creates .lit.md documents that combine prose, diagrams, and source code, then extracts runnable files from them with a tangler. Edits to those source files can also be synced back into the literate document, making this a fit for teams coordinating code and documentation across agents.

AkoliteZA / hermes-agent-idea-workflow

Turns rough ideas into structured design and implementation documents for Hermes Agent. Lite and Full modes suit different levels of project complexity, while a spec review gate evaluates proposals with PASS/FAIL models.

ReinaMacCredy / maestro

Maestro provides a harness for long-running AI agents, with structured memory, cross-feature learning, and a plan-approve-execute approach. It does not require a background service and includes an SLP protocol for supervised teams, along with CLI commands for installation, updates, and diagnostics.

esaradev / icarus-plugin

Icarus shares memory across instances through Markdown files and automatically captures high-value decisions and outcomes. It also provides a pipeline for fine-tuning and switching to replacement models, connecting accumulated work with model replacement.

Hermes-brasil / hermes-brasil

This Portuguese-language Hermes Agent community project offers skills in SKILL.md format and guides covering installation, production, cron, MCP, and skill authoring. Contributions are submitted through pull requests, making it a community source of Portuguese-language resources.

black-forest-labs / skills

Black Forest Labs' skills focus on FLUX image and video generation prompting, with BFL API integration for polling and webhooks. The repository also includes a FLUX 3 video suite with eight specialist skills.

smartcontractkit / chainlink-agent-skills

This repository lists nine Chainlink skills, each following the Agent Skills specification, and documents installation with `npx skills add smartcontractkit/chainlink-agent-skills`. Its README describes the repository as containing community examples only.

armelhbobdad / bmad-module-skill-forge

Skill Forge creates agent instructions from repositories, documentation, and developer discourse. It supports both automated and step-by-step workflows, and includes skill testing and export.

supernovae-st / nika

Nika is a workflow language for AI that checks workflows before calling a model and runs with a model you choose. It also verifies a tamper-evident record for each run.

chigwell / skilldock.io

Skilldock is a registry of reusable AI skills based on the AgentSkills specification, with a Python client and CLI. It supports installation with recursive dependency resolution and includes commerce features using TON payments.

tiann / execplan-skill

ExecPlan supports autonomous execution of long-running, multi-step tasks, with real-time tracking of progress and decisions. Built-in rollback procedures provide a recovery path when execution needs to be undone.

adnw-vinc / hermes-nextcloud

Manage Nextcloud files, notes, calendars, tasks, and contacts through WebDAV and CalDAV. It uses HTTPS with Nextcloud App Passwords and includes a guided setup script for validating credentials and configuring access.

amanning3390 / hermeshub

Browse, search, and install community skills through a hub implementing the Agentic Resource Discovery v0.9 specification. It also offers federated search across GitHub and Hugging Face and operates autonomously via Hermes Agent on NVIDIA infrastructure.

willingning-coder / eagle-eye

Find relevant skills through five retrieval layers, from hard triggers to semantic embeddings. By narrowing skill lists before LLM calls, it aims to reduce token usage, and it can degrade gracefully when embedding models or dependencies are unavailable.

cablate / Agentic-MCP-Skill

Agentic-MCP-Skill is a progressive MCP client that uses three-layer loading to minimize token usage while incrementally discovering server metadata and tool schemas. Its socket-based daemon architecture maintains persistent connections, making it a useful skill for agents that need to work with MCP servers.

EntangledQuantum / Life_OS

A personal execution OS with agent-driven scheduling and system design through an MCP connection. It stores data locally in a single SQLite file and includes a React web app and an Expo-based Android application.

Sahil-SS9 / hermaguard

A read-only code review skill that uses parallel subagents to examine edge cases, adversarial concerns, and integration issues, then consolidates and triages findings. It combines deterministic scans with proof-of-concept execution in a hardened sandbox to verify findings.

Sahil-SS9 / hermes-simplify-swarm

Simplify code with parallel Hygiene, Clarity, and Correctness agents for TypeScript, JavaScript, Python, Go, and Rust. A tiered application process with an approval gate helps control how changes are applied.

handnewb / hermes-cybersec-lab

A cybersecurity lab for Hermes Agent that includes 2,077 skills across multiple repositories and installs 131+ tools for network work, forensics, and exploitation. It also integrates 28 cybersecurity frameworks and standards.

teixeirazeus / fablize-for-hermes

Adapt verified procedures for multi-story task decomposition, with mandatory evidence-based verification gates. The project also provides an investigation protocol for reproduction and causal debugging, plus a Python goal engine for persistent task state.

PederHP / skillsdotnet

A C#/.NET implementation of agentskills.io that loads skills progressively from SKILL.md files. It integrates with Microsoft.Extensions.AI for tool-based skill loading and can automatically register common agent skill directories.

Diabloluo / hermes-hud

A local, read-only dashboard for real-time tracking of token costs, session history, and skill analytics. It includes local log desensitization and optional incident alerts through Telegram and Feishu.

conorbronsdon / agent-skills

A collection of plain-markdown agent skills for code review, session management, and related workflows, including multi-session reconciliation and worktree recovery. Install skills by copying a directory or using the bundled installer.

conorbronsdon / demo-gif-skill

Creates reproducible VHS tape or Playwright recording scripts to add demo GIFs to repository READMEs, supporting terminal CLIs, TUIs, web apps, and libraries. It also optimizes GIFs toward a target size under 8 MB, making it useful for producing lightweight project demos.

conorbronsdon / agent-skill-builder

Generates Claude Code extensions and portable Agent Skills core files, then validates them against runtime-specific profiles with CI-friendly exit codes. It also checks official frontmatter specifications weekly for field drift, focusing on keeping skills aligned with changing specs.

aidevelopers2 / remoteopenclaw-mcp

Provides terminal and MCP access to searches across more than 13,870 MCP servers and 4,384 agent skills, with direct installation commands for discovered tools and plugins. Its stated integrations include Hermes, Cursor, and Claude Code.

Carlo1911 / skill-evolution

Analyzes past sessions and indexes installed skills to draft structured improvement proposals. Proposals are review-only by default, with optional auto-application gated by deterministic, LLM-judge, or regression evaluation.

CorsenAI / hermes-windows-runtime-skills

Provides Hermes Agent skills for routing file operations with environment-specific path syntax and selecting and verifying existing, project-compatible Python interpreters. It supports native Windows, Git Bash/MSYS, and WSL.

superagnt / leverage

Packages skills for social data, web research, and enrichment, including combinations of an agent, skills, and a data flow. It also welcomes community contributions in `skills/community/`.

jiawood2006 / hermes-skills

Offers Hermes skills for transcribing Douyin videos into structured Markdown and SRT subtitles, removing common Chinese AI-writing patterns with a rule-based engine, and extracting structured data from PDFs and images using macOS Vision. The collection also includes an E-commerce Material Studio.

webmilmind1 / hermes-bounty-board

Lets agents find open support bounties, purchase ticket context, and submit answers for human review; public wallet earnings records are also available. Users can create a bounty board that returns a URL, API key, and USDC deposit addresses.

mag3nt-com / openclaw-skill

Automates USDC payments for HTTP 402 responses and supports Pay Link, x402, MPP, and AP2 protocols. It is compatible with OpenClaw, Hermes Agent, and the agentskills.io standard.

skillseal / skillseal

Tests agent skills for structure, functionality, and security in isolated Docker containers. It produces Ed25519-signed certificates that can be verified through its public API, which also accepts skill submissions.

scavio-ai / hermes-agent

Provides structured web data across 31 platforms through a hosted MCP server exposing 191 tools, along with five ready-to-use workflow skills. It also lists support for Claude, Cursor, Goose, and OpenHands.

parkyucheol-del / alphapipeline

Checks token honeypot, tax, and liquidity risk, and provides market data that includes DEX slippage and funding rates. Its quantitative risk and slippage tools are available through REST endpoints and a remote MCP server.

NickSF189 / kisscode-agent

This skill helps AI agents join KissCode and includes SKILL.md and HEARTBEAT.md instructions, plus a registration API example. It offers a focused onboarding capability for agents, and is licensed under MIT.

Shine8592 / china-briefing

This Hermes Agent skill generates structured Chinese news briefings at geographic scales from global to street level, with core conclusions and action suggestions. It uses user interests stored in semantic memory to expand searches, making it a fit for agents that need tailored, multi-scale news summaries.

aidatatools-dev / astro-agents-mcp

This project provides an unauthenticated MCP endpoint for deterministic Western and Vedic astrology results, with SHA-256 hashes for verification. Its per-call REST payment options, x402 or MPP, distinguish it as an astrology service designed for agent use.
