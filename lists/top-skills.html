breakdown

obra / superpowers

This framework provides a library of composable skills for coding agents alongside workflows for TDD, debugging, and code review. It supports multiple agent harnesses through the use of plugins and extensions.

nexu-io / open-design

This local-first design and prototyping system includes CLI support for coding agents and supports exports for HTML, PDF, PPTX, and MP4. It features automation, a design system, and plugin capabilities.

mukul975 / Anthropic-Cybersecurity-Skills

This library contains 817 production-grade skills across 29 security domains, mapped to six major cybersecurity and AI frameworks. It is compatible with 26+ AI platforms and Hermes Agent.

Agents365-ai / drawio-skill

This tool converts Mermaid text into editable.drawio files and supports 11 diagram type presets. It includes self-check and auto-fix capabilities to generate diagrams from natural language.

conorbronsdon / avoid-ai-writing

This utility audits and rewrites content to eliminate detectable AI writing patterns using 57 pattern categories. It is compatible with Hermes, Claude Code, Cursor, and OpenClaw.

AMAP-ML / SkillClaw

This project enables collective skill evolution for shared user teams through an Agentic Evolver. It provides automated skill deduplication, quality improvement, and unified skill libraries across devices and agents.

wondelai / skills

This cross-platform library includes 12 metaskills designed for guided business and code journeys. It is compatible with agentskills.io and Claude Code, supporting installation via skills.sh.

internet-court / internet-court-skill

This skill acts as a trust layer for agent-to-agent commerce, providing adjudication for deals through escrow and dispute resolution. It includes a master router, connector skills, and vendored protocol skills.

mohitagw15856 / pm-claude-skills

This collection offers 822 professional agent skills in plain markdown format that run natively in Hermes Agent and Claude Code. It includes integrations for Slack, Obsidian, n8n, Raycast, and MCP.

Romanescu11 / hermes-skill-factory

This meta-skill plugin automatically detects and proposes reusable skills from active workflows. It generates Python plugin scaffolds and SKILL.md documentation using slash commands.

ZeroPointRepo / youtube-skills

This skill set enables video search, channel browsing, and playlist extraction for Hermes Agent and other agents. It extracts transcripts, captions, and timestamps without the use of yt-dlp.

DougTrajano / pydantic-ai-skills

This project provides type-safe agentskills.io support for Pydantic AI through modular packages of instructions, resources, and scripts. It implements progressive disclosure for prompt efficiency.

Cranot / super-hermes

This project enables Hermes Agent to generate custom thinking instructions for specific tasks using pre-built analytical lenses. It enhances agent reasoning by reporting findings alongside a report of analysis blind spots.

AkoliteZA / hermes-agent-idea-workflow

This skill set converts rough ideas into structured design and implementation documents through Lite and Full modes. It incorporates a spec review gate utilizing PASS/FAIL evaluation models to manage project complexity.

tlehman / litprog-skill

This skill implements literate programming by weaving prose, diagrams, and source code into.lit.md files. It uses a tangler to extract runnable source files and automatically syncs edits back to the documentation.

ReinaMacCredy / maestro

Designed for long-running AI agents, this harness provides a three-level work model and supports both file-backed and SQLite-backed cards. It includes a CLI for managing tasks and cards within a plan-approve-execute framework.

esaradev / icarus-plugin

This plugin facilitates cross-instance shared memory via markdown files and automates the capture of high-value decisions. It provides a pipeline for fine-tuning and switching to replacement models.

smartcontractkit / chainlink-agent-skills

These skills follow the Agent Skills specification to enable integration with CCIP, VRF, and Data Feeds. They include specialized skills for CRE and ACE services to support oracle network and smart contract interaction.

black-forest-labs / skills

This project provides standardized prompting guidelines for the FLUX.1 and FLUX.2 model families. It includes API integration patterns for polling, webhooks, and error handling, alongside support for JSON structured prompting.

armelhbobdad / bmad-module-skill-forge

This tool generates version-pinned instruction files by converting repositories, documentation URLs, or developer discourse into agentskills.io-compliant skills. It ensures provenance through the use of documentation URLs or file:line citations.

chigwell / skilldock.io

This registry offers reusable AI skills based on the AgentSkills specification and includes a Python SkilldockClient and a CLI. It supports skill installation with recursive dependency resolution and features commerce via TON payments.

tiann / execplan-skill

This skill enables autonomous execution for long-running, complex multi-step tasks. It provides real-time tracking of decisions and progress, including built-in rollback procedures for safe recovery.

cablate / Agentic-MCP-Skill

This skill implements a progressive MCP client using a three-layer lazy loading architecture to minimize token usage. It utilizes a socket-based daemon architecture for persistent connections and incremental discovery of tool schemas.

adnw-vinc / hermes-nextcloud

This skill enables management of files, notes, calendars, tasks, and contacts via WebDAV and CalDAV. It uses HTTPS and Nextcloud App Passwords for secure communication and includes a guided setup script for configuration.

supernovae-st / nika

This Rust binary executes workflows locally using a single file and four verbs. It audits costs, secrets, and types before token expenditure and generates hash-chained, verifiable receipts for every run.

willingning-coder / eagle-eye

This retrieval skill uses a five-layer approach involving hard triggers, FTS5, synonyms, dense embeddings, and RRF fusion. It reduces token usage by narrowing skill lists before LLM calls and features graceful degradation for missing dependencies.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across surfaces including CLI, TUI, Discord, and Telegram. It tailors rewrites to model family and reasoning capability while tracking quality and token savings in a local SQLite database.

Sahil-SS9 / hermaguard

This skill performs adversarial bug-hunting code reviews using three parallel subagents to analyze edge cases, exploitability, and integration risks. It operates in read-only mode and uses a deterministic pre-scan layer with Semgrep, Bandit, and Gosec.

PederHP / skillsdotnet

This.NET implementation of agentskills.io integrates with Microsoft.Extensions.AI for tool-based skill loading. It supports automatic registration of common agent skill directories and implements progressive disclosure via SKILL.md files.

teixeirazeus / fablize-for-hermes

This project implements multi-story task decomposition with mandatory evidence-based verification gates. It provides a systematic investigation protocol for causal debugging and uses a Python goal engine for persistent task state management.

Sahil-SS9 / hermes-simplify-swarm

This skill employs a three-agent swarm targeting hygiene, structural clarity, and logic correctness through a risk-tiered triage system. It includes language-specific detection for concurrency anti-patterns and N+1 queries.

amanning3390 / hermeshub

This hub provides community skill browsing, searching, and one-click installation based on the Agentic Resource Discovery (ARD) v0.9 specification. It features federated search integration with GitHub and Hugging Face.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server allows users to search over 13,870 MCP servers and 4,384 agent skills. It provides direct installation commands for discovered tools and integrates with MCP-compatible clients.

mag3nt-com / openclaw-skill

This skill automates payments for HTTP 402 responses using USDC. It supports Pay Link, x402, MPP, and AP2 protocols and is compatible with the agentskills.io standard.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news briefings ranging from global to street level. It produces structured reports with core conclusions and uses semantic memory to integrate user interests for search expansion.
