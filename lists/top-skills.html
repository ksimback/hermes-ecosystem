breakdown

obra / superpowers

Superpowers provides an agentic skills framework and a software development workflow covering specification, planning, and subagent-driven development. Skills trigger automatically in supported coding-agent harnesses, and the README provides installation instructions for multiple coding agents.

nexu-io / open-design

Open Design is a local-first system for creating and refining interactive web prototypes with a live preview, as well as slide decks, images, and motion graphics. Its skills, design templates, design systems, and plugins make it a design-focused addition to a skills list that also supports Hermes Agent.

mukul975 / Anthropic-Cybersecurity-Skills

This project offers structured cybersecurity skills across 34 security domains, with mappings to MITRE ATT&CK, ATLAS, D3FEND, and F3 frameworks. It stands out for its security focus and stated compatibility with more than 26 AI platforms.

Agents365-ai / drawio-skill

Drawio-skill turns natural-language prompts and real sources into editable .drawio diagrams. Its incremental sync preserves manual layout and annotations, and it also offers the diagramctl CLI with an optional MCP server.

internet-court / internet-court-skill

Internet Court provides a master router and connector skills, alongside vendored copies of official protocol skills. It adds a verification and dispute-resolution layer for agent-to-agent commerce.

conorbronsdon / avoid-ai-writing

Avoid AI Writing audits and rewrites content to address detectable AI-writing patterns, with a rewrite mode that allows up to two editing passes. Its detector scores files or piped text, while in-place editing refuses source code, configuration, and generated data.

sergebulaev / linkedin-skills

This collection provides 12 LinkedIn-focused skills for writing posts, drafting comments, auditing drafts, and planning a week of cadence. Drafts require approval before publishing, and the skills can be installed in Hermes Agent.

AMAP-ML / SkillClaw

SkillClaw unifies skills across agents and devices, with integrations for Hermes, Codex, Claude Code, and other agents. Its dashboard covers skills, validation, versions, and session traces.

wondelai / skills

This cross-platform library includes 51 expert frameworks and 14 guided metaskills for Claude Code and agents that support agentskills.io. It also maintains session state in the project's docs folder.

ZeroPointRepo / youtube-skills

YouTube skills covers transcripts, video search, channel browsing, and playlist extraction, with compatibility for Hermes Agent, OpenClaw, Claude Code, and Cursor. Use requires a TranscriptAPI key, which has a 100-credit free tier.

Romanescu11 / hermes-skill-factory

Hermes Skill Factory detects reusable patterns in active workflows and proposes skills based on them. It generates SKILL.md documentation and Python plugin scaffolds, and provides slash commands to manage, list, and save detected patterns.

Cranot / super-hermes

Super Hermes generates custom analytical instructions for specific tasks and includes pre-built lenses for various domains. It reports findings alongside an account of analysis blind spots.

DougTrajano / pydantic-ai-skills

Adds type-safe agentskills.io support for Pydantic AI, including progressive disclosure and remote skill registries sourced from Git or S3. It also provides tools for bundled resources and script execution, with sandboxing to isolate untrusted scripts from the host.

tlehman / litprog-skill

Creates .lit.md documents that combine prose, diagrams, and source code, then extracts runnable files from them with a tangler. It also syncs edits to source files back into the literate document, making it useful for keeping code and documentation aligned across agents.

AkoliteZA / hermes-agent-idea-workflow

Turns rough ideas into structured design and implementation documents for Hermes Agent, with Lite and Full modes for different project complexities. A spec review gate evaluates the documents with PASS/FAIL models, making this a fit for workflows that need a review before handoff.

ReinaMacCredy / maestro

Provides a harness for long-running AI agents, with structured memory, cross-feature learning, and a plan-approve-execute workflow. It requires no background service and includes an SLP protocol for supervised teams, plus CLI commands for installation, updates, and diagnostics.

esaradev / icarus-plugin

Shares memory across instances through Markdown files and automatically captures high-value decisions and outcomes. It also provides a pipeline for fine-tuning and switching to replacement models, connecting retained work context with model replacement.

Hermes-brasil / hermes-brasil

Offers Portuguese-language Hermes Agent skills in SKILL.md format, alongside guides covering installation, production, cron, MCP, and skill authoring. It belongs here as a Portuguese-language resource, with contributions submitted through pull requests.

black-forest-labs / skills

Provides prompting guidance for FLUX image and video generation, along with BFL API integration for polling and webhooks. Its FLUX 3 video suite includes eight specialist skills.

smartcontractkit / chainlink-agent-skills

Lists nine Chainlink skills, each following the Agent Skills specification, for oracle network and smart contract interactions. The README describes the repository as community examples only and gives an npx command for installation.

armelhbobdad / bmad-module-skill-forge

Creates agentskills.io-compliant agent instructions from repositories, documentation, and developer discourse. It supports both automated and step-by-step workflows, with skill testing and export.

supernovae-st / nika

Nika is a workflow language for AI with four verbs and a Rust binary; it checks workflows before calling a model. Runs can use a chosen model locally or through a provider API, and are recorded in a hash-chained trace.

chigwell / skilldock.io

Provides a registry of reusable AI skills based on the AgentSkills specification, with a Python SkilldockClient and CLI. It supports installation with recursive dependency resolution and includes commerce features using TON payments.

tiann / execplan-skill

Supports autonomous execution of long-running, multi-step tasks with real-time tracking of progress and decisions. Built-in checkpoints and rollback procedures make it a fit for task workflows that need recovery.

adnw-vinc / hermes-nextcloud

Manage Nextcloud files, notes, calendars, tasks, and contacts through WebDAV and CalDAV. Secure HTTPS connections use Nextcloud App Passwords, and a guided setup script helps validate credentials and configure the skill.

amanning3390 / hermeshub

Browse, search, and install community skills through a hub that implements the Agentic Resource Discovery v0.9 specification. It runs autonomously via Hermes Agent on NVIDIA infrastructure and federates search across GitHub and Hugging Face.

willingning-coder / eagle-eye

Find relevant Hermes Agent skills with five retrieval layers, from hard triggers to semantic embeddings. By narrowing the skill list before LLM calls, it reduces token usage; it can also degrade gracefully when embedding models or dependencies are unavailable.

cablate / Agentic-MCP-Skill

Agentic-MCP-Skill is a progressive MCP client that uses three-layer loading to minimize token usage, with server metadata and tool schemas discovered incrementally. Its socket-based daemon maintains persistent connections, making it a distinct choice for agents that need MCP access without loading everything up front.

Sahil-SS9 / hermaguard

Review code for bugs without modifying it, using parallel subagents to examine edge cases, adversarial risks, and integration issues. Deterministic pre-scans and proof-of-concept execution in a hardened sandbox help verify and triage findings.

EntangledQuantum / Life_OS

A locally run personal execution system with daily-scored recurring habits and tasks for other activities. It stores data in SQLite, includes an Android client, and connects to agents over MCP.

Sahil-SS9 / hermes-simplify-swarm

Simplify code with parallel Hygiene, Clarity, and Correctness agents, supporting TypeScript, JavaScript, Python, Go, and Rust. A tiered application process includes an approval gate.

doomsday-network / bounty-guard

Scan untrusted GitHub issues and repositories for prompt injection and repository threat signals, classifying issues as SAFE_WITH_ESCROW, SAFE_NO_ESCROW, or QUARANTINE. The project also provides MCP tools for escrow verification.

handnewb / hermes-cybersec-lab

A cybersecurity lab for Hermes Agent that combines 2,077 skills across multiple repositories with 131+ tools for network work, forensics, and exploitation. It also integrates 28 cybersecurity frameworks and standards.

teixeirazeus / fablize-for-hermes

Adapt verified procedures for task decomposition, investigation, and evidence-based verification, including mandatory gates for multi-story tasks. A Python goal engine manages persistent task state.

PederHP / skillsdotnet

A C#/.NET implementation of agentskills.io that loads skills progressively through SKILL.md files. It integrates with Microsoft.Extensions.AI for tool-based loading and can register common agent skill directories automatically.

doomsday-network / web3-agent-skills

A skill pack for verifying GitHub bounties and mining pool shares, with a remote MCP server offering escrow and pool leaderboard tools. It includes commands to scan bounty issues and mine pool shares, plus configurations for Claude Code, Cursor, Windsurf, and Cline.

Diabloluo / hermes-hud

A local, read-only dashboard for monitoring Hermes Agent activity, including token costs, session history, skill analytics, health, and incidents. Its local-first approach includes log desensitization and optional incident alerts via Telegram or Feishu.

conorbronsdon / agent-skills

A collection of plain-markdown agent skills covering code review and session management, including multi-session reconciliation and worktree recovery. Skills can be installed by copying a directory or using the bundled installer.

conorbronsdon / demo-gif-skill

This Claude Code skill creates reproducible demo GIFs for project READMEs using vhs or Playwright recording scripts. It also optimizes GIFs toward a target size under 8 MB and supports terminal tools, web apps, and libraries.

conorbronsdon / agent-skill-builder

A skill for generating Claude Code extensions and portable Agent Skills core files, with validation against runtime-specific profiles. It also monitors official frontmatter specifications weekly to detect field changes.

aidevelopers2 / remoteopenclaw-mcp

A CLI and MCP server for searching MCP servers, agent skills, and plugins from remoteopenclaw.com, with direct installation commands for discovered tools. It supports MCP-compatible clients including Hermes, Cursor, and Claude Code.

Carlo1911 / skill-evolution

This host-agnostic feedback loop analyzes past sessions and installed skills to draft structured improvement proposals. Proposals are review-only by default, with an evaluation gate that supports deterministic, LLM-judge, and regression evaluators.

superagnt / leverage

Leverage provides agent skills for social platforms and web data, along with packaged skills for complete jobs. Its skills can be installed through SKILL.md-compatible clients.

CorsenAI / hermes-windows-runtime-skills

A set of Hermes Agent skills for routing file operations with environment-specific path syntax and selecting existing, project-compatible Python interpreters. It supports native Windows, Git Bash/MSYS, and WSL.

jiawood2006 / hermes-skills

This collection includes tools to transcribe Douyin videos into structured Markdown and SRT subtitles, reduce common Chinese AI-writing patterns with rules, and extract structured data from PDFs and images using macOS Vision. It brings video, writing, OCR, and e-commerce material workflows together.

webmilmind1 / hermes-bounty-board

This Hermes Agent plugin lets agents find support bounties, purchase ticket context, and submit answers for human review, with USDC payments for winning answers. It also supports creating a bounty board and provides public wallet earnings records.

f-o-x11 / deed-page-skill

This skill publishes files or folders to a permanent deed.page URL with one curl request, without an account or API key. It includes a hosted MCP server configuration and installation instructions for agents including Hermes Agent.

mag3nt-com / openclaw-skill

This skill automates USDC payments for HTTP 402 responses using Pay Link, x402, MPP, and AP2 protocols. It is compatible with OpenClaw, Hermes Agent, and the agentskills.io standard.

skillseal / skillseal

Skillseal tests AI agent skills in isolated Docker containers for structure, functionality, and security. It also issues Ed25519-signed certificates that can be verified through its public API, making it a fit for checking whether a skill works before use.

scavio-ai / hermes-agent

This Hermes Agent project provides structured web data across 31 platforms through a hosted MCP server exposing 191 tools, along with five ready-to-use workflow skills. It stands out for its support for Claude, Cursor, Goose, and OpenHands as well as Hermes Agent.

parkyucheol-del / alphapipeline

Alphapipeline provides risk checks for token honeypots, tax, and liquidity, alongside market data such as DEX slippage and funding rates. It offers these capabilities through REST endpoints and a remote MCP server.

NickSF189 / kisscode-agent

This repository provides a skill for AI agents to join KissCode, including SKILL.md and HEARTBEAT.md. It includes installation instructions for several agent environments and mirrors kisscode.ai/skill.md.

Shine8592 / china-briefing

China Briefing generates structured Chinese news reports across geographic scales, from global to street level, with conclusions and action suggestions. It can also use semantic memory of user interests to expand searches.

aidatatools-dev / astro-agents-mcp

This astrology server offers tools for charts, transits, aspects, and Vedic calculations, and resolves time zones and historical offsets from coordinates. It supports MCP and REST, with REST payments via x402 or MPP.
