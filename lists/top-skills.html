breakdown

obra / superpowers

This framework provides an agentic skills methodology utilizing subagent-driven development for autonomous task execution. It integrates with coding harnesses such as Claude, Codex, and Cursor while enforcing TDD and YAGNI principles.

nexu-io / open-design

A local-first design and prototyping system for macOS and Windows that generates web, mobile, and desktop prototypes. It supports multiple coding agents and CLI executables, including Hermes Agent.

mukul975 / Anthropic-Cybersecurity-Skills

This repository contains 817 structured cybersecurity skills mapped across 29 security domains. These skills align with six industry frameworks and are compatible with over 26 AI platforms.

topoteretes / cognee

This platform provides persistent long-term memory for AI agents through a self-hosted knowledge graph engine. It is capable of building knowledge graphs from any data format and supports Rust and TypeScript clients.

Agents365-ai / drawio-skill

This tool converts Mermaid text into editable.drawio files and supports 11 diagram type presets. It features built-in self-check and auto-fix capabilities for natural language diagram generation.

internet-court / internet-court-skill

This skill set acts as a trust layer for agent-to-agent commerce, incorporating escrow, dispute resolution, and delegated permissions. It functions as an open, catch-all Agent Skill for Claude Code.

conorbronsdon / avoid-ai-writing

This utility audits and rewrites content to remove detectable AI writing patterns using a two-pass detection process. It is compatible with Hermes, Cursor, Claude Code, and OpenClaw.

AMAP-ML / SkillClaw

This tool automates skill deduplication and quality improvement through an agentic evolver. It synchronizes skill libraries across team environments and multiple devices while integrating with Hermes and OpenAI-compatible APIs.

wondelai / skills

A cross-platform skills library designed for agentskills.io-compatible agents and Claude Code. It includes 12 metaskills that utilize a docs/ folder to preserve state.

mohitagw15856 / pm-claude-skills

This collection offers 1,117 task-specific markdown files for professional agent use. These skills run natively in Hermes Agent and Claude Code and can be exported for ChatGPT, Gemini, Cursor, and Codex.

ZeroPointRepo / youtube-skills

This skill set provides functionality for YouTube transcripts, search, channels, and playlists. It is powered by TranscriptAPI and is compatible with the Agent Skills format.

Romanescu11 / hermes-skill-factory

This meta-skill plugin automatically detects and proposes reusable skills from active workflows. It generates Python plugin scaffolds and SKILL.md documentation, including slash commands for pattern management.

Cranot / super-hermes

This project enables Hermes Agent to generate custom thinking instructions for specific tasks using pre-built analytical lenses. It enhances reasoning by reporting findings alongside a report of analysis blind spots.

DougTrajano / pydantic-ai-skills

This library provides type-safe support for agentskills.io through modular packages containing instructions, resources, and scripts. It implements progressive disclosure for prompt efficiency and supports remote registries.

AkoliteZA / hermes-agent-idea-workflow

This workflow converts rough ideas into structured design and implementation documents. It features Lite and Full modes for different project complexities and includes a spec review gate with PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill facilitates literate programming by generating.lit.md files that combine prose, diagrams, and source code. It uses a tangler to extract runnable source files and automatically syncs edits back to the document.

ReinaMacCredy / maestro

This harness supports long-running AI agents using a three-level work model. It provides structured memory via file-backed or SQLite-backed cards and includes a CLI for task and card management.

esaradev / icarus-plugin

This plugin enables cross-instance shared memory via markdown files to capture high-value decisions and outcomes. It provides a pipeline for fine-tuning and switching to replacement models.

smartcontractkit / chainlink-agent-skills

This project provides integration for CCIP, VRF, and Data Feeds following the Agent Skills specification. It includes specialized skills for CRE and ACE services.

Hermes-brasil / hermes-brasil

This community resource provides skills in SKILL.md format and installation guides in Portuguese. It supports the agentskills.io standard.

black-forest-labs / skills

This repository provides prompting guides for FLUX.2 and FLUX.1 models along with API integration documentation. It offers a suite of six specialized FLUX 3 video skills.

armelhbobdad / bmad-module-skill-forge

This tool generates version-pinned skills from code or documentation with provenance via file and line number citations. It supports both Node.js and Python environments.

chigwell / skilldock.io

This registry provides a Python SkilldockClient and a CLI for installing reusable AI skills with recursive dependency resolution. It includes commerce features using TON payments.

tiann / execplan-skill

This skill enables autonomous execution for long-running tasks with real-time progress and decision tracking. It includes built-in rollback procedures for safe recovery.

supernovae-st / nika

This Rust-based workflow language provides intent as code through a single binary. It enables static auditing for cost, secrets, and types while generating tamper-evident execution receipts.

adnw-vinc / hermes-nextcloud

This skill enables management of files, notes, calendars, tasks, and contacts via WebDAV and CalDAV. It communicates securely over HTTPS using Nextcloud App Passwords.

cablate / Agentic-MCP-Skill

This MCP client utilizes a three-layer progressive loading architecture to minimize token usage. It employs a socket-based daemon for persistent connections and incremental discovery of tool schemas.

willingning-coder / eagle-eye

This skill implements a five-layer retrieval system using hard triggers, FTS5, synonyms, dense embeddings, and RRF fusion. It reduces token usage by narrowing skill lists prior to LLM calls.

Sahil-SS9 / hermaguard

This read-only skill performs adversarial code reviews using three parallel subagents to identify edge cases and exploitability. It verifies findings via sandbox execution to provide VERIFIED or REFUTED status.

amanning3390 / hermeshub

This hub provides community skill browsing, search, and one-click installation. It implements the Agentic Resource Discovery (ARD) v0.9 specification and features federated search with GitHub and Hugging Face.

EntangledQuantum / Life_OS

This personal execution OS uses local SQLite storage to manage habits and study blocks. It connects to AI agents via the Model Context Protocol (MCP).

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across various surfaces, including CLI, TUI, Discord, and Telegram. It supports 97 languages and can reduce token usage by 20–80% per rewrite.

teixeirazeus / fablize-for-hermes

This project implements multi-story task decomposition with mandatory evidence-based verification gates. It provides a systematic investigation protocol and a Python goal engine for task state management.

Sahil-SS9 / hermes-simplify-swarm

This skill uses three parallel sub-agents—Hygiene, Clarity, and Correctness—to simplify code in TypeScript, JavaScript, Python, Go, and Rust. It features a tiered application process with an approval gate.

PederHP / skillsdotnet

This.NET implementation of agentskills.io integrates with Microsoft.Extensions.AI for tool-based skill loading. It supports automatic registration of common agent skill directories via SKILL.md files.

handnewb / hermes-cybersec-lab

This lab provides over 2,000 skills and 131+ tools for network, forensics, and exploitation. It integrates 28 cybersecurity frameworks, including MITRE ATT&CK and NIST.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server enables searching over 13,870 MCP servers and 4,384 agent skills. It provides direct installation commands for discovered tools and integrates with MCP-compatible clients like Hermes.

mag3nt-com / openclaw-skill

This project automates payments for HTTP 402 responses using USDC. It supports Pay Link, x402, MPP, and AP2 protocols and is compatible with the agentskills.io standard.

skillseal / skillseal

This tool tests the structure, functionality, and security of AI agent skills within isolated Docker containers. It produces cryptographically verifiable certificates using Ed25519 signatures and provides a public API for verification.

webmilmind1 / hermes-bounty-board

This plugin allows users to earn USDC on the Base network by answering support bounties without requiring an account or API key. It includes tools for listing bounties, buying context, and creating boards.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news briefings ranging from global to street level. It produces structured reports with core conclusions and integrates user interests via semantic memory.

jiawood2006 / hermes-skills

This suite provides video-to-text transcription, local OCR for PDFs and images, and batch e-commerce material generation. It includes specialized tools for AI text de-humanization and brand overlays.

CorsenAI / hermes-windows-runtime-skills

This skill set manages deterministic path routing and Python runtime selection across Windows, Git Bash/MSYS, and WSL. It ensures file operations use environment-specific path syntax and verifies project-compatible interpreters.

scavio-ai / hermes-agent

This project exposes 191 tools via a hosted MCP server to provide structured web data across 31 platforms. It includes five production-grade skills and supports Claude, Cursor, Goose, and OpenHands.
