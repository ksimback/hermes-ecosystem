breakdown

obra / superpowers

This framework implements subagent-driven development to enable autonomous task execution for Hermes Agent. It enforces rigorous software engineering standards, including red-green-refactor TDD and YAGNI principles, across multiple coding harnesses.

nexu-io / open-design

A local-first prototyping system that provides Hermes Agent with a CLI for generating web, mobile, and desktop designs. It supports application development on macOS and Windows, bridging the gap between design specs and agentic coding.

mukul975 / Anthropic-Cybersecurity-Skills

This library equips agents with 817 structured security skills mapped to industry frameworks like MITRE ATT&CK and NIST CSF 2.0. It spans 29 security domains and maintains compatibility across more than 26 AI platforms.

topoteretes / cognee

Cognee functions as a self-hosted knowledge graph engine that provides AI agents with persistent long-term memory across different sessions. It processes various data formats into a graph structure and offers dedicated clients for Rust and TypeScript.

Agents365-ai / drawio-skill

This skill enables Hermes Agent to transform natural language descriptions and Mermaid text into editable .drawio files. It features 11 diagram presets and includes built-in self-check and auto-fix capabilities to ensure diagram accuracy.

internet-court / internet-court-skill

Acting as a trust layer for agent-to-agent commerce, this project provides a master router for delegated permissions and x402 payments. It integrates escrow and dispute resolution services to facilitate secure financial transactions between autonomous agents.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI patterns using a two-pass detection process and a 112-entry word replacement table. It is specifically designed for compatibility with Hermes, Claude Code, and Cursor environments.

AMAP-ML / SkillClaw

SkillClaw uses an Agentic Evolver to automate skill deduplication and quality improvements across team environments. It synchronizes skill libraries across multiple devices and integrates with Hermes, Codex, and OpenAI-compatible APIs.

wondelai / skills

This cross-platform library provides 12 metaskills that allow agents to preserve state within a local directory. These skills are delivered as spec-conformant plugins compatible with Claude Code and agentskills.io-compliant systems.

mohitagw15856 / pm-claude-skills

This collection features 1,117 task-specific markdown files designed to run natively in Hermes Agent and Claude Code. It provides a vast library of 822 professional skills with ready-to-paste exports for other assistants like Gemini and ChatGPT.

ZeroPointRepo / youtube-skills

This skill set allows Hermes Agent to extract transcripts, search results, and channel data directly from YouTube. It requires a TranscriptAPI key and is compatible with various coding environments including OpenClaw and Windsurf.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that monitors active workflows to automatically detect and propose reusable skill patterns. It generates both SKILL.md documentation and Python scaffolds, allowing agents to self-expand their capabilities via slash commands.

Cranot / super-hermes

This project enables Hermes Agent to generate its own analytical prompts and custom thinking instructions for specific domains. It enhances critical output by reporting findings alongside an assessment of potential analysis blind spots.

DougTrajano / pydantic-ai-skills

This toolkit provides type-safe support for Pydantic AI through modular packages containing instructions, resources, and scripts. It utilizes progressive disclosure to maintain prompt efficiency and supports both programmatic skills and remote registries.

AkoliteZA / hermes-agent-idea-workflow

These skills automate the transition from rough concepts to structured design and implementation documents. The workflow features Lite and Full modes for varying complexity and includes a spec review gate with PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill implements literate programming by weaving prose, diagrams, and source code into .lit.md files. It includes a tangler to extract runnable source files and automatically syncs code edits back to the primary documentation.

ReinaMacCredy / maestro

Maestro provides a harness for long-running agents using a three-level work model and structured memory backed by files or SQLite. It facilitates cross-feature learning and includes a CLI for managing tasks and cards through a plan-approve-execute cycle.

esaradev / icarus-plugin

This plugin establishes cross-instance shared memory via markdown files to capture high-value decisions and outcomes. It creates a pipeline for fine-tuning and transitioning to replacement models based on recorded work history.

smartcontractkit / chainlink-agent-skills

These interoperable skills follow the Agent Skills specification to enable direct interaction with Chainlink services like CCIP, VRF, and Data Feeds. They provide specialized capabilities for integrating oracle networks and smart contracts into agent workflows.

Hermes-brasil / hermes-brasil

This project serves the Brazilian community by providing Hermes Agent skills, installation guides, and configuration resources in Portuguese. All skills are delivered in the SKILL.md format and adhere to the agentskills.io standard.

black-forest-labs / skills

These official skills provide API integration and prompting guidelines for FLUX.1 and FLUX.2 image generation models. The repository also includes a specialized suite of six skills for FLUX 3 video generation.

armelhbobdad / bmad-module-skill-forge

This tool converts repositories, documentation, and developer discourse into version-pinned, agentskills.io-compliant skills. It supports Node.js and Python environments while providing provenance through file and line number citations.

chigwell / skilldock.io

This registry facilitates the discovery and installation of reusable AI skills with recursive dependency resolution. It includes a Python client and CLI, as well as commerce features powered by TON payments.

tiann / execplan-skill

This skill manages complex, multi-step tasks by providing autonomous execution with real-time progress and decision tracking. It ensures operational safety through built-in checkpoints and rollback procedures for recovery.

supernovae-st / nika

This project introduces a workflow language that audits AI intents for cost, permissions, and types before execution. It generates verifiable, hash-chained receipts for every run and supports local execution via Ollama.

adnw-vinc / hermes-nextcloud

This skill enables Hermes to manage files, notes, calendars, and contacts through standard WebDAV and CalDAV protocols. It features a guided setup script for secure HTTPS communication using Nextcloud App Passwords.

cablate / Agentic-MCP-Skill

A progressive MCP client that utilizes a three-layer lazy loading architecture to minimize token usage. It employs a socket-based daemon for persistent connections and incremental discovery of tool schemas.

willingning-coder / eagle-eye

This retrieval skill uses a five-layer system, including hard triggers and semantic embeddings, to narrow skill lists before LLM calls. It reduces token overhead and features graceful degradation if specific embedding dependencies are missing.

Sahil-SS9 / hermaguard

This read-only tool performs adversarial code reviews using three parallel subagents to identify edge cases and exploitability. It combines deterministic pre-scans from tools like Semgrep with sandbox execution to verify or refute findings.

amanning3390 / hermeshub

A community hub for browsing and installing skills that implements the Agentic Resource Discovery (ARD) v0.9 specification. It operates autonomously on NVIDIA infrastructure and provides federated search across GitHub and Hugging Face.

EntangledQuantum / Life_OS

An ADHD-friendly execution system where an AI agent manages system design while the user completes tasks via a tap-based interface. It stores data locally using SQLite and connects to agents through the Model Context Protocol.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across various interfaces like Discord and CLI to reduce token usage by up to 80%. It supports 97 languages and evaluates prompt quality across five distinct dimensions.

teixeirazeus / fablize-for-hermes

This project adapts verified procedures for task decomposition and evidence-based verification gates. It includes a systematic investigation protocol for debugging and a Python goal engine for persistent state management.

Sahil-SS9 / hermes-simplify-swarm

A code simplification skill that utilizes parallel agents focused on hygiene, clarity, and correctness. It supports multiple languages including Rust and Python, featuring a tiered application process with a final approval gate.

PederHP / skillsdotnet

This C# and .NET implementation of the agentskills.io pattern enables progressive disclosure via SKILL.md files. It integrates with Microsoft.Extensions.AI for tool-based loading and automatic skill directory registration.

handnewb / hermes-cybersec-lab

A comprehensive cybersecurity lab providing over 2,000 skills and 131 tools for forensics and exploitation. it integrates 28 frameworks, including MITRE ATT&CK and NIST, to handle CVE-driven tasks.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server enables terminal-based searching of over 13,870 MCP servers and 4,384 agent skills. It provides direct installation commands for discovered tools and integrates with MCP-compatible clients like Hermes and Cursor.

mag3nt-com / openclaw-skill

This skill automates USDC payments for HTTP 402 responses using protocols such as Pay Link and x402. It is designed for compatibility with the agentskills.io standard and the Hermes Agent environment.

skillseal / skillseal

Skillseal provides a functional quality seal by testing agent skills for structure, functionality, and security within isolated Docker containers. It issues cryptographically verifiable Ed25519 certificates and offers a public API for skill submission and verification.

CorsenAI / hermes-windows-runtime-skills

This skill set manages deterministic path routing and Python runtime selection across Windows, Git Bash, and WSL environments. It ensures compatibility by verifying existing interpreters and routing file operations using environment-specific syntax.

webmilmind1 / hermes-bounty-board

This plugin allows users to earn USDC on the Base network by answering support bounties without requiring accounts or API keys. It includes tools for listing bounties and creating boards, with 85% of the payment automatically routed to the winning wallet upon human approval.

Shine8592 / china-briefing

This news briefing generator for Hermes Agent produces structured reports across geographic scales ranging from global to street level. It utilizes semantic memory to integrate user interests and applies quality gates to AI-generated analysis and action suggestions.

jiawood2006 / hermes-skills

This collection provides utilities for video-to-text transcription, local OCR for PDFs and images, and batch e-commerce material generation. It also includes a specialized tool for removing 'AI flavor' from generated text to improve copy quality.

scavio-ai / hermes-agent

Scavio exposes 191 tools and five production-grade workflow skills through a hosted MCP server. The project provides structured web data access across 31 platforms for clients including Hermes, Claude, and OpenHands.
