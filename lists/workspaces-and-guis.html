breakdown

farion1231 / cc-switch

A cross-platform manager for Claude Code, Codex, OpenCode, OpenClaw, Gemini CLI, and Hermes Agent. It is built with Tauri 2 to provide efficient desktop performance on Windows, macOS, and Linux.

iOfficeAI / AionUi

This local open-source cowork app unifies multiple CLI agents, including Hermes Agent and OpenClaw, into a single interface. It features a built-in agent engine with zero configuration and automates document creation for Word, Excel, and PPT.

nesquena / hermes-webui

A web-based interface that provides full parity with the Hermes CLI experience. It features a three-panel layout with workspace file browsing and supports secure remote access via SSH tunneling.

fathah / hermes-desktop

A desktop companion app designed for installing, configuring, and chatting with Hermes Agent. It provides a GUI for managing sessions, tools, and multiple AI providers through a guided setup.

EKKOLearnAI / hermes-web-ui

A web dashboard that supports multi-platform AI chat, session management, and scheduled jobs. It includes a file browser, web terminal, and usage analytics, with unified configuration for Telegram, Discord, Slack, and WhatsApp.

outsourc-e / hermes-workspace

A native web workspace featuring a chat interface, terminal, memory browser, skills manager, and inspector panel. It supports Swarm Mode with role-based dispatch and tmux-backed workers.

dodo-reach / hermes-desktop

A native Mac workspace that enables direct local or SSH connections to Hermes hosts. It includes native views for sessions, Kanban, skills, and cron jobs, alongside an embedded terminal for system repair.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension that connects the active browser context to a local, remote, or Hermes Cloud runtime. It provides a full-page Hermes Web workspace for Chrome, Edge, and Chromium.

Eynzof / hermes-agent-cn-desktop

A Windows-first desktop application built with Tauri, TypeScript, and Rust that supports both Windows and macOS. It includes a built-in Hermes-CN-Core runtime and supports Markdown and LaTeX rendering.

xaspx / hermes-control-interface

A self-hosted web dashboard providing a browser-based terminal, file explorer, and agent status panel. It features real-time chat with tool call visualization and a ZOO Swarm Monitor for tracking agent health.

jazzyalex / agent-sessions

A native macOS application that serves as a session browser, agent cockpit, and analytics tool. It provides a searchable view of multiple AI coding agent histories and tracks live per-session token throughput.

nickvasilescu / hermes-desktop-os1

A native macOS workspace designed for running Hermes Agent on SSH hosts or Orgo cloud computers. It features one-click automated installation and integrated WebRTC voice mode via Orgo MCP.

liftaris / herm

An alternative Hermes TUI and dashboard built with OpenTUI. It consolidates chat, sessions, and configuration into a terminal dashboard and includes integrated kanban boards and an Eikon avatar system.

clawvader-tech / hermes-telegram-miniapp

A React-based mobile-first UI for Telegram Mini App v2.0 that runs locally. It supports terminal chat with streaming responses, file attachments, and background agent spawning for up to five concurrent instances.

aivrar / portable-hermes-agent

A portable, no-install Windows desktop application that requires no admin rights or Docker. It includes 100 tools, such as TTS and ComfyUI, and features a workflow engine for multi-step automation pipelines.

pyrate-llama / hermes-ui

A glassmorphic web interface for self-hosted Hermes Agent chat and real-time log streaming. It includes integrated task tracking, a file browser, and management tools for MCP servers, skills, and cron jobs.

sanchomuzax / hermes-webui

A dashboard focused on process monitoring and configuration for Hermes. It provides real-time tracking of session activity and costs, alongside inspection tools for skill source code and environment variables.

Euraika-Labs / pan-ui

A self-hosted AI workspace featuring chat with real-time SSE streaming and tool approval cards. It includes an integrated marketplace for skills and MCP servers, plus isolated profile management for API keys and memory.

Felix-Forever / hermes-agent-desktop

A multi-agent desktop client that orchestrates collaboration between 20 specialized AI agents. It features a visual Skill Store with over 50 curated installations and a native interface for streaming SSE responses.
