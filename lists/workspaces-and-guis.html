breakdown

farion1231 / cc-switch

CC-Switch is a cross-platform manager for Hermes Agent and several other agent CLIs, including Claude Code, Codex, and Gemini CLI. It lets users switch API providers in one click and manage MCP, Skills, and Prompts in one place, with versions for Windows, macOS, and Linux.

iOfficeAI / AionUi

AionUi is a local, open-source cowork app for Hermes Agent and other agent CLIs. Its built-in agent offers file access, web search, and image generation, while 21 ready-to-use professional assistants and support for macOS, Windows, and Linux make it a broader workspace option.

nesquena / hermes-webui

Hermes WebUI provides browser-based access to Hermes Agent, including from a phone, without a build step or framework. Its three-panel layout combines chat with a workspace file browser, and the project documents access through an SSH tunnel.

fathah / hermes-desktop

Hermes Desktop is a desktop companion for installing, configuring, and chatting with Hermes Agent, using the official Hermes install script. Its GUI manages profiles, sessions, skills, and tools, and the app is available from the project website or GitHub Releases.

EKKOLearnAI / ekko-studio

Ekko Studio is a Hermes Agent web dashboard for chat, session management, scheduled jobs, usage analytics, and channel configuration. It also offers shared and group chats, visual workflows, persistent sessions, and tools for files, voice, devices, and agent management; it is available as a desktop app, npm package, or Docker image.

outsourc-e / hermes-workspace

Hermes Workspace brings chat, a terminal, a memory browser, a skills manager, and an inspector into a native web workspace. Its Swarm Mode supports role-based dispatch with tmux-backed workers, alongside an MCP catalog and a file browser with Monaco and a PTY terminal.

spacering-net / codeg

CodeG is a collaborative multi-agent coding workspace that aggregates sessions from Hermes and other coding agents, including Claude Code, Codex, and OpenCode, as a desktop or self-hosted app. Users can import, search, resume, and hand off sessions, then delegate tasks with @ or queue them in separate worktrees.

dodo-reach / hermes-desktop

This Hermes desktop workspace connects directly to local or SSH-hosted Hermes systems, with native views for sessions, Kanban, skills, and cron jobs. Its embedded terminal provides direct shell access for tasks such as system repair.

Eynzof / Hermes-CN-Desktop

Hermes-CN-Desktop is a Windows-first Chinese desktop app for Hermes Agent, with support for Windows and macOS. It includes a Hermes-CN-Core kernel with health checks and updates, plus interfaces for chat, memory management, and LaTeX and Markdown rendering.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension connects active browser context to a local, Cloud, or remote Hermes Agent runtime. Its Bot Mode supports agent switching and group chats; the project notes that Firefox omits Chromium-only real-tab attachment.

uzairansaruzi / hermex

Hermex is a native SwiftUI iPhone client for driving a self-hosted Hermes Agent, pairing with a hermes-webui server. It requires you to run the server, supports iOS 18 and later, and is described as free with no analytics or tracking.

freestylefly / wesight

Wesight is a desktop AI agent workspace with one-click setup for Hermes Agent, Claude Code, Codex, and OpenClaw, plus custom LLM model routing. Its runtime dashboard tracks token usage and latency, while a live workspace shows code writes and diffs.

joeynyc / hermes-hud

Hermes HUD is an interactive TUI with nine tabs and four selectable color themes for monitoring Hermes. It tracks agent growth, git projects, and cron jobs, and adds a tmux operator view for managing live agent panes.

jazzyalex / agent-sessions

Agent Sessions is a native macOS browser and cockpit for Hermes sessions and sessions from other coding-agent CLIs. It lets users search prompts, responses, tool activity, errors, and supported image references, resume supported sessions in Terminal.app, iTerm2, or Warp, and view Codex and Claude quota burn per session.

xaspx / hermes-control-interface

Hermes Control Interface is a self-hosted web dashboard for the Hermes AI agent stack, bringing browser-based tools and agent status into one place. Its highlights include streaming chat with tool-call visualization, an MCP server control plane, and a ZOO Swarm Monitor for agent health and kanban pipelines.

nickvasilescu / hermes-desktop-os1

Hermes Desktop OS1 is a native macOS workspace for running Hermes Agent on Orgo cloud VMs and SSH hosts. It includes one-click automated installation on fresh cloud computers and WebRTC voice mode using OpenAI Realtime and Orgo MCP.

sharbelxyz / hermes-agent-mission-control

Hermes Agent Mission Control is a self-hostable dashboard template that connects a local Hermes agent to web dashboards through a Postgres message bus. Its approval inbox lets users review requests with side effects before they proceed.

liftaris / herm

Herm is an alternative Hermes TUI and dashboard built with OpenTUI for chatting and managing agent sessions. It also combines a kanban board for agentic work with controls for profiles, skills, cron jobs, and toolsets.

clawvader-tech / hermes-telegram-miniapp

Hermes Telegram Mini App is a locally run, mobile-first React SPA dashboard for Telegram Mini App v2.0. Its features include streaming terminal chat with file attachments, Telegram validation using dual HMAC-SHA256 and Ed25519 authentication, and background spawning for up to five agent instances.

aivrar / portable-hermes-agent

Portable Hermes Agent packages Hermes as a Windows desktop app with a GUI and 100 tools across more than 20 toolsets. It supports cloud AI and LM Studio local models, and includes a workflow engine for scheduling, conditions, loops, and parallel execution.

pyrate-llama / hermes-ui

Hermes UI is a self-hosted AI assistant interface with a glassmorphic design, chat, and real-time log streaming. It also provides a file browser, task tracking dashboard, and management tools for skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

Hermes WebUI is a dashboard for monitoring and configuring Hermes, with real-time session activity and cost tracking. Users can inspect conversation histories and skill source code, while configuration and environment variables are available for read-only monitoring.

Euraika-Labs / pan-ui

Pan UI is a self-hosted AI workspace centered on chat, with real-time SSE streaming and tool approval cards. It also includes a marketplace for skills and MCP servers, plus isolated profiles for separate sessions, memory, and API keys.

Felix-Forever / hermes-agent-desktop

Hermes Agent Desktop is a multi-agent desktop client with streaming chat, model switching, and collaboration among 20 specialized AI agents. Its visual Skill Store offers more than 50 curated one-click installations, alongside a PM orchestrator.
