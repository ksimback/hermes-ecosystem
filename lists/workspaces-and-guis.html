breakdown

farion1231 / cc-switch

A lightweight Tauri-based manager that provides a unified desktop interface for Hermes Agent alongside other major CLI tools like Claude Code and Gemini. It simplifies cross-platform usage on Windows, macOS, and Linux by acting as a centralized hub for multiple agentic environments.

iOfficeAI / AionUi

This local cowork application offers a comprehensive GUI for Hermes Agent and over 13 other CLI agents, featuring a built-in engine for web search and MCP tool integration. It distinguishes itself with automated document generation capabilities, allowing users to create editable PPT, Word, and Excel files directly through the agent.

nesquena / hermes-webui

A lightweight Python and JavaScript web interface designed to mirror the full Hermes CLI experience on mobile and desktop browsers. It features a functional three-panel layout that allows users to chat, manage sessions, and browse their workspace files simultaneously.

fathah / hermes-desktop

A dedicated companion app that streamlines the Hermes Agent experience through guided installation and dependency resolution. It provides a unified GUI for managing 14 distinct toolsets, including web browsing and code execution, alongside session history and profile management.

EKKOLearnAI / hermes-web-ui

This dashboard focuses on multi-platform connectivity, allowing users to configure Hermes Agent for use across Telegram, Discord, Slack, and WhatsApp. It supports isolated profiles for distinct models and memory, featuring detailed tool call inspection and markdown rendering for local sessions.

outsourc-e / hermes-workspace

A native web workspace that introduces a 'Swarm Mode' for role-based dispatching using tmux-backed workers. It integrates a Monaco-powered file browser and a PTY terminal with a specialized memory browser and MCP catalog for advanced development workflows.

dodo-reach / hermes-desktop

A native macOS workspace that prioritizes direct system access via real SSH and terminal connections to local or remote Hermes hosts. It includes specialized native views for Kanban boards, cron jobs, and system repair tasks, making it ideal for power users managing remote environments.

Eynzof / hermes-agent-cn-desktop

Built with Tauri and Rust, this Windows-optimized desktop application provides a localized interface for managing both local and cloud model providers. It offers advanced UI components for monitoring tasks, skills, and memory, specifically tailored for the Chinese-speaking developer community.

xaspx / hermes-control-interface

A self-hosted dashboard that serves as a control plane for managing MCP server lifecycles and monitoring agent health. It features a 'ZOO Swarm Monitor' and a Kanban pipeline view to track complex agentic workflows and system metrics in real-time.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension bridges the gap between web browsing and Hermes Agent by syncing tools and memory directly into the browser. It allows the agent to capture page text, metadata, and URLs for context-aware prompting without leaving the active tab.

jazzyalex / agent-sessions

A native macOS cockpit designed for transcript inspection and analytics across Hermes and other coding agents. It stands out by providing live quota tracking and burn-rate analytics to help users monitor the costs and resource usage of active agent sessions.

nickvasilescu / hermes-desktop-os1

This macOS workspace is designed for Orgo cloud computers, offering one-click automated Hermes installation on fresh cloud VMs. It features a unique WebRTC voice mode that utilizes OpenAI Realtime for hands-free interaction with the agent.

liftaris / herm

An alternative TUI and dashboard built with OpenTUI that brings a terminal-centric management style to Hermes Agent. It combines markdown and LaTeX rendering with Kanban boards for diagnosing agentic work and managing profiles and skills from the command line.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA that functions as a Telegram Mini App, providing a terminal-style chat interface with vision support. It allows users to spawn up to five concurrent background agent instances while monitoring real-time system metrics like CPU and disk usage.

aivrar / portable-hermes-agent

A zero-install Windows solution that bundles Hermes Agent with 100 tools, including ComfyUI and TTS, without requiring admin rights or Docker. It features a workflow engine for building multi-step automation pipelines and supports local models via LM Studio.

pyrate-llama / hermes-ui

A glassmorphic web interface that emphasizes visual aesthetics while providing real-time log streaming and task tracking. It includes integrated tools for managing MCP servers, skills, and cron jobs within a modern, self-hosted dashboard.

sanchomuzax / hermes-webui

This dashboard focuses on process monitoring and configuration, utilizing WebSockets for real-time status updates on agent activity. It provides full-text search capabilities for inspecting conversation histories and a visual interface for scheduling agentic cron jobs.

Euraika-Labs / pan-ui

A self-hosted workspace that utilizes SSE streaming and tool approval cards to give users fine-grained control over agent actions. It features an integrated marketplace for discovering new skills and MCP servers, alongside isolated profile management for separate API keys.

Felix-Forever / hermes-agent-desktop

A multi-agent desktop client that orchestrates collaboration between 20 specialized AI agents via a PM orchestrator. It includes a visual 'Skill Store' for one-click installations of over 50 curated capabilities, making it a robust environment for complex, multi-expert tasks.
