breakdown

farion1231 / cc-switch

This cross-platform manager supports Windows, macOS, and Linux for handling configurations across multiple agents including Hermes Agent and Claude Code. It allows users to perform one-click switching between different API providers within a single interface.

iOfficeAI / AionUi

AionUi is a local cowork application that enables autonomous multi-step tasks with file access and user approval for agents like Hermes and OpenClaw. It extends accessibility by providing remote access through a WebUI and messaging platforms such as Telegram.

nesquena / hermes-webui

This web interface offers 1:1 feature parity with the Hermes CLI for use on web browsers and mobile devices. It utilizes a three-panel layout for chat, sessions, and workspace browsing, built entirely with Python and vanilla JavaScript.

fathah / hermes-desktop

This desktop companion app facilitates the installation and configuration of Hermes Agent via local backends or remote API connections. It features a streaming chat UI with markdown support and provides management for 14 toolsets, memory systems, and environment profiles.

EKKOLearnAI / hermes-studio

This web dashboard serves as a unified configuration hub for Hermes and other runtimes across ten communication platforms like WhatsApp and Matrix. It includes a visual workflow builder with cron-based scheduling, approval gates, and usage analytics.

outsourc-e / hermes-workspace

This native web workspace features a Swarm Mode with role-based dispatch and tmux-backed workers for agent coordination. The interface integrates a Monaco-based file browser, a PTY terminal, and a dedicated inspector panel for managing skills and MCP catalogs.

xintaofei / codeg

Codeg is a collaborative workspace that aggregates sessions from fifteen built-in agents, including Hermes and Codex, as a desktop or self-hosted application. It supports custom ACP-compatible agent registration and offers native iOS and Android clients for remote connectivity.

dodo-reach / hermes-desktop

Designed as a native Mac workspace, this tool provides direct local or SSH connections to Hermes hosts for system repair and shell access. It includes native views for managing sessions, Kanban boards, skills, and cron jobs through an embedded terminal.

Eynzof / Hermes-CN-Desktop

Built with Tauri, TypeScript, and Rust, this Windows-first desktop application includes a built-in kernel for health checks and updates. The UI supports memory management and LaTeX rendering while providing native window and process management for Hermes Agent.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension connects active browser tabs to local or remote Hermes Agent runtimes using intelligent tab-scoping controls. It features site-aware drafting capabilities in 31 writing environments and supports multi-agent thread synchronization.

uzairansaruzi / hermex

Hermex is a native SwiftUI iPhone app that pairs with a hermes-webui server to drive self-hosted agents from a mobile device. It supports real-time chat streaming with tool-call details, file attachments, and private push notifications via an open-source relay.

freestylefly / wesight

This desktop workspace offers one-click setup for engines like Hermes Agent and Claude Code alongside custom LLM model routing. It provides a runtime dashboard for tracking token usage and latency while monitoring live code writes and diffs.

joeynyc / hermes-hud

This interactive TUI serves as a consciousness monitor for Hermes, featuring nine tabs and four selectable color themes. It provides a tmux operator view for managing live agent panes while tracking agent growth, git projects, and scheduled cron jobs.

xaspx / hermes-control-interface

This self-hosted web dashboard provides a browser-based terminal, file explorer, and a ZOO Swarm Monitor for tracking agent health and kanban pipelines. It features real-time chat with tool call visualization and an MCP server control plane for managing server lifecycles.

jazzyalex / agent-sessions

A native macOS session browser that allows users to search prompts, tool calls, and command outputs across local agent histories. It builds a local search index without telemetry to track per-session token burn and estimated API-equivalent costs.

nickvasilescu / hermes-desktop-os1

This native macOS interface facilitates one-click automated Hermes Agent installation on Orgo cloud VMs and SSH hosts. It integrates a WebRTC voice mode using OpenAI Realtime and Orgo MCP for communication with cloud-based agents.

sharbelxyz / hermes-agent-mission-control

Built with Next.js 16 and React 19, this dashboard template uses a Postgres message bus to bridge local agents with a web interface. It specifically includes an approval inbox for managing agent requests that have side effects.

liftaris / herm

Built with OpenTUI, this alternative interface provides a TUI for chatting and managing Hermes Agent sessions. It supports profile and skill management alongside a kanban board for organizing agentic work and tasks.

clawvader-tech / hermes-telegram-miniapp

This mobile-first React SPA dashboard runs locally as a Telegram Mini App with dual HMAC-SHA256 and Ed25519 authentication. It supports background agent spawning for up to five concurrent instances and includes a terminal chat with file attachment support.

aivrar / portable-hermes-agent

This no-install desktop solution for Windows runs via portable Python and Node.js environments without requiring admin rights or Docker. It features a built-in workflow engine and 100 tools for tasks including TTS, music generation, and ComfyUI image creation.

pyrate-llama / hermes-ui

This glassmorphic web interface provides real-time log streaming and a task tracking dashboard for self-hosted AI assistants. It includes management tools for skills, cron jobs, and MCP servers alongside an integrated file browser.

sanchomuzax / hermes-webui

A monitoring dashboard focused on session activity and cost tracking for Hermes deployments. It allows for full inspection of conversation histories and skill source code, plus read-only monitoring of environment variables.

Euraika-Labs / pan-ui

This self-hosted workspace features real-time SSE streaming and tool approval cards within a chat-first interface. It includes an integrated marketplace for skills and MCP servers, plus isolated profile management for separate sessions and API keys.

Felix-Forever / hermes-agent-desktop

This native desktop client facilitates orchestrated collaboration between 20 specialized AI agents. It features a Visual Skill Store with over 50 one-click installations and supports streaming SSE responses with model switching.
