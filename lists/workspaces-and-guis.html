breakdown

farion1231 / cc-switch

This cross-platform manager, built on the Tauri 2 framework, serves as an all-in-one configuration tool for Windows, macOS, and Linux users. It centralizes the management of Hermes Agent alongside other command-line interfaces like Claude Code and Gemini CLI.

iOfficeAI / AionUi

AionUi is a local cowork application that integrates dozens of external agents, including Hermes Agent, into a single interface. It features 21 built-in professional assistants and enables remote access through a WebUI and various messaging platforms.

nesquena / hermes-webui

Developed with Python and vanilla JavaScript, this web-based interface allows users to access Hermes Agent from browsers or mobile devices. It includes a circular context ring for monitoring token usage and supports secure connectivity via SSH tunnels.

fathah / hermes-desktop

This desktop companion simplifies the initial setup of Hermes Agent through guided installation and provider configuration. It provides a graphical interface for managing chat sessions, tools, and multiple AI providers in one location.

EKKOLearnAI / hermes-studio

Hermes Studio is a web dashboard featuring a visual workflow canvas with approval gates and execution history. It enables unified configuration across 10 messaging platforms, such as Telegram and Discord, while tracking token consumption via local SQLite storage.

outsourc-e / hermes-workspace

This native web workspace features a Swarm Mode with role-based dispatch and tmux-backed workers for complex tasks. It integrates a Monaco-based file browser, a PTY terminal, and a dedicated memory browser to manage agent skills and MCP catalogs.

xintaofei / codeg

Codeg is a collaborative workspace that aggregates sessions from Hermes and other agents into a desktop, server, or Docker-based environment. It supports custom ACP-compatible agent registration and offers native iOS and Android clients for mobile access.

dodo-reach / hermes-desktop

Designed as a native Mac workspace, this tool provides direct local or SSH connections to Hermes hosts with an embedded terminal for shell access. It features specialized native views for managing Kanban boards, skills, and cron jobs.

Eynzof / Hermes-CN-Desktop

Built with Tauri, TypeScript, and Rust, this Windows-first application includes the Hermes-CN-Core kernel for local agent execution. The interface supports LaTeX and Mermaid rendering alongside dedicated modules for MCP tools and memory management.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension connects a local or remote Hermes runtime directly to the active browser context. It includes site-aware drafting tools for 31 writing environments and live browser control governed by explicit approval gates.

uzairansaruzi / hermex

Hermex is a native SwiftUI iPhone app that pairs with a hermes-webui server to drive self-hosted agents from iOS 18+ devices. It allows for real-time chat and server file system browsing without the use of subscriptions or third-party relays.

freestylefly / wesight

This desktop workspace offers one-click setup for Hermes Agent and other engines, featuring a runtime dashboard to track latency and token usage. It provides a live monitoring environment specifically for observing code writes and diffs in real time.

joeynyc / hermes-hud

This terminal-based consciousness monitor provides an interactive TUI with nine tabs and four color themes for tracking agent growth and git projects. It includes a tmux operator view designed specifically for managing live agent panes and scheduled cron jobs.

xaspx / hermes-control-interface

This self-hosted web dashboard features a browser-based terminal, system metrics, and a ZOO Swarm Monitor for tracking agent health via kanban pipelines. It serves as an MCP server control plane that supports real-time chat with streaming and tool call visualization.

jazzyalex / agent-sessions

A native macOS session browser that attributes live quota burn to individual agent sessions while operating locally with no telemetry. It provides searchable transcripts for Hermes and other coding-agent CLIs to serve as a private agent cockpit and analytics tracker.

nickvasilescu / hermes-desktop-os1

This native macOS workspace facilitates one-click automated Hermes Agent installation on Orgo cloud VMs and SSH hosts. It integrates a WebRTC voice mode utilizing OpenAI Realtime and Orgo MCP for remote agent management.

sharbelxyz / hermes-agent-mission-control

Built with Next.js 16 and React 19, this dashboard template uses a Postgres message bus to bridge local agents with a web-based mission control. It features a dedicated approval inbox for managing agent requests that have side effects.

liftaris / herm

Built with OpenTUI, this alternative interface provides a terminal-based environment for chatting and managing Hermes Agent sessions. It includes a kanban board for task management and supports the configuration of profiles, skills, and toolsets.

clawvader-tech / hermes-telegram-miniapp

This mobile-first React SPA dashboard functions as a Telegram Mini App with support for background agent spawning of up to five concurrent instances. It features terminal chat with file attachments and utilizes dual HMAC-SHA256 and Ed25519 authentication.

aivrar / portable-hermes-agent

This portable Windows desktop GUI requires no installation, Docker, or admin rights to connect Hermes to cloud or local models. It includes a dynamic tool maker for API and Python handlers alongside integrated support for ComfyUI and workflows.

pyrate-llama / hermes-ui

This glassmorphic web interface provides real-time log streaming and a file browser for self-hosted AI assistants. It includes a task tracking dashboard and management tools for skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

This monitoring dashboard tracks real-time session activity and costs while allowing full inspection of conversation histories and skill source code. It provides read-only access to configuration settings and environment variables for process oversight.

Euraika-Labs / pan-ui

A self-hosted workspace featuring chat with SSE streaming and tool approval cards for secure execution. It includes an integrated marketplace for skills and MCP servers, plus isolated profile management for separate memory and API keys.

Felix-Forever / hermes-agent-desktop

This desktop client features a PM orchestrator to manage collaboration between 20 specialized AI agents. It includes a Visual Skill Store with over 50 one-click installations and a native interface that supports streaming responses and model switching.
