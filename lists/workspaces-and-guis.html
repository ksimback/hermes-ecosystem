breakdown

farion1231 / cc-switch

A cross-platform manager built with Tauri 2 that provides native performance for Windows, macOS, and Linux. It serves as an all-in-one interface for managing Hermes Agent alongside other CLI tools like Claude Code and Gemini CLI.

iOfficeAI / AionUi

A local open-source cowork app that unifies Hermes Agent and 13+ other CLI agents into a single GUI. It features a built-in engine for web search and MCP integration, with the ability to automatically generate editable Word, Excel, and Morph PPT files.

nesquena / hermes-webui

A zero-build web interface using Python and vanilla JavaScript that offers full feature parity with the Hermes Agent CLI. It utilizes a three-panel layout to organize chat, sessions, and workspace file browsing for use on web or mobile.

fathah / hermes-desktop

A desktop companion app designed to guide the installation and configuration of Hermes Agent environments. It supports multiple AI providers and local OpenAI-compatible endpoints, integrating with 14 specialized toolsets and 16 messaging gateways.

EKKOLearnAI / hermes-web-ui

A web dashboard focused on multi-platform configuration for channels like Telegram, Discord, and WhatsApp. It provides local session management via SQLite and multi-profile control for managing credentials, skills, and memory.

outsourc-e / hermes-workspace

A native web workspace featuring a PTY terminal and Monaco editor for full file browsing. It introduces Swarm Mode with role-based dispatch and tmux-backed workers, alongside an integrated MCP catalog and memory browser.

dodo-reach / hermes-desktop

A native macOS workspace that connects directly via SSH without the need for browser wrappers or daemons. It provides dedicated views for Kanban, cron jobs, and skills, supporting multiple Hermes profiles on universal macOS architecture.

xaspx / hermes-control-interface

A self-hosted web dashboard featuring the ZOO Swarm Monitor with a kanban pipeline and live event feed. It provides a full MCP server control plane with log tailing and a browser-based terminal for agent stack management.

jazzyalex / agent-sessions

A native macOS session browser and agent cockpit that indexes Hermes and other coding agents locally without telemetry. It includes a specialized Limits Widget to predict usage for Claude and Codex.

nickvasilescu / hermes-desktop-os1

A native macOS interface specifically for Hermes Agent instances running on SSH hosts and Orgo cloud computers. It enables one-click automated installation on cloud VMs and integrates WebRTC voice mode via OpenAI Realtime.

Eynzof / hermes-agent-cn-desktop

A Windows-first Chinese desktop application built with Tauri, TypeScript, and Rust. It includes a built-in kernel for installation and health checks, with native support for LaTeX, Mermaid rendering, and MCP tools.

liftaris / herm

An alternative TUI and dashboard built with OpenTUI for managing profiles, memory, and cron jobs. It facilitates agentic workflows through integrated task diagnostics and kanban boards within a rich markdown-supported chat interface.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA designed as a Telegram Mini App v2.0 that runs locally. It allows for terminal chat with streaming responses and the management of background agent spawning and scheduled cron jobs.

aivrar / portable-hermes-agent

A zero-install Windows desktop GUI that requires no Docker or admin rights. It bundles over 100 tools, including ComfyUI and MusicGen, and includes a dynamic tool maker for creating Python handlers and API wrappers.

pyrate-llama / hermes-ui

A self-hosted, glassmorphic web interface delivered as a single-file React 18 HTML application. It integrates a terminal and file browser with real-time monitoring for agent logs, tasks, and cron jobs.

sanchomuzax / hermes-webui

A process monitoring and configuration dashboard that provides a real-time activity feed via WebSockets. It offers FTS5 search for session history and read-only access to environment variables and config.yaml.

Euraika-Labs / pan-ui

A self-hosted AI workspace featuring a chat-first interface with tool approval cards and SSE streaming. It includes an integrated marketplace for installing MCP servers and skills, with isolated profile management for separate API keys and memory.

Felix-Forever / hermes-agent-desktop

A multi-agent desktop client that orchestrates collaboration between 20 specialized AI agents. It features a visual Skill Store with over 50 one-click installations and a PM orchestrator for managing streaming chat responses.
