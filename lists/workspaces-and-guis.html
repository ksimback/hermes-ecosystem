breakdown

farion1231 / cc-switch

Built with the Tauri 2 framework, this cross-platform manager provides a centralized hub for Windows, macOS, and Linux users to handle multiple AI coding agents. It simplifies the workflow by allowing users to switch between and manage Hermes Agent alongside other major CLIs like Claude Code and Gemini.

iOfficeAI / AionUi

AionUi is a local open-source cowork application that offers a unified interface for both built-in and external CLI agents. It stands out for its productivity features, such as automated generation of editable Office files and remote access capabilities via Telegram, Lark, and WeChat.

nesquena / hermes-webui

This zero-build web interface achieves full feature parity with the Hermes CLI using only Python and vanilla JavaScript. It features a functional three-panel layout that includes workspace file browsing and inline previews for a seamless mobile or desktop experience.

fathah / hermes-desktop

Designed as a desktop companion, this app guides users through the installation and configuration of Hermes Agent for both local and remote AI providers. It provides an integrated management suite for handling sessions, profiles, memory, and specific toolsets in one place.

EKKOLearnAI / hermes-web-ui

This comprehensive web dashboard focuses on multi-platform connectivity, supporting eight different channels including Discord, Slack, and WhatsApp. It allows for advanced management of scheduled cron jobs and provides an integrated file browser compatible with Docker, SSH, and Singularity backends.

outsourc-e / hermes-workspace

This native web workspace introduces a 'Swarm Mode' with role-based dispatch and tmux-backed workers for complex agent orchestration. It integrates a full Monaco-based file browser, a PTY terminal, and a dedicated MCP catalog for managing agent skills and memory.

dodo-reach / hermes-desktop

A native Mac workspace that prioritizes direct system access through real SSH connections and embedded terminals. It provides specialized native views for managing Kanban boards, skills, and cron jobs, making it ideal for system repair and direct shell interaction.

xaspx / hermes-control-interface

This self-hosted dashboard features a 'ZOO Swarm Monitor' for tracking agent health and a Kanban pipeline for task visualization. It serves as a full control plane for MCP servers, offering real-time log tailing, configuration editing, and tool call cards within the chat.

jazzyalex / agent-sessions

Focusing on transparency and local-first privacy, this macOS session browser allows for deep transcript inspection without remote telemetry. It includes unique quota tracking features that provide usage predictions for various coding-agent APIs to help manage costs.

Eynzof / hermes-agent-cn-desktop

Built with Tauri, TypeScript, and Rust, this Windows-first desktop application is optimized for the Chinese ecosystem with Feishu integration. It handles the end-to-end lifecycle of the Hermes Agent kernel, including automated installations and updates.

nickvasilescu / hermes-desktop-os1

This macOS workspace is tailored for Orgo cloud computers, offering one-click automated Hermes installation on fresh cloud VMs. It leverages WebRTC for a native voice mode and provides a streamlined interface for managing remote SSH hosts.

liftaris / herm

An alternative TUI and dashboard built with OpenTUI, this project brings a terminal-based aesthetic to agent management. It renders markdown and LaTeX in chat while providing Kanban boards for diagnosing agentic workflows and managing memory profiles.

clawvader-tech / hermes-telegram-miniapp

This React-based Telegram Mini App provides a mobile-first dashboard for monitoring system metrics like CPU and disk usage. It supports background agent spawning and a terminal-style chat interface with slash commands directly within the Telegram ecosystem.

aivrar / portable-hermes-agent

A zero-install Windows solution that requires no admin rights or Docker, making it highly portable. It comes pre-loaded with over 100 tools, including ComfyUI and TTS, and features a dynamic tool maker for creating custom API wrappers.

pyrate-llama / hermes-ui

This glassmorphic web interface offers a modern, self-hosted aesthetic for managing the Hermes stack. It combines real-time log streaming and terminal access with dedicated tools for configuring MCP servers and AI skills in a single-file React application.

sanchomuzax / hermes-webui

This dashboard focuses on process monitoring and analytics, featuring a real-time activity feed with cost tracking and model distribution data. It utilizes FTS5 for searchable conversation histories, allowing for message-level inspection of agent interactions.

Euraika-Labs / pan-ui

Pan-ui is a chat-first workspace that uses real-time SSE streaming and tool approval cards for secure agent interaction. It includes a built-in marketplace for discovering skills and supports isolated profiles to keep API keys and memory separate between sessions.

Felix-Forever / hermes-agent-desktop

This desktop client specializes in multi-agent orchestration, coordinating collaboration between 20 specialized AI agents. It features a 'Visual Skill Store' for one-click installations and a PM orchestrator to manage complex streaming chat workflows.
