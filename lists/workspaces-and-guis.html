breakdown

farion1231 / cc-switch

CC Switch is a cross-platform manager for Hermes Agent and several other agent tools, including Claude Code, Codex, OpenCode, and Gemini CLI. It lets users switch API providers in one click and manage MCP, Skills, and Prompts in one place, with support for Windows, macOS, and Linux.

iOfficeAI / AionUi

AionUi is a local open-source cowork app for Hermes Agent and other agent CLIs, with 21 built-in professional assistants. It also supports remote access through a WebUI and messaging platforms, and runs on macOS, Windows, and Linux.

nesquena / hermes-webui

Hermes WebUI provides web and phone access to Hermes Agent through a three-panel layout for sessions, chat, and workspace files. Its file browser includes inline previews, and the project is designed for access through an SSH tunnel.

fathah / hermes-desktop

Hermes Desktop is a desktop companion for installing, configuring, and chatting with Hermes Agent, using the official Hermes install script. Its GUI manages profiles, sessions, skills, and tools, and the app is available from the project website or GitHub Releases.

EKKOLearnAI / ekko-studio

Ekko Studio is a web dashboard for Hermes Agent with multi-platform AI chat, session management, scheduled jobs, usage analytics, and channel configuration for Telegram, Discord, Slack, and WhatsApp. It stands out with multi-agent and group chat plus visual workflows, and is available as a desktop app, npm CLI, or Docker image.

outsourc-e / hermes-workspace

Hermes Workspace combines chat with a terminal, memory browser, skills manager, MCP catalog, and workspace file browser with Monaco. It also offers Swarm Mode for role-based dispatch with tmux-backed workers.

spacering-net / codeg

Codeg is a collaborative coding workspace that aggregates sessions from Hermes and other agents, including Claude Code, Codex, and OpenCode, as a desktop or self-hosted app. Users can import, search, resume, and hand off sessions, delegate across agents, or queue to-dos in worktrees.

dodo-reach / hermes-desktop

This native Mac workspace connects directly to Hermes hosts locally or over SSH and provides views for sessions, Kanban, skills, and cron jobs. Its embedded terminal offers direct shell access for system repair.

Eynzof / Hermes-CN-Desktop

Hermes-CN-Desktop is a Windows-first desktop app for Hermes Agent that also supports macOS, with native window and process management. It includes a Hermes-CN-Core kernel with health checks and updates, plus UI for chat, memory management, and LaTeX and Markdown rendering.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension connects the active browser context to a local, Hermes Cloud, or self-hosted remote Hermes Agent runtime. Bot Mode supports agent switching and group chats, while Hermes Control is opt-in and Chromium-only.

uzairansaruzi / hermex

Hermex is a native SwiftUI iPhone app for driving a self-hosted Hermes agent by pairing with a hermes-webui server. It supports streaming chats and file or image attachments, and lets users browse, search, and resume sessions and view scheduled tasks, skills, memory, and insights.

freestylefly / wesight

Wesight is a desktop AI agent workspace with one-click setup for Hermes Agent, Claude Code, Codex, and OpenClaw, plus custom LLM model routing. Its runtime dashboard tracks token usage and latency, while a live workspace shows code writes and diffs.

joeynyc / hermes-hud

Hermes HUD is an interactive TUI with nine tabs and four selectable color themes for monitoring agent growth, git projects, and scheduled cron jobs. Its tmux operator view also lets users manage live agent panes.

jazzyalex / agent-sessions

Agent Sessions is a native macOS browser and analytics tool for Hermes agents and other coding-agent CLIs. It searches local histories for prompts, tool calls, errors, and file paths, and displays session metadata and supported token or pricing details without uploading session history.

xaspx / hermes-control-interface

This self-hosted web dashboard brings a browser-based terminal, file explorer, session overview, cron management, system metrics, and agent status panel together in one interface. It also offers streaming chat with tool-call visualization, MCP server lifecycle controls, and a ZOO Swarm Monitor for agent health and kanban pipelines.

nickvasilescu / hermes-desktop-os1

Hermes Desktop OS1 is a native macOS workspace for running Hermes Agent on Orgo cloud VMs and SSH hosts. It offers one-click installation on fresh cloud computers and integrated WebRTC voice mode using OpenAI Realtime and Orgo MCP.

sharbelxyz / hermes-agent-mission-control

Mission Control is a self-hostable dashboard template that connects to a local Hermes agent through a Postgres message bus. Its approval inbox lets users review requests with side effects before they proceed.

liftaris / herm

Herm is an alternative Hermes TUI and dashboard that connects to the Hermes Agent gateway. Its tabs cover profiles, sessions, skills, cron, and memory, while kanban boards, diagnostics, task details, and dispatch controls support agent operations.

clawvader-tech / hermes-telegram-miniapp

This locally run React SPA provides a 10-page, mobile-first dashboard for Telegram Mini App v2.0. It includes streaming terminal chat with file attachments, Telegram authentication validation using HMAC-SHA256 and Ed25519, and background spawning for up to five concurrent agent instances.

aivrar / portable-hermes-agent

Portable Hermes Agent is a desktop version for Windows with a dark-themed, multilingual GUI and session management. It supports local models through LM Studio and includes workflow automation and runtime tool creation.

pyrate-llama / hermes-ui

Hermes UI is a self-hosted web interface with a glassmorphic chat experience and real-time log streaming. Its file browser and task dashboard sit alongside management tools for skills, cron jobs, and MCP servers.

thomasbek3 / hermes-bot-kit

This project adds iMessage-style chat bubbles and a dockable noVNC viewer for remote machines to Hermes Desktop. It includes four Desktop plugins and two agent plugins, with the computer pane supporting remote machines and bot-specific bindings; the Desktop plugins require Hermes Desktop 0.20.5 or later.

sanchomuzax / hermes-webui

Hermes WebUI is a dashboard for monitoring processes and configuring Hermes. It tracks session activity and costs, provides inspection of conversation histories and skill source code, and offers read-only views of configuration and environment variables.

Euraika-Labs / pan-ui

Pan UI is a self-hosted, chat-first workspace with real-time SSE streaming and tool approval cards. It combines an integrated marketplace for skills and MCP servers with isolated profiles for separate sessions, memory, and API keys.

Felix-Forever / hermes-agent-desktop

Hermes Agent Desktop is a native desktop client for multi-agent collaboration, with streaming chat and model switching. It includes an orchestrator for collaboration between 20 specialized AI agents and a visual skill store with more than 50 curated one-click installations.

nicolasestrem / hermes-model-switcher

This plugin presents configured model routes across profiles in one matrix, making cross-profile switching available from the Hermes Agent Web Dashboard. It previews changes before applying them and includes named presets and a guarded Undo.

robbyczgw-cla / hermes-ui-plus

This unofficial, open-source chat client for self-hosted Hermes Agent supports interactive answers such as checklists, choices, forms, rankings, and votes. It also provides command approvals and live tool-step updates, and runs on Android, web, macOS, and Linux alpha.

silent-reader-cn / hermes-anywhere

Hermes Anywhere is a Flutter client for Hermes Agent that shares the same interface and sessions across Windows and Android. Its streaming chat displays reasoning and tool calls in cards, while the Windows installer bundles a WebUI backend and Python runtime.
