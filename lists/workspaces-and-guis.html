breakdown

farion1231 / cc-switch

A cross-platform manager built with Tauri 2 that supports Windows, macOS, and Linux. It functions as an all-in-one tool for managing multiple agentic tools including Hermes Agent, Claude Code, and Gemini CLI.

iOfficeAI / AionUi

A local open-source cowork application that supports remote access via WebUI and messaging platforms. It enables 24/7 task automation through scheduled cron jobs and generates editable PPT, Word, and Excel files via OfficeCLI.

nesquena / hermes-webui

A Python and vanilla JS-based interface designed for accessing Hermes Agent via a browser or SSH tunnel. The tool provides workspace file browsing with inline preview capabilities.

fathah / hermes-desktop

A desktop companion app that provides a GUI for chat, sessions, and tools. It features guided installation and provider setup for multiple AI providers.

EKKOLearnAI / hermes-studio

A web dashboard that offers multi-platform AI chat, session management, and usage analytics. It includes visual workflow building, Kanban boards, and channel configuration for 10 platforms including Telegram, Discord, Slack, and WhatsApp.

outsourc-e / hermes-workspace

A native web workspace featuring a chat interface, terminal, memory browser, skills manager, and inspector panel. It utilizes tmux-backed workers for Swarm Mode with role-based dispatch and includes an MCP catalog.

xintaofei / codeg

A collaborative multi-agent coding workspace available as a desktop app, standalone server, or Docker container. It aggregates sessions from Hermes and other agents and includes native iOS and Android clients.

dodo-reach / hermes-desktop

A native Mac workspace that connects to Hermes hosts via local or SSH connections. It provides native views for sessions, Kanban, skills, and cron jobs, alongside an embedded terminal for shell access and system repair.

Eynzof / Hermes-CN-Desktop

A Windows-first desktop app built with Tauri, TypeScript, and Rust that also supports macOS. It includes a built-in Hermes-CN-Core kernel for local execution and features UI for MCP tools, memory management, and LaTeX/Mermaid rendering.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension that connects active browser context to local, cloud, or remote Hermes Agent gateways. It features Hermes Assist for site-aware drafting and Hermes Web Alpha for session and runtime management.

uzairansaruzi / hermex

A native SwiftUI app for iOS 18+ that pairs with a hermes-webui server to drive a self-hosted Hermes agent. It manages agent sessions, tasks, and skills while providing read-only access to memory and analytics.

freestylefly / wesight

A desktop AI agent workspace that includes a runtime dashboard for tracking token usage and latency. It provides a live workspace for monitoring code writes and diffs while supporting custom LLM model routing.

xaspx / hermes-control-interface

A self-hosted web dashboard providing a browser-based terminal, file explorer, and agent status panel. It features real-time chat with tool call visualization and a ZOO Swarm Monitor for tracking agent health and kanban pipelines.

jazzyalex / agent-sessions

A native macOS session browser and agent cockpit that supports Hermes and various other coding-agent CLIs. It provides searchable history with transcript inspection and live per-session quota burn-rate tracking for Codex and Claude.

nickvasilescu / hermes-desktop-os1

A native macOS workspace designed for Hermes Agent running on SSH hosts and Orgo cloud computers. It includes one-click automated installation on fresh cloud computers and integrated WebRTC voice mode.

sharbelxyz / hermes-agent-mission-control

A self-hostable dashboard template that connects to local agents via a Postgres message bus. The interface features an approval inbox for requests involving side effects.

liftaris / herm

An alternative Hermes TUI and dashboard built with OpenTUI for chatting and managing agent sessions. It includes a kanban board for task management and tools for managing profiles, skills, and cron jobs.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA dashboard designed for Telegram Mini App v2.0. It supports terminal chat with streaming responses and background agent spawning for up to five concurrent instances.

aivrar / portable-hermes-agent

A portable Windows desktop application that requires no installation, Docker, or admin rights. It supports cloud and local AI model connections and includes a dynamic tool maker for Python and API handlers.

pyrate-llama / hermes-ui

A glassmorphic web interface for self-hosted Hermes Agent that provides real-time log streaming and chat. It integrates a file browser and a dashboard for tracking tasks, skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

A process monitoring and configuration dashboard for Hermes. It offers real-time session activity and cost tracking, alongside read-only inspection of environment variables and skill source code.

Euraika-Labs / pan-ui

A self-hosted AI workspace featuring a chat-first interface with real-time SSE streaming and tool approval cards. It includes an integrated marketplace for discovering skills and MCP servers, alongside isolated profile management.

Felix-Forever / hermes-agent-desktop

A native desktop client designed for orchestrated collaboration between 20 specialized AI agents. It features a visual Skill Store with over 50 curated installations and streaming SSE responses.
