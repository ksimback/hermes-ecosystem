breakdown

farion1231 / cc-switch

A cross-platform manager built with the Tauri 2 framework that supports Windows, macOS, and Linux. It manages configurations for Hermes Agent alongside Claude Code, Codex, OpenCode, OpenClaw, and Gemini CLI.

iOfficeAI / AionUi

A local open-source cowork application that integrates Hermes Agent and other agent CLIs. It supports remote access via WebUI and messaging platforms like Telegram, and includes assistants for generating editable PPT, Word, and Excel files.

nesquena / hermes-webui

A web-based interface that runs the Hermes agent in-process using existing configurations and models. It features a three-panel layout with an integrated workspace file browser and is accessible via browser or mobile through secure SSH tunneling.

fathah / hermes-desktop

A desktop companion app designed for installing, configuring, and chatting with Hermes Agent. It provides a GUI for chat, sessions, and tools, and supports multiple AI providers.

EKKOLearnAI / hermes-studio

A web dashboard that provides multi-platform AI chat, session management, and usage analytics. It features streaming responses, tool traces, visual workflow building, Kanban boards, and channel configuration for 10 platforms including Telegram, Discord, Slack, and WhatsApp.

outsourc-e / hermes-workspace

A native web workspace featuring a chat interface, terminal, memory browser, skills manager, and inspector panel. It includes a full workspace file browser with Monaco and PTY terminal, and supports Swarm Mode with role-based dispatch and tmux-backed workers.

xintaofei / codeg

A collaborative multi-agent coding workspace that aggregates sessions from Hermes, Claude Code, Codex, and OpenCode as a desktop or self-hosted app. It allows users to delegate tasks to sub-agents using @ mentions and can run unattended tasks on separate git branches.

dodo-reach / hermes-desktop

A native Mac workspace that connects to Hermes hosts via direct local or SSH connections. It provides native views for sessions, Kanban, skills, and cron jobs, along with an embedded terminal for shell access and system repair.

Eynzof / Hermes-CN-Desktop

A Windows-first desktop app built with Tauri, TypeScript, and Rust that also supports macOS. It includes a built-in Hermes-CN-Core kernel for local execution and features a UI for MCP tools, memory management, and LaTeX/Mermaid rendering.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension that connects active browser context to a local, Hermes Cloud, or remote API Hermes Agent runtime. It includes Hermes Web for full-page session management and site-aware drafting via Hermes Assist.

uzairansaruzi / hermex

A native SwiftUI app for iOS 18+ that allows users to drive a self-hosted Hermes agent from an iPhone. It pairs with a hermes-webui server to manage agent sessions, tasks, and skills, while providing read-only access to memory and analytics.

freestylefly / wesight

A desktop AI agent workspace that supports Hermes Agent, Claude Code, Codex, and OpenClaw engines. It includes a runtime dashboard for tracking latency and token usage, alongside a live workspace for monitoring code writes and diffs.

xaspx / hermes-control-interface

A self-hosted web dashboard providing a browser-based terminal, file explorer, and system metrics. It includes a ZOO Swarm Monitor for tracking agent health and an MCP server control plane for managing server lifecycles.

jazzyalex / agent-sessions

A native macOS session browser and agent cockpit that supports 13 agent sources, including Hermes. It features image browsing, analytics, and one-click resume functionality for supported CLIs.

nickvasilescu / hermes-desktop-os1

A native macOS workspace designed for Hermes Agent running on SSH hosts and Orgo cloud computers. It offers one-click automated installation on fresh cloud computers and integrated WebRTC voice mode.

sharbelxyz / hermes-agent-mission-control

A self-hostable dashboard template that connects to local agents via a Postgres message bus. It features an approval inbox for requests involving side effects.

liftaris / herm

A TUI and dashboard built with OpenTUI for chatting and managing Hermes Agent sessions. It includes a kanban board for task management alongside tools for managing profiles, skills, and cron jobs.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA designed for Telegram Mini App v2.0 that runs locally. It supports terminal chat with streaming responses and background agent spawning for up to five concurrent instances.

aivrar / portable-hermes-agent

A portable Windows desktop application that requires no installation, Docker, or admin rights. It supports cloud and local AI model connections and includes a dynamic tool maker for Python and API handlers.

pyrate-llama / hermes-ui

A glassmorphic web interface for self-hosted AI assistance. It provides real-time log streaming, a file browser, and management tools for MCP servers, skills, and cron jobs.

sanchomuzax / hermes-webui

A process monitoring and configuration dashboard for Hermes. It allows for real-time tracking of session activity and costs, as well as read-only inspection of environment variables and skill source code.

Euraika-Labs / pan-ui

A self-hosted AI workspace featuring a chat-first interface with real-time SSE streaming. It includes a marketplace for discovering skills and MCP servers, alongside isolated profile management for memory and API keys.

Felix-Forever / hermes-agent-desktop

A native desktop client for orchestrating collaboration between 20 specialized AI agents. It features a visual Skill Store with over 50 curated installations and streaming SSE responses.
