breakdown

farion1231 / cc-switch

A cross-platform manager built with Tauri 2 that supports Windows, macOS, and Linux. It provides a unified interface for managing multiple agentic tools, including Hermes Agent, Claude Code, and Gemini CLI.

iOfficeAI / AionUi

A local open-source cowork application that supports various agent CLIs like Hermes Agent and OpenClaw. It features built-in assistants for Word, Excel, and PPT, and offers remote access via WebUI and messaging platforms like Telegram and WeChat.

nesquena / hermes-webui

A Python and vanilla JavaScript web interface designed to provide full parity with the Hermes CLI experience. The layout features three panels, including a chat interface and a workspace file browser, accessible via web or mobile.

fathah / hermes-desktop

A desktop companion app designed for installing and configuring Hermes Agent. It provides a GUI for managing sessions, tools, and multiple AI providers.

EKKOLearnAI / hermes-studio

A web dashboard available via desktop, npm CLI, or Docker that manages multi-platform AI chat and scheduled jobs. It includes visual workflow building, Kanban task tracking, and configuration for 10 platform channels including Discord and Slack.

outsourc-e / hermes-workspace

A native web workspace featuring an integrated terminal, memory browser, skills manager, and inspector panel. It supports Swarm Mode with role-based dispatch and tmux-backed workers.

xintaofei / codeg

A collaborative multi-agent coding workspace that aggregates sessions from Hermes, Claude Code, and Codex. It is available as a desktop app, standalone server, or Docker deployment and includes native iOS and Android clients.

dodo-reach / hermes-desktop

A native Mac workspace that connects to Hermes hosts via local or SSH connections. It provides native views for sessions, Kanban, skills, and cron jobs, alongside an embedded terminal for shell access.

Eynzof / Hermes-CN-Desktop

A Windows-first desktop application built with Tauri, Rust, and TypeScript. It supports Windows and macOS and includes a built-in Hermes-CN-Core runtime.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension for Chrome, Edge, and Chromium that connects active browser contexts to a local, cloud, or remote Hermes Agent runtime. It includes Hermes Web for full-page workspace sessions.

uzairansaruzi / hermex

A native SwiftUI app for iOS 18+ that pairs with a hermes-webui server to drive a self-hosted Hermes agent. It supports real-time streaming chat, file attachments, and management of agent tasks and skills.

freestylefly / wesight

A desktop AI agent workspace that supports Hermes Agent, Claude Code, Codex, and OpenClaw. It includes a runtime dashboard for tracking latency and token usage, plus a live workspace for monitoring diffs and code writes.

xaspx / hermes-control-interface

A self-hosted web dashboard that provides a browser-based terminal, file explorer, and system metrics. It features real-time chat with tool call visualization and a ZOO Swarm Monitor for tracking agent health and kanban pipelines.

jazzyalex / agent-sessions

A native macOS session browser and agent cockpit designed for Hermes and other coding-agent CLIs. It offers live per-session quota burn-rate tracking and operates locally with no telemetry or remote logging.

nickvasilescu / hermes-desktop-os1

A native macOS workspace for Hermes Agent running on SSH hosts or Orgo cloud computers. It includes one-click automated installation on fresh cloud computers and integrated WebRTC voice mode.

liftaris / herm

An alternative TUI and dashboard built with OpenTUI for chatting and managing Hermes Agent sessions. It includes a kanban board for task management and supports managing profiles, skills, cron jobs, and toolsets.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA dashboard for Telegram Mini App v2.0 that runs locally. It supports terminal chat with streaming responses, file attachments, and background agent spawning for up to five concurrent instances.

aivrar / portable-hermes-agent

A portable Windows desktop version of Hermes Agent that requires no installation, Docker, or admin rights. It supports cloud and local AI model connections and includes a dynamic tool maker for Python and API handlers.

pyrate-llama / hermes-ui

A glassmorphic web interface for self-hosted Hermes Agent chat and real-time log streaming. The dashboard integrates a file browser and task tracking alongside management tools for skills, cron jobs, and MCP servers.

sharbelxyz / hermes-agent-mission-control

A self-hostable dashboard template that connects to local agents via a Postgres message bus. It features an approval inbox for requests involving side effects.

sanchomuzax / hermes-webui

A process monitoring and configuration dashboard for Hermes. It provides real-time session activity and cost tracking, as well as read-only monitoring of environment variables and skill source code.

Euraika-Labs / pan-ui

A self-hosted AI workspace featuring chat with real-time SSE streaming and tool approval cards. It includes an integrated marketplace for discovering skills and MCP servers, plus isolated profile management for API keys and memory.

Felix-Forever / hermes-agent-desktop

A native desktop client designed for orchestrated collaboration between 20 specialized AI agents. It features a visual Skill Store with over 50 curated installations and streaming SSE responses.
