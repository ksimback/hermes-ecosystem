breakdown

farion1231 / cc-switch

A cross-platform manager built with the Tauri 2 framework that supports Windows, macOS, and Linux. It provides centralized configuration management for Hermes Agent alongside Claude Code, Codex, OpenCode, OpenClaw, and Gemini CLI.

iOfficeAI / AionUi

This local open-source cowork application integrates dozens of external agents, including Hermes Agent, into a single interface. It features 21 built-in professional assistants and enables remote access through a WebUI and various messaging platforms.

nesquena / hermes-webui

A web-based interface built using Python and vanilla JavaScript that allows users to access Hermes Agent from a browser or phone. The interface includes a circular context ring to monitor token usage and supports secure access via SSH tunnels.

fathah / hermes-desktop

A desktop companion app designed to assist with the installation and configuration of Hermes Agent and its providers. It offers a graphical user interface for managing chats, sessions, and tools.

EKKOLearnAI / hermes-studio

A web dashboard providing multi-platform AI chat, session management, and usage analytics for Hermes Agent. It features a visual workflow canvas with approval gates and supports unified configuration for 10 messaging platforms, including Telegram and Discord.

outsourc-e / hermes-workspace

This native web workspace includes a terminal, memory browser, skills manager, and inspector panel. It utilizes Swarm Mode with role-based dispatch and tmux-backed workers, alongside a full workspace file browser with Monaco.

xintaofei / codeg

A collaborative multi-agent coding workspace that aggregates sessions from Hermes Agent and other tools into a desktop or self-hosted application. It supports custom ACP-compatible agent registration and provides native iOS and Android clients for remote access.

dodo-reach / hermes-desktop

A native Mac workspace that connects directly to Hermes hosts via local or SSH connections. It provides native views for sessions, Kanban, skills, and cron jobs, complemented by an embedded terminal for shell access and system repair.

Eynzof / Hermes-CN-Desktop

A Windows-first desktop application built with Tauri, TypeScript, and Rust that also supports macOS. It includes a built-in Hermes-CN-Core kernel for local execution and features a UI for MCP tools, memory management, and LaTeX/Mermaid rendering.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension for Chrome, Edge, and Chromium browsers that connects active browser context to a Hermes Agent runtime. It includes Hermes Assist for site-aware drafting in 31 writing environments and features live browser control with explicit approval gates.

uzairansaruzi / hermex

A native SwiftUI iPhone app for iOS 18+ that drives a self-hosted Hermes agent by pairing with a hermes-webui server. The app supports real-time chat, task management, and server file system browsing without subscriptions or third-party relays.

freestylefly / wesight

A desktop AI agent workspace featuring one-click setup for Hermes Agent, Claude Code, Codex, and OpenClaw. It includes a runtime dashboard for tracking latency and token usage, as well as a live workspace for monitoring code writes and diffs.

joeynyc / hermes-hud

This terminal-based consciousness monitor features an interactive TUI with nine tabs and four selectable color themes. It enables users to track agent growth and scheduled cron jobs while providing a tmux operator view for managing live agent panes.

xaspx / hermes-control-interface

This self-hosted web dashboard provides a centralized control plane for managing MCP server lifecycles and ZOO Swarm agent health. It features a browser-based terminal, real-time chat with tool call visualization, and a kanban pipeline for tracking agent tasks.

jazzyalex / agent-sessions

Operating locally on macOS 14+, this native session browser tracks live quota burn across 15 agent sources by model, tokens, or cost. It offers searchable transcripts and image browsing with a strict focus on privacy, requiring no telemetry or data uploads.

nickvasilescu / hermes-desktop-os1

This native macOS workspace facilitates one-click automated Hermes Agent installations on Orgo cloud VMs and SSH hosts. It integrates a WebRTC voice mode using OpenAI Realtime and Orgo MCP to enable vocal interaction with cloud-hosted agents.

sharbelxyz / hermes-agent-mission-control

Built with Next.js 16 and Tailwind CSS v4, this dashboard template uses a Postgres message bus to bridge local agents with a web-based interface. It includes a dedicated approval inbox for managing agent requests that have side effects.

liftaris / herm

This OpenTUI-based dashboard provides a terminal interface for chatting with agents and managing their sessions. It includes a kanban board for task management and tools for configuring agent profiles, skills, and cron jobs.

clawvader-tech / hermes-telegram-miniapp

This mobile-first React SPA serves as a Telegram Mini App dashboard capable of spawning five concurrent background agent instances. It supports terminal chat with file attachments and uses HMAC-SHA256 and Ed25519 for secure Telegram authentication.

aivrar / portable-hermes-agent

This portable Windows desktop GUI requires no installation, Docker, or admin rights to run Hermes Agent with local or cloud models. It features a dynamic tool maker for API and Python handlers alongside integrated support for TTS and ComfyUI workflows.

pyrate-llama / hermes-ui

This glassmorphic web interface provides real-time log streaming and a task tracking dashboard for self-hosted AI assistants. It includes an integrated file browser and management tools for skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

This monitoring dashboard provides real-time tracking of session activity, costs, and conversation histories. It offers read-only inspection of environment variables and configuration settings to ensure oversight of the agent's state.

Euraika-Labs / pan-ui

This chat-first workspace features real-time SSE streaming and tool approval cards for secure agent interactions. It includes an integrated marketplace for discovering skills and MCP servers, alongside isolated profile management for separate API keys and memory.

Felix-Forever / hermes-agent-desktop

This native desktop client orchestrates collaboration between 20 specialized AI agents through a PM orchestrator. It features a Visual Skill Store with over 50 one-click installations and supports streaming SSE responses with on-the-fly model switching.
