Hermes Agent plugins

The official Hermes plugin catalog lists 2,381 plugins (as of 2026-11-16). This page is the short list of the ones worth running, grouped by the job they do — 28 picks across 9 use cases, each with a verdict and the caveats worth knowing first.

We only pick catalog entries: each one has been reviewed and is pinned to a commit, so hermes plugins install <name> gets you what was reviewed rather than whatever is on a branch today. The tier badge (Official, Verified, Community) says who publishes a plugin — it is provenance, not a security audit.

New to plugins? The plugins guide covers what plugins are, why yours won't load, and how to stay safe. Looking for skills? The Skills Hub →

Checked against the official catalog on 2026-11-16. Picks install-tested against Hermes v0.23.1. Tested 2026-11-17 on Windows 11: each pick installs from the catalog into a clean Hermes home and loads (hermes plugins doctor: import and register), with no API keys set. Not tested: Bubblewrap (Linux only) and Fish Audio (Linux and macOS only), which refuse to install on Windows; Accent Picker is a Desktop add-on, which doctor does not check.

See what your agent does and spends

Traces, metrics and budget limits for people running Hermes every day or on cron.

The first plugin most serious setups add. Pick one tracing plugin for your existing stack, and add a budget guard if anything runs unattended.

top pick

Langfuse

Officialgeneral

The default tracing pick: one trace per turn, one generation per LLM call with cost, one observation per tool call and subagent. Content capture is sanitized by default. It used to be built into core.

install
hermes plugins install langfuse

Requires Hermes >=0.21.7

github: NousResearch/hermes-official-plugins → atlas project page →

Hermes OTel

Communitygeneral

Choose this over Langfuse if you already run an OpenTelemetry backend. It declares more lifecycle hooks (34) than any other entry in the official catalog, including approvals, Kanban and subagents.

caveatIt can send prompts, tool arguments and tool output to the backends you configure, so point it only at a backend you control.

install
hermes plugins install hermes_otel

Requires Hermes >=0.21

github: briancaffey/hermes-otel → atlas project page →

Hermes Telemetry

Communitygeneral

The budget guard. It tracks tokens, cost and latency per session and cron job in local SQLite, and /budget can stop runaway spend before the bill arrives.

caveatEnforce mode is the default: first load writes a $5/day and $100/month budget, and a hard breach blocks every tool call. Set your own limits right after installing.

install
hermes plugins install hermes-telemetry
github: nujovich/hermes-telemetry → atlas project page →

tokenjuice

Communitytools

Compacts successful terminal output locally before the model sees it. That's a cheap win for coding-heavy sessions where build logs eat your context.

caveatNeeds the separate tokenjuice CLI installed with npm, outside the pinned commit.

install
hermes plugins install tokenjuice

Requires Hermes >=0.22.5

github: vincentkoc/tokenjuice →
Sandbox the terminal and guard tool calls

Contain what the agent can touch, put policy in front of tool calls, and scan your own code.

Hermes runs commands as your user by default. These plugins move execution into a sandbox, add a policy layer in front of tool calls, or turn the agent into a security reviewer.

top pick

Bubblewrap sandbox

Officialtools

The most important safety plugin on Linux. Every terminal and execute_code command runs in its own bwrap sandbox with a read-only root, hidden credential stores and per-command limits. Turn it on with terminal.backend: bubblewrap.

caveatLinux only.

install
hermes plugins install bubblewrap

Requires Hermes >=0.22.6

github: NousResearch/hermes-official-plugins → atlas project page →

Cua Spaces

Verifiedtools

Runs the agent's terminal, file and code tools inside an isolated Linux, macOS or Windows machine you can watch live. From 0.22.3 the browser and computer use follow it in. This is the pick on macOS and Windows, where Bubblewrap doesn't run.

caveatEverything the agent runs goes to the Space, which is on Cua's cloud unless you run one locally.

install
hermes plugins install cua-spaces

Requires Hermes >=0.21.6

github: trycua/hermes-cua-spaces →

Tracekit

Communitytools

A policy layer in front of every tool call: deny blocks it, ask waits for a person. Each call and its outcome is signed into a run you can verify offline. Built for setups that need an audit trail.

caveatIt starts a background signer process that keeps running for 15 minutes after Hermes exits.

install
hermes plugins install tracekit

Requires Hermes >=0.22.5

github: cygnux-labs/tracekit →

Security review

Officialtools

Turns Hermes into a security reviewer for your own repository. It builds a threat model, reviews the code with parallel subagents and checks whether an attacker can actually reach each finding. Exports to SARIF.

install
hermes plugins install hermes-security

Requires Hermes >=0.21.5

github: NousResearch/hermes-official-plugins → atlas project page →

Snyk

Officialtools

Snyk's own MCP server, pinned, with a scan workflow skill. It covers code, dependencies, containers, IaC and SBOMs. It pairs with Security review: Snyk finds known-vulnerable dependencies, the review finds logic bugs.

caveatNeeds Node.js and a free Snyk account.

install
hermes plugins install snyk
github: NousResearch/hermes-official-plugins → atlas project page →
Better web search and browsing

Search, extraction and browser backends that beat the defaults.

Web access is where most agents fail quietly. Choose one search provider, and add a browser backend only if you need logins or bot-resistant browsing.

top pick

Tavily

Verifiedweb

The safe default for search: published by Tavily itself, with search, extract, map, crawl and research through its hosted MCP server, plus Tavily's skills.

caveatNeeds TAVILY_API_KEY or a Hermes-managed Tavily sign-in.

install
hermes plugins install tavily-plugin

Requires Hermes >=0.22.2

github: tavily-ai/tavily-hermes-plugin →

TinyFish

Verifiedweb

Free search and fetch that replace Hermes's own web_search and web_extract, with a remote browser agent for sites that need clicks, forms or a login.

caveatBrowser sessions spend TinyFish credits. Each one asks for approval by default, and unattended runs are denied unless you allow them.

install
hermes plugins install tinyfish

Requires Hermes >=0.19

github: tinyfish-io/tinyfish-web-agent-integrations →

Web Search Plus

Communityweb

The community pick if you don't want to depend on one vendor. It routes across several search providers, including self-hosted SearXNG, with quality reports and an opt-in research mode.

install
hermes plugins install web-search-plus
github: robbyczgw-cla/hermes-web-search-plus → atlas project page →

Camofox

Officialweb

A self-hosted anti-detection Firefox as the browser backend, for sites that block ordinary automated browsers. It moved out of core in v0.23.0, and existing users get it automatically.

caveatYou run the Camofox server yourself.

install
hermes plugins install camofox

Talk to Hermes

Realtime voice, spoken replies and dictation.

Voice plugins become Hermes's speech and transcription providers, so they work across the CLI, messaging and Desktop.

top pick

Hermes Talk

Communityvoice

Realtime voice across the terminal, Discord, the dashboard and Desktop. It's the most complete voice plugin and is actively maintained.

caveatIts GPT-Live subscription mode uses an undocumented ChatGPT endpoint that may stop working without notice. Use the API-key modes for anything you depend on.

install
hermes plugins install hermes-talk

Requires Hermes >=0.21.7

github: TheSmokeDev/hermes-talk → atlas project page →

Fish Audio

Communityvoice

Fish Audio's plugin for expressive speech: 80+ languages, voice design from a sentence, voice cloning and live word-by-word dictation, with a Voices page in Desktop.

caveatLinux and macOS only; the installer refuses Windows. Four known issues are listed in the catalog, including Desktop sometimes leaving part of a reply unspoken (which affects every speech provider).

install
hermes plugins install fish-audio

Requires Hermes >=0.21.5

github: 100yenadmin/fish-audio-hermes → atlas project page →

The best smart-home plugin. State changes come into Hermes as events, notifications go out, and four tools let the agent read and control entities. It used to be built into core.

Run Hermes on a subscription you already pay for

Model-provider plugins that use an existing subscription instead of per-token API billing.

Both picks trade some stability for cost. Read the caveat before you rely on either one for unattended work.

Claude subscription

Officialmodels

Runs Hermes turns on a Claude Pro or Max subscription through the official Claude Code CLI, so there's no API key and no per-token bill.

Make Hermes Desktop yours

Desktop plugins: themes, panes and remote connections for the native app.

Desktop plugins are a separate format that only the app loads. They change the app, not the agent, so they are the lowest-risk plugins to try.

top pick

CommunityDesktop plugin

Eighteen warm, readable palettes assigned per profile, so each bot looks different, with matching terminal colours. A theme-only plugin with no tools, no hooks and no network calls.

Requires Hermes >=0.21.3

github: mykeura/minimalist-themes-for-hermes →

Blender Lab's official MCP server with a workflow skill that opens Blender when a task needs it. This is how to model, light and render from chat.

Smarter subagents

Route subagents to different models or profiles, or give the agent a fixed team.

Built-in delegation gives every subagent the parent's model and tools. These plugins make delegation deliberate.

top pick

Advanced Delegation

Officialtools

Two delegation modes worth having. Model routes let the agent pick fast, deep or local per subagent. Profile routes run a subagent as one of your Hermes profiles, with its own model, credentials and skills.

install
hermes plugins install advanced-delegation

Requires Hermes >=0.22.5

github: NousResearch/hermes-official-plugins → atlas project page →

Hermes Teammates

Communityautomation

Define a fixed team once (instructions, toolsets and model per specialist), and the agent picks one by name. Tool limits are actually enforced: a reviewer limited to todo gets no web, file or terminal tools. Uses only public plugin APIs.

install
hermes plugins install hermes-teammates

Requires Hermes >=0.21.4

github: 100yenadmin/hermes-teammates → atlas project page →
memory providers

Memory providers are deliberately not listed here: picking one is a bigger decision than adding a plugin, and it has its own guide. See the Hermes memory guide and the best memory providers list.

what we skip
  • Plugins that sign in with another app's client identity or call undocumented endpoints. They can break, or put your account at risk, without warning.
  • Repos that call themselves plugins but are really MCP servers. Add those under mcp_servers instead: they're portable, and you don't need a plugin.
  • Uncataloged plugins installed from a branch tip, when a catalog entry pinned to a reviewed commit exists for the same job.
