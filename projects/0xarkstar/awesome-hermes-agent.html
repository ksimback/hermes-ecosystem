Awesome Hermes Agent

A curated list of awesome resources for Hermes Agent, the self-improving AI agent by Nous Research.

Hermes Agent is an open-source, self-improving AI agent with persistent memory, autonomous skill creation, and multiple deployment backends. Get started by exploring deployment options, adding skills, and joining the community.

Official Resources

  • agentskills.io - Official cross-platform skill registry and marketplace for agent capabilities.
  • Discord - Official community Discord server for support and discussion.
  • Documentation - Official guides covering installation, configuration, skills, and deployment.
  • Hermes Agent - Open-source self-improving AI agent with persistent memory and autonomous skill creation.
  • Nous Portal - Cloud-hosted Hermes Agent instances with managed infrastructure.
  • Nous Research - Parent organization building open-source AI models and tools.
  • Product Page - Official product page with feature overview and getting started information.

Models

  • Hermes 4 14B - Compact model balancing capability with resource efficiency for local deployment.
  • Hermes 4 405B - Flagship model with maximum capability for complex agent tasks.
  • Hermes 4 70B - Mid-range model offering strong reasoning with manageable resource requirements.
  • Hermes 4 Technical Report - Research paper detailing Hermes 4 architecture, training methodology, and benchmarks.

Deployment

  • evey-setup - One-command setup script for a full Hermes Agent development stack.
  • hermes-agent-docker - Minimal Docker sandbox environment for isolated Hermes Agent instances.
  • nix-hermes-agent - Nix package and NixOS module for reproducible Hermes Agent installations.
  • portainer-stack-hermes - Docker Compose stack with Portainer management UI and ttyd web terminal.

Skills and Plugins

  • Anthropic-Cybersecurity-Skills - Over 700 cybersecurity skills mapped to the MITRE ATT&CK framework.
  • black-forest-labs/skills - Official FLUX image generation skills for agent-driven visual content creation.
  • chainlink-agent-skills - Official Chainlink integration skills for blockchain oracle interactions.
  • evey-bridge-plugin - Plugin bridging Claude Code and Hermes Agent for cross-tool workflows.
  • execplan-skill - Complex task execution skill with checkpoints and failure recovery.
  • hermes-plugins - Collection of plugins for goal management, model selection, and cost control.
  • hermes-weather-plugin - Professional-grade weather data plugin using NWS and NEXRAD radar sources.
  • litprog-skill - Literate programming skill for generating well-documented executable code.
  • pydantic-ai-skills - Pydantic AI integration with agentskills.io skill validation and discovery.
  • Skills Guide - Official documentation for creating, publishing, and discovering skills.
  • wondelai/skills - Cross-platform agent skills collection compatible with multiple agent frameworks.

Tools and Utilities

  • hermes-workspace - Web-based workspace combining chat interface, terminal, and skills manager.
  • lintlang - Static analysis linter for AI agent configuration files and skill definitions.
  • mission-control - Agent orchestration dashboard for monitoring and managing multiple Hermes instances.
  • openclaw-to-hermes - Migration tool for converting OpenClaw configurations to Hermes Agent format.
  • portable-hermes-agent - Windows desktop application for running Hermes Agent without terminal setup.

Integrations

  • hermes-agent-acp-skill - Multi-agent delegation skill enabling task handoff across Hermes, Codex, and Claude Code.
  • hermes-android - Android device bridge for controlling mobile devices through Hermes Agent.
  • hermes-cloudflare - Cloudflare browser rendering plugin for headless web interactions.
  • hermes-miniverse - Bridge connecting Hermes Agent to Miniverse interactive pixel worlds.

Memory and Personality

  • Honcho - User context management layer for building personalized agent experiences.
  • Memory Guide - Official guide for configuring persistent memory and conversation context.
  • Personality Guide - Official guide for customizing agent personality through SOUL.md and persona files.

Training and Research

  • Atropos - Reinforcement learning environments framework for training LLM agent trajectories.
  • hermes-agent-self-evolution - Evolutionary self-improvement pipeline using DSPy and GEPA.
  • Open-Reasoning-Tasks - Curated reasoning benchmark suite for evaluating agent capabilities.
  • Pokemon Agent - Autonomous Pokemon gameplay agent demonstrating planning and real-time decision making.
  • tinker-atropos - Standalone Atropos integration with Tinker API for reinforcement learning training runs.

Showcase Projects

  • Autonovel - Autonomous novel writing pipeline showcasing long-form creative generation.
  • gladiator - Autonomous AI companies competing in simulated business environments.
  • hermes-agent-camel - Hermes Agent fork with CaMeL trust boundaries for safer autonomous operation.
  • hermes-incident-commander - Autonomous SRE agent for infrastructure incident detection and self-healing.
  • hermescraft - Minecraft AI companion agent demonstrating embodied gameplay interaction.
