overview

Perseus is a context and memory platform for AI agents that resolves workspace state into rendered briefing files before model execution. It consists of a context engine for live workspace facts, a vault for durable memory across sessions, and a ledger for recording reviewable events.

  • Resolves live workspace state into rendered context files.
  • Provides local-first memory persistence and session history tracking.
  • Supports MCP-native integration via stdio or SSE servers.
