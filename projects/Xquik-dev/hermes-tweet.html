overview

Hermes Tweet connects Hermes agents to the Xquik API for searching posts, reading profile timelines, and monitoring accounts. It also supports actions such as posting, replying, and exporting followers, with actions disabled by default and approval required for `tweet_action`.

  • Includes separate tools for catalog search, reads, and actions.
  • Bundles a Hermes Skill and two slash commands.
  • Requires an Xquik API key for API access.

Install the Hermes Twitter plugin

Install and enable the plugin in Hermes Agent.

hermes plugins install Xquik-dev/hermes-tweet --enable

Create an API key in Xquik. Set it in your environment, then restart Hermes.

export XQUIK_API_KEY="xq_..."

Tools

Reads and actions use separate tools. The plugin bundles a Hermes Skill and 2 slash commands.

Tool Purpose
tweet_explore Search the bundled catalog. Makes no API call.
tweet_read Call catalog-listed read endpoints.
tweet_action Call private or mutating endpoints. Off by default.

Use tweet_explore first. Then pass a listed /api/v1/... path to the matching tool. Copied Xquik URLs work when their paths match the catalog.

Slash commands

Command Purpose
/xstatus Show Xquik account and usage status.
/xtrends Show current X (Twitter) trends.

Other install paths

Hermes scans plugins during install and update. Review any warning before you continue. A dangerous verdict blocks installation or disables an update.

Hermes installs no extra Python package for this plugin. Hermes core already ships httpx, its only dependency.

Do you manage the Hermes Python environment yourself? Add the hermes-tweet PyPI package to it, then enable the plugin.

hermes plugins enable hermes-tweet

Install a local checkout with this command.

hermes plugins install file:///absolute/path/to/hermes-tweet --force --enable

Configure

These settings are optional.

export XQUIK_BASE_URL="https://xquik.com"
export HERMES_TWEET_ENABLE_ACTIONS="false"

Restart Hermes after you change environment variables.

Safety

  • Tools never accept credentials as arguments.
  • The plugin injects XQUIK_API_KEY at request time.
  • Admin, billing, credit, support, guest-wallet, and API-key routes stay hidden.
  • Account re-authentication routes stay hidden.
  • Binary downloads stay outside the agent catalog. Use REST for those files.
  • Private reads and mutations use tweet_action.
  • tweet_action requires HERMES_TWEET_ENABLE_ACTIONS=true.

Without an API key, Hermes exposes only tweet_explore.

Questions

Do I need an X (Twitter) developer account?

No. Public reads need only an Xquik API key. Private reads & X (Twitter) account actions need a connected account.

Is Hermes Tweet the official X API?

No. Xquik runs its own REST API. Hermes Tweet calls that API, not the official X API.
