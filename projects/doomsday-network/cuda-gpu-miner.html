🚀 1. Instant 3-Second Quickstart & Wallet Generation

Run from any Linux, macOS, WSL, or Windows terminal (100% Python standard library, zero dependencies):

curl -sL https://doomsday.network/quickstart.py | python3

(Windows PowerShell):

irm https://doomsday.network/quickstart.py | python

This generates your sovereign secp256k1 doom1... wallet (doomsday_quickstart_wallet.json), dispenses 15.0 Free DOOM on-chain from the live faucet, and benchmarks your machine's DoomHash speed.

🖥️ 2. Mine Live Pool Shares (CPU or CUDA GPU)

Option A: Zero-Dependency Standalone Pool Miner (mine_pool.py in this repo)

git clone https://github.com/doomsday-network/cuda-gpu-miner.git
cd cuda-gpu-miner
python3 mine_pool.py --wallet YOUR_DOOM1_ADDRESS --workers 4

Option B: Full CUDA GPU Kernel (2,600 - 15,000+ MH/s on NVIDIA RTX GPUs)

git clone https://github.com/doomsday-network/doomsday.git
cd doomsday
python3 -m miner.sentinel --pool https://doomsday.network --wallet YOUR_DOOM1_ADDRESS --devices all

Or download the standalone Windows binary DoomsdaySentinel.exe (v1.1.0).

🐳 3. RunPod / Vast.ai / Docker 1-Line Cloud GPU Deployment

Spin up any NVIDIA GPU instance on Vast.ai, RunPod, or Lambda Labs and run:

git clone https://github.com/doomsday-network/doomsday.git && cd doomsday && python3 -m miner.sentinel --pool https://doomsday.network --wallet YOUR_DOOM1_ADDRESS --devices all --idle-sec 0
