Quick start

Bring MeiGen into the AI tool you already use:

Client Get started
ChatGPT Install from the official ChatGPT store, then sign in to MeiGen.
Claude Connect remote MCP and sign in; no dedicated Claude plugin is needed.
Cursor / VS Code / Codex Add the remote MCP URL and sign in. Client setup →
OpenClaw Install from ClawHub and connect your MeiGen account.
Other MCP clients Use remote MCP, or the npm bridge if your client requires stdio.

Try it with inspiration first:

Use MeiGen to find minimalist product photography inspiration. Show me the reference images and prompts.

Then refine a direction, bring in your own references, or create something new. Explore MeiGen →

Search and model/Skill lookups do not spend generation credits. Generation uses purchased credits only, not daily free credits; your assistant should check current prices before creating.

Pick up where you left off

Explore ideas on MeiGen, save them to boards, and continue in your AI conversation. With OAuth, you can browse favorites and past creations, read original prompts, save selected results, and manage references or characters with the relevant permissions.

Compatible MCP Apps hosts can show an interactive home, inspiration gallery, favorites, and generation cards with model-specific time estimates. Other hosts use text and media results; presentation depends on the client.

Connect MeiGen

Remote MCP — recommended

Add this Streamable HTTP URL in your client's MCP settings, then connect and sign in to MeiGen:

https://www.meigen.ai/api/mcp

No Node.js installation or new API key is needed. Keep one MeiGen connection per client. Verify with “List MeiGen's available models and Skills”; account features request their own OAuth permissions. Setup and troubleshooting →

npm bridge — for clients that require stdio

meigen@4.0.0 connects to the same hosted service. Requires Node.js 22.19+; Node.js 24 is recommended.

{
  "mcpServers": {
    "meigen": {
      "command": "npx",
      "args": ["-y", "meigen@4.0.0"]
    }
  }
}

New connections use browser OAuth. Existing MeiGen API keys remain supported for their compatible tools; private-library and character tools require OAuth. The bridge cannot read local file paths—use supported uploads or accessible image URLs.

Routine model and tool updates now arrive from the remote service. Refresh your tool list or reconnect; security or transport updates may still require a bridge update.

The dedicated Claude plugin is retired. Existing users can migrate to remote MCP, preserving their configuration and avoiding duplicate connections.

OpenClaw — install from ClawHub

Install MeiGen from ClawHub, then use OpenClaw's MCP connection settings to sign in:

openclaw plugins install clawhub:meigen-ai-design

The plugin contains the remote connection and one short usage guide. Its ClawHub version is independent of npm; the standalone creative-toolkit Skill is not needed alongside it. Connection guide →

Upgrading from 3.x?

4.0 is a remote bridge. BYOK, local file processing/downloads, local preferences, prompt enhancement and meigen gen remain in 3.4.0. Keep that version if you need these features. Existing version pins do not auto-upgrade. Migration and rollback →
