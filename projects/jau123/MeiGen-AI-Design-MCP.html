overview

MeiGen AI Design MCP provides tools for AI assistants to search for visual inspiration and create images and videos. It also supports tasks such as background removal, image upscaling, and product imagery, with connections available through remote OAuth or a legacy local npm setup.

  • Search inspiration and view associated prompts.
  • Generate images and videos with available models.
  • Connect through remote OAuth or local npm.

Quick start

Choose the AI tool you use:

Client Get started
ChatGPT Install from the official ChatGPT store → sign in to MeiGen → start a new chat and use MeiGen. No API key needed.
Claude Connect remote MCP and sign in to MeiGen. Optional creative helpers are available separately.
Cursor Add the remote MCP URL, then sign in.
OpenClaw Install from ClawHub, then sign in with OAuth.
Other MCP clients Connect remote MCP with OAuth. Setup guide →

Try a search first:

Use MeiGen to find minimalist product photography inspiration. Show me the reference images and prompts.

Want more options? With remote MCP, ask for another batch of the same search, or describe a new direction.

Search and model/Skill lookups do not spend generation credits. MeiGen Cloud generation uses purchased credits from your account; daily free credits do not apply. Check current prices and confirm the scope before generating.

What you can do

Capability Try asking
Inspiration search “Find cinematic portrait references and show their prompts.”
Image & video generation “Create one product photo, then animate it into a short video.”
Reference media “Use this clip or audio as a reference with a compatible video model.”
Saved characters — remote OAuth “List my MeiGen characters and use this one in the video.”
Personal library — remote OAuth “Find my saved references, or the prompt from a previous creation.”
Background removal “Remove this background and give me a transparent PNG.”
Product Detail Images “Make a hero shot, a close-up and a lifestyle image for this product.”
Marketing Poster “Design one poster for our weekend coffee tasting.”
AI Backgrounds “Place this product on a sunlit stone counter.”
Upscale “Enhance this original photo while preserving its appearance.”

Provide a source image when the task needs one. Your assistant checks available models, options and prices with list_models / list_skills, prepares inputs, and returns results. See the Skill API guide for input limits and tool-call examples.

Video references follow each model’s supported frame, content-image, video and audio inputs. Media preparation does not spend generation credits, requires a positive purchased balance, and creates temporary public URLs cleared after seven days. Saved characters can be read and reused through OAuth; creating characters is not supported. See 3.1 release notes.

Bring your MeiGen library into the conversation

Browse and save ideas in MeiGen, then continue with your assistant. With remote OAuth, it can search your favorites, browse boards, find past creations and read a selected original prompt. For questions about your preferred style, it can use relevant favorites as references.

Ask to save a selected inspiration or your own result, optionally to a private board. Saving requires your request or prior permission, does not publish the work, and does not spend generation credits. Reading and saving use separate account permissions; existing connections may need additional consent.

Available through remote OAuth and the official ChatGPT plugin. Local npm and API keys cannot access the private library. Refresh your client’s tool list and complete any requested additional consent. See the account-library reference for tool names and prompt pagination.

Manual MCP setup

Use remote OAuth for a new MeiGen connection. Keep one connection per client to avoid duplicate tools. Local npm and the optional client plugins below support existing API-key integrations and OpenAI-compatible image providers.

Remote MCP

Add this Streamable HTTP URL in your client's MCP settings, then choose Connect / Authenticate and sign in to MeiGen:

https://www.meigen.ai/api/mcp

OAuth requires support in your client. If unavailable, use a compatible host or the official ChatGPT plugin; a new API key is not a substitute for account sign-in. Reconnect and ask “List MeiGen's available Skills and current prices” to verify the connection without generating.

For optional Codex CLI / IDE MCP configuration, see the advanced setup guide.

Local npm — legacy compatibility and BYOK

Existing local integrations and BYOK workflows can keep this stdio configuration. New MeiGen users should use remote OAuth above. Node.js 22+ is recommended:

{
  "mcpServers": {
    "meigen": {
      "command": "npx",
      "args": ["-y", "meigen@3.3.3"]
    }
  }
}

Existing local API keys remain compatible with generation, public search and Skills as MEIGEN_API_TOKEN in the server's private environment, but cannot access the private library. New connections use remote OAuth. OpenAI-compatible providers support general image generation; video and the five visual Skills use MeiGen Cloud. See client-specific setup, providers and CLI.

Upgrading from 2.x? 3.0.0 is available on npm. It removes ComfyUI and the bundled offline prompt library. Read the migration notes and preserve your existing credentials and settings when updating.

Claude plugin

For new connections, use remote OAuth. The optional plugin below retains its bundled legacy stdio connection; keep one active MeiGen connection per host when switching. To install only within that supported setup, run inside Claude, then restart:

/plugin marketplace add jau123/MeiGen-AI-Design-MCP
/plugin install meigen@meigen-marketplace

Use /meigen:setup for connection guidance or existing legacy/BYOK configuration. The plugin adds /meigen:gen, /meigen:find, /meigen:models and optional creative agents. Plugin guide →

OpenClaw

Install MeiGen from ClawHub in current OpenClaw, then connect your account with OAuth:

openclaw plugins install clawhub:meigen-ai-design
# New connection only; preserve any existing meigen entry
openclaw mcp add meigen --url https://www.meigen.ai/api/mcp --transport streamable-http --auth oauth --timeout 240
openclaw mcp login meigen

The 4.1 plugin includes creative guides and remote tools, including OAuth-only favorites, boards and history. The standalone creative-toolkit Skill is instructions only and is not needed alongside the plugin. Setup and migration from local 3.x →

Let your coding assistant set up MCP

Paste this into an assistant that can configure your MCP client:

Set up MeiGen MCP using https://github.com/jau123/MeiGen-AI-Design-MCP#quick-start.
Detect this client, preserve other servers and reuse any existing MeiGen entry.
Use remote HTTP with OAuth for MeiGen account access. Keep existing legacy API-key or BYOK connections only when they are needed; do not create a new MeiGen key.
Let me sign in through the host, never send credentials in chat.
Reconnect and verify with list_skills. Do not upload, generate or spend credits.
If you cannot configure this client, explain the remaining manual steps.
