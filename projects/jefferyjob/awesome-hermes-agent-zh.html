从哪里开始？

从零到高效使用的三步路径：

  1. 跑起来 Hermes： 按照官方文档快速开始操作（安装、CLI、第一次对话）。
  2. 添加技能： wondelai/skills（覆盖面广的技能库）或 litprog-skill（文学化编程）。
  3. 添加交互界面： hermes-workspace（Hermes GUI）或 mission-control（fleet / 调度仪表盘）。

然后浏览下面的完整列表。每个资源都带有成熟度标签：

标签 含义
production 稳定、文档完善、持续维护 —— 可以放心在其基础上构建
beta 可以使用，但仍在持续演进 —— 预计会有一些粗糙边角
experimental 概念验证或早期阶段 —— 可以借鉴学习，但不建议依赖

标签是基于文档质量、安装证据、维护情况和社区采用信号做出的编辑快照。在依赖某个项目之前，请先重新核查其链接指向的现状。

检查信任边界

生态收录只是一份发现指南，并非安全背书。在启用社区技能、插件、MCP server 或无人值守任务之前，请核实：谁能触发它、它能拿到哪些工具、命令在哪里执行、它能读取哪些凭据，以及你如何停止它。对不可信的工作，优先使用最小工具集和隔离后端。

有关当前可用的控制手段，请使用官方安全指南、工具参考和 cron 文档。

关于 /new、/resume、/compress、/branch、导出与清理的操作者例行流程，请参阅 Hermes Agent 会话管理指南。

官方资源

由 Nous Research 维护的核心仓库和资源。

  • Hermes Agent by Nous Research - 核心项目。具备封闭学习回路的可自我改进 AI agent，支持技能创建与管理、持久化记忆、20+ 消息平台、六种终端后端（local、Docker、SSH、Singularity、Modal、Daytona）、cron 调度、MCP 集成、隔离 profiles、provider 路由以及从 OpenClaw 自动迁移。215k+ stars。
  • autonovel by Nous Research - 基于 Hermes 构建的自主小说写作流水线。使用 agent 循环端到端生成长篇手稿（100k+ 字）。

  • hermes-agent-self-evolution by Nous Research - 使用 DSPy 和 GEPA（Genetic Evolution of Prompt Architectures）进行进化式自我改进。这是用于优化 Hermes 自身提示词和行为的研究流水线。
  • Official Documentation - 全面的官方文档，涵盖快速开始、CLI、配置、消息网关、安全、工具、技能、记忆、MCP、cron、ACP、API server 和架构。
  • Release Notes - 官方更新日志，包含每个 Hermes 版本的功能亮点、迁移说明和可靠性修复。
  • tinker-atropos by Nous Research - 独立的 Atropos 集成，接入 Thinking Machines Tinker API。用于在真实 agent 轨迹上微调工具调用模型的 RL 训练基础设施。
  • Skills Hub - 面向 agent 技能的开放标准。兼容 Hermes、Claude Code、Cursor、Codex 和其他 agent。
  • Discord - Nous Research 社区。用于提交 bug、提出功能请求以及一般讨论。
