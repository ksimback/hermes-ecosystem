overview

oh-my-hermes is an operating layer for Hermes Agent that provides governed workflows for planning, research, and project memory. It functions as a management interface above Hermes-native skills, utilizing explicit evidence boundaries to frame problems and run capabilities.

  • Adds an operating layer for planning, research, and project memory.
  • Supports installation via Homebrew, Bun, npm, and universal shell scripts.
  • Integrates with Hermes Desktop, CLI, and messenger applications.
