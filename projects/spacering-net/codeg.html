overview

Codeg brings multiple AI coding agents into one workspace, where they appear in a shared structured conversation interface. It can import, search, and resume agent histories, hand sessions to another agent, and support cross-agent delegation and queued to-dos in separate worktrees. The README lists desktop, self-hosted server, Docker, mobile, and messaging-app access.

  • Includes 19 agents and supports ACP agents.
  • Import, search, resume, and hand off agent sessions.
  • Delegate across agents or queue to-dos in worktrees.

🤖 Supported Agents

Codeg talks to every agent over the Agent Client Protocol, so each one gets the same structured interface. Nineteen come built in, and Codeg installs, pins, and updates most of them for you:

Claude Code   Codex   Gemini CLI   OpenClaw   OpenCode   Cline   Hermes Agent   CodeBuddy   Kimi Code   Pi   Grok   Cursor   DeepSeek Harness   Qoder   Google Antigravity   Kiro CLI   ZCode   TRAE CLI   Command Code   + any ACP agent

Not on the list? Pick any agent from the public ACP registry or paste its distribution JSON — Codeg installs it, checks that it launches, and treats it like a built-in. Runtime requirements and where each agent keeps its sessions: Supported Agents.

📦 Install

Desktop — installers for macOS, Windows, and Linux are on Releases; setup steps in Installation.

Server — run Codeg headless and reach it from any browser. On Linux or macOS:

curl -fsSL https://raw.githubusercontent.com/spacering-net/codeg/main/install.sh | bash
CODEG_STATIC_DIR=/usr/local/share/codeg/web codeg-server

On Windows, in PowerShell:

irm https://raw.githubusercontent.com/spacering-net/codeg/main/install.ps1 | iex
$env:CODEG_STATIC_DIR="$env:LOCALAPPDATA\codeg-server\web"; codeg-server

Docker — the same server, in one container:

docker run -d -p 3080:3080 -v codeg-data:/data ghcr.io/spacering-net/codeg:latest

Either way, open http://<host>:3080 in a browser and enter the access token the server prints when it starts (docker logs shows it for the container), or set CODEG_TOKEN to choose your own.

Mobile — install the iOS app or the Android APK, then point it at the Web Service of your desktop app or at your own codeg-server: URL, token, done. Pairing steps in Mobile apps.

Compose, prebuilt binaries, source builds, and in-place updates are covered in Deployment; environment variables in Configuration.
