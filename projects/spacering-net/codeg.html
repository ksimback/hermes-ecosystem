overview

Codeg brings multiple AI coding agents into one workspace, presenting their activity as structured conversations. It can import, search, and resume agent sessions, hand sessions to another agent, and support cross-agent delegation and queued tasks in separate worktrees. The README lists desktop, self-hosted server, Docker, mobile, and messaging options for using Codeg.

  • Includes 15 agents and supports ACP agents.
  • Import, search, resume, and hand off agent sessions.
  • Delegate with @ or queue tasks in separate worktrees.

✨ Features

One Interface for Every Agent

Fifteen agents come built in, and any other ACP agent can join from the public registry or its distribution JSON. Codeg speaks the Agent Client Protocol to every one of them, so they all get the same rich conversation — tool cards, live diffs, plans, and permission prompts — instead of a terminal to squint at.

Docs → · Custom agents →

Every Session, Searchable

Codeg reads the history every agent CLI keeps on disk: import it in one click, search all of it, and resume any session where it stopped. @-mention an old session and the agent you're talking to can read it — even one a different agent wrote.

Docs →

Multi-Agent Collaboration

Type @, pick an agent, send. Each mentioned agent runs as its own session, side by side, streaming back into your thread — Claude Code drafting while Codex reviews — and sub-agents show up as cards that fill in while they work.

Docs →

To-dos That Run Unattended

Write a job down and walk away. Each to-do gets its own git worktree and branch, starts now or on a schedule, and waits in Review; accept the diff and the agent lands it, and Codeg checks git before calling it done.

Docs →

Infinite Canvas

Lay your work out in space: conversations, files, terminals, and notes become cards on a board, grouped by folder and agent, so several agents can run side by side in plain sight.

Docs →

Desktop, Server, Mobile & Chat

Run Codeg as a desktop app, a self-hosted server you open in any browser, or a single Docker container. Native iPhone, iPad, and Android clients — plus Telegram, Lark, and WeChat channels — keep your agents in reach, while your files and sessions stay on your own machine.

Docs → · Mobile apps → · Chat channels →

Office Documents & Research

Ask for a deck, a report, or a workbook and watch the real .pptx, .docx, or .xlsx render live beside the conversation. Bundled research skills — hypotheses, experimental design, statistics, literature search — work with any agent.

Docs → · Research →

Browser & Computer Use

In the desktop app, links open in a built-in browser beside your files: hand the agent a page, an element, a screenshot, or a console error, or let it drive a page you share. In preview, agents can also see and operate the windows you share — and Stop is one click away.

Docs → · Computer Use →

The Full Engineering Loop

An editor, live and side-by-side diffs, a full git client with a three-pane merge editor, one-click worktrees, an embedded terminal, and split views — all next to the agent, on the real files in your repo.

Docs → · Git & worktrees →

Also in the box:

  • Repository Panel — issues, pull requests, checks, and merges for GitHub, GitLab, Gitea, and Forgejo; any issue or PR can become a to-do
  • Automations — save a configured composer and run it headlessly, on a cron schedule or on demand
  • Token Usage — trends, cache hit rate, an activity heatmap, and usage by folder, agent, model, and session
  • Fork & Steer — fork a conversation from a finished reply, or send a message into a turn that is still running, on agents that support it
  • Skills & MCP — skill packs per agent, a local MCP scan, and registry search and install
  • Project Boot — scaffold a new project visually, with a live preview
  • Make It Yours — twelve themes you can recolor token by token, wallpapers, corner radius, and custom CSS — in any of ten interface languages
  • Backup & Sync — encrypted backups, and configuration sync between machines through a file or your own WebDAV server
  • URL Scheme — codeg://session/<id> opens a conversation from another app (desktop)
  • And more — nearly every release adds something; the release notes are the full list

🤖 Supported Agents

Codeg talks to every agent over the Agent Client Protocol, so each one gets the same structured interface. Fifteen come built in, and Codeg installs, pins, and updates most of them for you:

Claude Code   Codex   Gemini CLI   OpenClaw   OpenCode   Cline   Hermes Agent   CodeBuddy   Kimi Code   Pi   Grok   Cursor   DeepSeek Harness   Qoder   Google Antigravity   + any ACP agent

Not on the list? Pick any agent from the public ACP registry or paste its distribution JSON — Codeg installs it, checks that it launches, and treats it like a built-in. Runtime requirements and where each agent keeps its sessions: Supported Agents.

📦 Install

Desktop — installers for macOS, Windows, and Linux are on Releases; setup steps in Installation.

Server — run Codeg headless and reach it from any browser. On Linux or macOS:

curl -fsSL https://raw.githubusercontent.com/spacering-net/codeg/main/install.sh | bash
CODEG_STATIC_DIR=/usr/local/share/codeg/web codeg-server

On Windows, in PowerShell:

irm https://raw.githubusercontent.com/spacering-net/codeg/main/install.ps1 | iex
$env:CODEG_STATIC_DIR="$env:LOCALAPPDATA\codeg-server\web"; codeg-server

Docker — the same server, in one container:

docker run -d -p 3080:3080 -v codeg-data:/data ghcr.io/spacering-net/codeg:latest

Mobile — install the iOS app or the Android APK, then point it at the Web Service of your desktop app or at your own codeg-server: URL, token, done. Pairing steps in Mobile apps.

Compose, prebuilt binaries, source builds, and in-place updates are covered in Deployment; environment variables in Configuration.
