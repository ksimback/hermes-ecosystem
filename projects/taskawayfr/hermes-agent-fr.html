Hermes Agent en français

Le guide pratique, en français, pour installer Hermes Agent (l'agent IA libre de Nous Research), le brancher sur Telegram, le sécuriser et le laisser travailler seul.

Pourquoi ce guide, à côté de la documentation officielle ?

La documentation officielle est complète, en anglais, et rangée par fonction. Ce guide ne la remplace pas : il la complète.

  • Il suit l'ordre de la première fois. Ce qu'on fait, dans l'ordre, puis les pièges.
  • Il dit ce qui casse en production. Les encadrés « Sur le terrain » viennent d'une équipe de cinq agents Hermes qui tourne tous les jours : ce qui a cassé, pourquoi, ce qu'on fait depuis.
  • Il donne des fichiers prêts à copier, et testés. Un SOUL.md en français, une configuration de sécurité, un plugin garde-fou, une compétence, un script de surveillance : exemples/.
  • Il couvre ce que les débutants demandent vraiment. Consommation de jetons, choix de la machine, abonnements utilisables, Docker et NAS, navigation web.
  • Il est vérifié automatiquement. Voir plus bas.

Par où commencer ?

Vous dirigez une petite entreprise et voulez comprendre avant de décider (20 minutes). Le schéma ci-dessus, puis le chapitre 12 (cas d'usage), le chapitre 5 (sécurité) et la FAQ.

Vous installez. Chapitres 1 à 6 dans l'ordre, puis la liste de contrôle du chapitre 13 avant de laisser l'agent seul.

Ça ne marche pas. Chapitre 8 (dépannage), puis la FAQ.

Comment ce guide est-il vérifié ?

  • Le contenu est écrit à partir de la documentation officielle (v0.21.5, 4 octobre 2026) et de son code source quand la documentation se contredit. Chaque chapitre cite ses sources.
  • Les commandes : un script extrait chaque commande hermes … du guide et contrôle, dans la dernière image Docker officielle de Hermes, que la commande et ses options existent (scripts/verifier_commandes.py).
  • Les exemples sont installés dans un conteneur Hermes neuf et testés : la configuration de sécurité refuse ce qu'elle doit refuser, le plugin bloque ce qu'il doit bloquer, la compétence est reconnue, le script reste muet quand tout va bien (scripts/tester_exemples.sh).
  • Les liens sont contrôlés.
  • Tout cela tourne sur GitHub à chaque modification et chaque lundi, pour repérer ce qu'une nouvelle version de Hermes a changé.

Guide non officiel, indépendant de Nous Research. En cas de doute, la documentation officielle fait foi.
