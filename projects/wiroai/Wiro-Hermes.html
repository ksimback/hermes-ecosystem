overview

Wiro-Hermes provides two plugins for Hermes Agent: `wiro-media` adds tools for image, video, speech, music, transcription, and 3D tasks, while `wiro` adds Wiro AI’s LLM gateway as a model provider. Both use a Wiro AI API key; the gateway offers GPT, Claude, Gemini, DeepSeek, GLM, Kimi, and Grok models through an OpenAI-compatible API.

  • Media plugin includes thirteen `wiro_*` tools.
  • Install the media and model-provider plugins separately.
  • Runs are paid from a Wiro AI wallet.

Wiro-Hermes

Wiro AI for Hermes Agent: image, video, speech, music, transcription and 3D tools with 1,000+ models, and the Wiro AI LLM gateway as a model provider, all on one API key.

Plugin What it adds
wiro-media Thirteen wiro_* tools: generate and edit images, make video from a prompt or a picture, read text aloud, compose music, transcribe audio, build 3D models, search the catalog with prices, and run any model or workflow. Wiro AI as the backend of Hermes' own image_generate, video_generate, text_to_speech and voice message transcription. A skill with recipes.
wiro The Wiro AI LLM gateway as a model provider: GPT, Claude, Gemini, DeepSeek, GLM, Kimi and Grok models on one OpenAI-compatible API. 
hermes plugins install wiro-media --enable   # tools and media backends
hermes plugins install wiro                  # chat models, then pick Wiro AI in `hermes model`
hermes config set WIRO_API_KEY <your-key>

Until the wiro-media catalog listing lands, install it from the repository: hermes plugins install "https://github.com/wiroai/Wiro-Hermes#wiro-media" --enable.

Create a key at wiro.ai/panel/project. Each plugin's README covers setup, models and settings: wiro-media, wiro. Hermes loads model providers and tool plugins through separate paths, so they are two plugins; install one or both. Runs are paid as you go from your Wiro AI wallet. API docs: wiro.ai/docs.

Development

Tests run against a Hermes source checkout (HERMES_SOURCE, a sibling hermes-agent directory, or PYTHONPATH):

python -m pytest tests -q
hermes plugins validate wiro --install-deps
hermes plugins validate wiro-media --install-deps

The media tests run the plugin inside Hermes against an in-memory Wiro AI API, so they need no key; with ffmpeg installed they also cover the voice note conversion. With WIRO_API_KEY set, WIRO_LIVE_CATALOG=1 python -m pytest tests -q also compares the model provider's table against the live catalog.
