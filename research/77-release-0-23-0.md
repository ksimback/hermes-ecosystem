# Hermes Agent v0.23.0

**Release Date:** November 5, 2026
**Since v0.22.0:** ~10,080 commits · ~1,950 merged PRs · ~8,720 files changed · ~725,200 insertions · ~201,400 deletions · **~850 issues closed** · 666 contributors

> **The Hearth Release.** In the old hymns Hermes kept the threshold and Hestia kept the hearth, and the two were honored side by side. v0.22.0 got newcomers through the door; v0.23.0 builds the fire they gather around. The headline: your whole Desktop workspace now opens in a browser tab, served by your own gateway. Underneath it, every conversation lives in one place: a single gateway owns each session, and the CLI, TUI, Desktop, editors, bots and cron all sit down at the same table instead of each running its own agent. From that one hearth, Desktop keeps every machine you run Hermes on connected at once, Group Chats route their own conversations, and the terminal finally draws your images inline and lets you rewind a conversation. Around it: plugins that keep themselves updated, price tags and spend limits on paid MCP tools, pluggable delegation, a plugin catalog that grew from about 600 to over 1,050 entries, a leaner built-in skill set, and a long run of memory and latency work for long-lived gateways. This release rolls up and fully documents the v0.22.1–v0.22.7 patch releases.

## ✨ Highlights

- **Your Desktop workspace in a browser tab** — The new Webapp serves the full Desktop workspace from your own gateway: the same chats, Group Chats, plugins and settings, in any browser on your network or behind a public URL with sign-in. The Docker image and Nix package ship it. It is off by default; turn it on with `webapp.enabled` or Web Access in Settings. ([#141864](https://github.com/NousResearch/hermes-agent/pull/141864), [#145598](https://github.com/NousResearch/hermes-agent/pull/145598), [#145536](https://github.com/NousResearch/hermes-agent/pull/145536), [#145072](https://github.com/NousResearch/hermes-agent/pull/145072), [#145153](https://github.com/NousResearch/hermes-agent/pull/145153) — @jquesnelle, @BearHuddleston, @IAvecilla, @Adolanium)

- **One gateway owns every conversation** — Before, the CLI, TUI, Desktop, editors (ACP), messaging bots and cron could each run their own copy of the agent against the same chat, which is how messages got written twice or went missing between surfaces. Now each machine runs one gateway that owns every session, and every surface attaches to it as a client: a chat you open anywhere is the same chat, with one queue and one history. You can even steer or edit a queued prompt from Desktop without it running twice. ([#106742](https://github.com/NousResearch/hermes-agent/pull/106742), [#140334](https://github.com/NousResearch/hermes-agent/pull/140334) — @unsupportedpastels, @kshitijk4poor)

- **Pictures in the terminal** — When you paste an image, or a tool takes a screenshot, the CLI and TUI now draw it right in the chat instead of printing a file path: real pixels in kitty and Ghostty (CLI and TUI) and in iTerm2, WezTerm and Konsole (CLI), coloured blocks everywhere else, and full resolution in VS Code's terminal when its image support is on. ([#147293](https://github.com/NousResearch/hermes-agent/pull/147293), [#148874](https://github.com/NousResearch/hermes-agent/pull/148874) — @Adolanium)

- **Rewind a conversation** — Press Esc twice or type `/rewind` in the TUI or classic CLI, pick an earlier message, then edit and resend it or fork a new session from that point. The original session stays exactly as it was. The TUI can also start `/new` while a turn is still running; the old one keeps working in the background. ([#144937](https://github.com/NousResearch/hermes-agent/pull/144937), [#148880](https://github.com/NousResearch/hermes-agent/pull/148880) — @SaguaroDev)

- **Every machine in one Desktop window** — Desktop now keeps all your gateways connected at once, so switching between this computer and an SSH or remote gateway is instant. Terminal tabs run on the host they were opened on, and a Group Chat can mix bots from different machines. ([#147681](https://github.com/NousResearch/hermes-agent/pull/147681), [#147708](https://github.com/NousResearch/hermes-agent/pull/147708), [#148418](https://github.com/NousResearch/hermes-agent/pull/148418) — @dskwe, @janviernine)

- **Group Chats that run themselves** — Bot Mode rooms can let a lead bot, or an automatic router, pick who answers a message that names nobody. Scheduled jobs can post into a room, rooms keep a purpose and shared notes, and bots no longer ping each other in endless loops. Rooms also look like a normal Hermes chat now, and each bot shows what it is doing live ("scout · terminal · 7s"). ([#144833](https://github.com/NousResearch/hermes-agent/pull/144833), [#148417](https://github.com/NousResearch/hermes-agent/pull/148417), [#148888](https://github.com/NousResearch/hermes-agent/pull/148888), [#148903](https://github.com/NousResearch/hermes-agent/pull/148903), [#148422](https://github.com/NousResearch/hermes-agent/pull/148422) — @KoNit-K)

- **Plugins that keep themselves current** — `hermes plugins update` updates everything at once, and an opt-in Auto-update switch (CLI, chat, Desktop and dashboard) keeps catalog and git plugins up to date. Updates that would break your setup are held back instead of applied. The catalog itself grew from about 600 to over 1,050 entries, and a new Verified tier marks plugins built by the vendor itself. ([#141513](https://github.com/NousResearch/hermes-agent/pull/141513), [#85794](https://github.com/NousResearch/hermes-agent/pull/85794), [#143468](https://github.com/NousResearch/hermes-agent/pull/143468), [#144257](https://github.com/NousResearch/hermes-agent/pull/144257) — @charan-rathore, @YS-OH-CORE)

- **Price tags and spend limits for paid tools** — Paid MCP tools, such as 3D or media generation, can declare what a call costs. The approval prompt shows each call's price and the chat's running total, and Hermes asks before a chat goes over its limit, even in YOLO mode. ([#142470](https://github.com/NousResearch/hermes-agent/pull/142470), [#143780](https://github.com/NousResearch/hermes-agent/pull/143780), [#143795](https://github.com/NousResearch/hermes-agent/pull/143795), [#143787](https://github.com/NousResearch/hermes-agent/pull/143787) — @liuhao1024, @fangliquanflq)

- **New official plugins, and a smaller core** — Meshy (text and image to 3D), ElevenLabs Music and Sound Effects, X Chat, REA (reverse engineering) and a bubblewrap sandbox are now one-command installs. Camofox, `mcp-serve`, the agent importers and Singularity moved out of core into plugins that install themselves for anyone who used them. ([#142619](https://github.com/NousResearch/hermes-agent/pull/142619), [#146294](https://github.com/NousResearch/hermes-agent/pull/146294), [#139725](https://github.com/NousResearch/hermes-agent/pull/139725), [#143484](https://github.com/NousResearch/hermes-agent/pull/143484), [#139983](https://github.com/NousResearch/hermes-agent/pull/139983))

- **Choose how subagents are run** — Delegation is now pluggable: keep the default, or install the official `advanced-delegation` plugin to send each subagent task to a named model or into a separate profile. Switch with `/delegation`. ([#142563](https://github.com/NousResearch/hermes-agent/pull/142563), [#142564](https://github.com/NousResearch/hermes-agent/pull/142564), [#143423](https://github.com/NousResearch/hermes-agent/pull/143423))

- **Lighter and faster, especially when Hermes runs all day** — Recurring cron jobs share a prompt cache, one-shot runs send about 1,570 fewer prompt tokens per call, and `patch`/`write_file` return in milliseconds with LSP on. Long-lived gateways now let go of closed sessions' memory, and the Desktop sidebar no longer slows down as sessions pile up (one store with ~35k cron runs went from a 121 s refresh to instant). ([#139876](https://github.com/NousResearch/hermes-agent/pull/139876), [#144177](https://github.com/NousResearch/hermes-agent/pull/144177), [#140387](https://github.com/NousResearch/hermes-agent/pull/140387), [#147863](https://github.com/NousResearch/hermes-agent/pull/147863), [#137087](https://github.com/NousResearch/hermes-agent/pull/137087), [#147819](https://github.com/NousResearch/hermes-agent/pull/147819), [#144940](https://github.com/NousResearch/hermes-agent/pull/144940) — @kshitijk4poor)

- **A leaner skill set you can lock** — The built-in skills went from 58 to 44, with Word, PowerPoint and Excel merged into one `microsoft-office` skill. `hermes curator lock` stops the agent from rewriting a skill you curated by hand, through any tool, even in YOLO mode. ([#147557](https://github.com/NousResearch/hermes-agent/pull/147557) — @daviseford)

- **Password managers and a keychain vault key** — Verified password-manager plugins can hand the browser your logins without seeing anyone else's, and the browser vault's key can now live in your OS keychain. ([#143964](https://github.com/NousResearch/hermes-agent/pull/143964), [#144246](https://github.com/NousResearch/hermes-agent/pull/144246) — @Jesssullivan)

- **Stop a running cron job** — Cancel a running job from the CLI, Desktop, the API or the agent itself, and set per job what happens to runs missed while Hermes was off. ([#144801](https://github.com/NousResearch/hermes-agent/pull/144801) — @kokhlo, @fangliquanflq, @LeonSGP43)

## ⚠️ Upgrade notes

- **The old built-in browser tools are gone.** Browser automation runs on `browser_exec` only; agent-browser and the ten `browser_*` tools (`browser_navigate`, `browser_click`, ...) were removed. Homes that used Camofox get the `camofox` plugin installed automatically. If your own prompts, skills or toolset lists name the old tools, switch them to `browser_exec`. ([#143146](https://github.com/NousResearch/hermes-agent/pull/143146))
- **Desktop needs macOS 13+ and 64-bit Windows.** The app moved to Electron 44, which no longer runs on macOS 11, macOS 12 or 32-bit Windows. ([#142727](https://github.com/NousResearch/hermes-agent/pull/142727) — @OutThisLife, @Adihaliem)
- **`hermes mcp serve` is now `hermes mcp-serve`** (it moved into a plugin). MCP clients that launch Hermes as a server need their command updated; nothing rewrites it for you.
- **Word, PowerPoint and Excel skills are now one `microsoft-office` skill.** Old copies stay on disk until you remove them.
- **The Webapp is off by default.** Nothing is served to a browser until you turn on `webapp.enabled` or Web Access.

### Agent Loop & Sessions
- **Lower prompt-token and cache costs** — Every fire of the same cron job now shares one prompt-cache key. Background one-shot calls (summaries, titles, `/moa`) stop paying for cache writes. One-shot runs send 1,570 fewer prompt tokens per call, and four tool schemas are 319 tokens shorter. Gateway goal and heartbeat turns, post-compaction turns and between-turn MCP refreshes no longer rewrite the cached prefix. ([#139876](https://github.com/NousResearch/hermes-agent/pull/139876), [#140478](https://github.com/NousResearch/hermes-agent/pull/140478), [#144177](https://github.com/NousResearch/hermes-agent/pull/144177), [#144173](https://github.com/NousResearch/hermes-agent/pull/144173), [#139865](https://github.com/NousResearch/hermes-agent/pull/139865), [#139851](https://github.com/NousResearch/hermes-agent/pull/139851) — @100yenadmin, @jonpol01, @chelsealong, @AdrianBinDC)
- **Opt-in prepared compaction** — With `compression.prepare_ahead: true`, the next summary is written in the background as a session nears the trigger, so compaction no longer pauses the turn while the summary is written. Messages that arrive in the meantime stay in the tail word for word. Off by default. ([#144684](https://github.com/NousResearch/hermes-agent/pull/144684), [#144886](https://github.com/NousResearch/hermes-agent/pull/144886) — @kshitijk4poor)
- **Compaction is more honest and harder to stall** — Summaries list uncertain claims on `UNVERIFIED:` lines, so a guess does not come back as a fact. The main-model fallback uses the main route, `/stop` closes a summary stream, and queued messages and `/steer` survive a context-exhaustion reset. ([#86019](https://github.com/NousResearch/hermes-agent/pull/86019), [#139872](https://github.com/NousResearch/hermes-agent/pull/139872), [#144825](https://github.com/NousResearch/hermes-agent/pull/144825), [#139783](https://github.com/NousResearch/hermes-agent/pull/139783), [#139923](https://github.com/NousResearch/hermes-agent/pull/139923) — @helix4u, @thehugegatsby)
- **`hermes sessions refresh-prompts`** — Continuing sessions pick up an edited `SOUL.md`, skills or context files on their next turn without `/new`. History is kept and each session takes one cache miss. ([#143581](https://github.com/NousResearch/hermes-agent/pull/143581) — @victor-kyriazakos)
- **Opt-in stream lifetime cap** — `agent.stream_max_lifetime` (off by default) cuts off a stream that never finishes. Timeout errors now name the phase that failed and the setting to raise. ([#80701](https://github.com/NousResearch/hermes-agent/pull/80701), [#80873](https://github.com/NousResearch/hermes-agent/pull/80873) — @krzsda)
- **Follow-up questions about a photo still see the photo** — This applies after `--resume`, API-server session continuation and gateway restarts. ([#139873](https://github.com/NousResearch/hermes-agent/pull/139873) — @Alexbob0)
- **Session storage** — Auto-prune is opt-in again, and Hermes asks once when the disk runs low. `hermes sessions optimize-storage` shows progress and finished a real store about 18x faster. Startup no longer waits on the scratch prune, and `hermes sessions` failures exit 1. ([#139762](https://github.com/NousResearch/hermes-agent/pull/139762), [#144630](https://github.com/NousResearch/hermes-agent/pull/144630), [#144625](https://github.com/NousResearch/hermes-agent/pull/144625), [#144767](https://github.com/NousResearch/hermes-agent/pull/144767))

([#141005](https://github.com/NousResearch/hermes-agent/pull/141005), [#143791](https://github.com/NousResearch/hermes-agent/pull/143791), [#81434](https://github.com/NousResearch/hermes-agent/pull/81434), [#144266](https://github.com/NousResearch/hermes-agent/pull/144266), [#141017](https://github.com/NousResearch/hermes-agent/pull/141017), [#140995](https://github.com/NousResearch/hermes-agent/pull/140995), [#140997](https://github.com/NousResearch/hermes-agent/pull/140997), [#140624](https://github.com/NousResearch/hermes-agent/pull/140624), [#140978](https://github.com/NousResearch/hermes-agent/pull/140978) — @curiouscleo, @Halldrix, @Baophan00, @Finn763, @pieralukasz, @ewtillman, @nekwo)
- **Plugins can sign you in to third-party APIs without seeing the token** — a plugin declares an OAuth client, `hermes auth add <plugin>:<id>` runs the browser sign-in, and Hermes attaches the token only on requests to the hosts the plugin declared. - **Bigger Desktop plugin SDK** — Desktop plugins can add rows to the composer's right-click menu and words to the spell checker, render media from their own tools, post cards into their own chat, and script the preview Browser once they declare the capability and you allow it for that site. ([#143678](https://github.com/NousResearch/hermes-agent/pull/143678), [#143980](https://github.com/NousResearch/hermes-agent/pull/143980), [#143776](https://github.com/NousResearch/hermes-agent/pull/143776), [#143668](https://github.com/NousResearch/hermes-agent/pull/143668), [#141533](https://github.com/NousResearch/hermes-agent/pull/141533) — @Schildkrote)
